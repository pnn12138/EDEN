# EDEN 项目概述

## 项目简介
EDEN 是一个 AI 叙事游戏项目，玩家通过对话与游戏角色互动，影响故事走向。

## 当前阶段
Chapter 0 Demo：玩家扮演蛇，通过对话诱导夏娃吃下善恶果。

## 技术栈
- 前端：Next.js + TypeScript
- AI：待定（DeepSeek API 等）
- 状态管理：待定

## 项目结构
- `doc/` - 项目管理资料区
- `design/` - 游戏设计文档区
- `src/` - 代码区

## 开发计划
1. Chapter 0 Demo 实现
2. Chapter 1 扩展
3. 多角色、多场景、多结局
4. AI Agent 与工具调用
