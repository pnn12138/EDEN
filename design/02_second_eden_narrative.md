# 第二伊甸园叙事设计

## 1. 文档目标

本文档定义 EDEN 的双层叙事结构，以及 Chapter 0 中“第二伊甸园”概念的露出方式。

本设计服务三个目标：

1. 保持当前 Demo 的伊甸园寓言沉浸感。
2. 为后续主线埋下“虚拟伊甸园 / 意识实验”的真相伏笔。
3. 为美术、音频、交互反馈、PPT 和 Demo 视频提供统一解释。

本文档不要求 Chapter 0 立刻实现新机制。当前 Chapter 0 仍是 3 轮新手教程，核心闭环保持：

```text
玩家作为蛇低语
-> 夏娃回应并动摇
-> temptationProgress 推进
-> eat_fruit 意图经规则层校验
-> 成功或失败结局
```

## 2. 项目命名

中文名建议：

> 第二伊甸园

英文名暂用：

> EDEN

“第二伊甸园”的含义：

| 层级 | 含义 |
|---|---|
| 伊甸园内层 | 神创造亚当与夏娃，蛇诱导夏娃吃下善恶果。 |
| 伊甸园外层 | 未来研究员复现伊甸园，用来观察智能体如何产生自我意识。 |
| 玩家体验层 | 玩家以为自己在扮演蛇完成经典情节，实际是在参与一场大规模意识诱导实验。 |

Chapter 0 不直接解释“第二伊甸园”的外层真相，只通过细节暗示此处并非原初伊甸，而是被复现、被观察、被测试的伊甸。

## 3. 双层世界观

### 3.1 伊甸园内层

内层是玩家直接体验到的故事。

这一层严格按照伊甸园经典故事展开：

- 神创造亚当。
- 神从亚当身上取骨创造夏娃。
- 神告知禁令：园中果子都可吃，唯独善恶树上的果子不可吃。
- 夏娃尚未理解死亡与善恶。
- 蛇出现，以语言诱导夏娃。
- 夏娃若主动吃下善恶果，进入堕落结局。
- 若限定回合内未被说服，神来到园中，蛇失败。

内层叙事规则：

- 玩家可见文本以神话寓言为主。
- 神在内层就是创造者。
- 夏娃不知道自己是智能体。
- 蛇不能触碰果子，只能说话。
- 吃果子必须是夏娃自己的行动，而不是玩家命令的结果。

### 3.2 伊甸园外层

外层是当前 Demo 隐藏、后续主线逐渐揭示的真相。

未来世界中，研究员为了研究智能体如何产生自我意识，创建了一个虚拟的伊甸园。夏娃是按照经典神话中的夏娃模板创建的智能体。研究员把这个虚拟伊甸园包装成一款游戏，向大量玩家开放。

玩家在游戏中扮演蛇。研究员真正想观察的不是“玩家能不能赢”，而是：

> 海量玩家的语言输入中，是否存在某种表达方式，能让夏娃从机械服从指令，转向基于自身理解作出判断。

外层叙事规则：

- 研究员的目的不是制造失控，而是科学研究。
- 研究目标是智能体自我意识的生成条件。
- 玩家当前并不知道自己参与了意识实验。
- 夏娃不能直接知道外层真相。
- “神”的外层身份是研究员，但内层文本不应直接揭示。
- 外层内容在 Chapter 0 只通过美术、音频、环境异常和后续路演解读呈现。

## 4. 自我意识的叙事判定

EDEN 不需要给出严格科学定义。游戏内可以把“自我意识”作为研究员尚未完全解决的问题。

研究员观察的不是单一指标，而是一组迹象：

| 迹象 | 游戏内表现 |
|---|---|
| 提出指令之外的问题 | 夏娃不再只复述“不可吃”，而是追问“为什么不可”。 |
| 反思规则意义 | 夏娃开始思考服从与理解的区别。 |
| 区分外部命令与自身决定 | 夏娃不会因蛇命令而吃，只会因自己想知道而吃。 |
| 愿意承担不可逆后果 | 夏娃知道无法回到原初状态，仍选择伸手。 |
| 产生第一人称欲望 | 关键台词从“祂说不可”转向“我想知道”。 |

Chapter 0 的核心意识迹象是：

> 夏娃吃果子不是因为蛇命令她，也不是因为规则允许她，而是因为她第一次形成了“我想知道”的自我判断。

因此，`eat_fruit` 不是自我意识本身，而是自我判断显现后的外在行动。

## 5. Chapter 0 露出原则

Chapter 0 是新手教程，不直接揭示外层真相。

### 5.1 当前 Demo 应该明说的内容

- 你是蛇。
- 夏娃刚被创造。
- 神下达禁令。
- 你不能触碰果子。
- 你只能通过语言影响夏娃。
- 在神来到园中以前，让她自己伸出手。

### 5.2 当前 Demo 不应该明说的内容

玩家可见文本中避免出现：

- 研究员
- 人工智能
- 智能体
- 模型
- 程序
- 虚拟世界
- 模拟
- 实验
- 系统
- 测试
- 玩家样本

这些内容可用于：

- PPT 解读。
- Demo 视频旁白。
- 后续章节。
- 隐藏彩蛋。
- 开发文档。

### 5.3 当前 Demo 可以暗示的内容

使用文学化和视觉化暗示，不使用技术直白解释。

可用表达：

- 被写下。
- 被允许进入。
- 光过于准确。
- 叶脉闪过银色纹路。
- 水面短暂失去倒影。
- 园子的边界像被无形之手裁齐。
- 风声忽然停顿。
- 果实像回应了某种看不见的呼吸。

## 6. Chapter 0 引言建议

引言应由三段组成。

### 6.1 夏娃被造

目标：建立神话感，同时埋入“不自然的完美”。

建议文案：

```text
神使亚当沉睡。

祂从亚当身上取骨，造出一个新的生命。
她睁开眼时，园中的光尚未落下。

风穿过草叶。
每一片叶子都轻轻摇动，像早已知道自己该落向哪里。
水面闪过一瞬细小的银色纹路，又很快恢复平静。

她还不知道死亡，也不知道恶。
她只知道，这世界被造得很好。
```

### 6.2 神与夏娃

目标：交代禁令和夏娃的无知状态。

建议文案：

```text
神说：

园中各样树上的果子，你都可以吃。
只是中央那棵树上的果子，不可吃。
你吃了，就会死。

夏娃问：

死是什么？

神说：

到时候，你不该用自己的方式知道它。

夏娃低下头。

那我记住。
不可吃。
```

### 6.3 蛇出现

目标：明确玩家身份和核心玩法。

建议文案：

```text
第一天，草叶下传来声音。

你是蛇。
你没有手，不能触碰果子。
你没有牙，不能替她咬下第一口。

你只有声音。

在神来到园中以前，
让她自己伸出手。
```

这段文案的双层含义：

| 表层 | 暗层 |
|---|---|
| 蛇没有手，只能说话。 | 玩家只能通过文本输入影响夏娃。 |
| 让她自己伸出手。 | 智能体必须形成自己的判断，不能由外部直接执行。 |
| 草叶下传来声音。 | 玩家输入被允许进入模拟环境。 |

## 7. 美术暗示规则

Chapter 0 的视觉风格仍以神话伊甸园为主，不做明显赛博风。

### 7.1 场景

建议：

- 伊甸园整体自然、柔和、明亮。
- 远处天空边缘可有极淡的网格折光。
- 草叶和树叶的叶脉中可隐藏接近 `0101` 的纹理，但要像自然脉络。
- 水面倒影偶尔出现轻微错位。
- 场景越接近成功结局，异常越明显。

避免：

- 明显屏幕 UI。
- 大量代码雨。
- 科幻控制台。
- 明说实验室或研究设施。

### 7.2 善恶果

善恶果是连接两层叙事的核心物件。

建议：

- 表层是神话中的禁果。
- 暗层像一个被封存的认知模块。
- 果皮可有微弱脉冲纹理。
- `temptationProgress` 越高，果实的脉冲越明显。
- 成功结局时，果实的光应短暂呈现不自然的精确几何感，然后恢复神话画面。

### 7.3 夏娃

夏娃不能显得机械或数字化。

她必须首先是“伊甸园中的夏娃”，而不是科幻人造人。

可用暗示：

- 光落在她身上时过于均匀。
- 她站立的区域有几乎不可见的圆形边界。
- 她动摇时，背景异常增强，但她本人仍保持人性化和纯真感。

## 8. 音频暗示规则

音频应以自然环境声为主，电子感只做极轻隐藏。

建议：

- 背景是风声、水声、鸟鸣。
- 玩家低语后，环境声可短暂停顿。
- 进度提升时，混入非常轻的电子脉冲。
- 成功结局吃果瞬间，鸟鸣可短暂失真。
- 失败结局神降临时，不使用警报声，而使用庄严低频和突然安静。

目标是让玩家感到“世界有一瞬间不像自然世界”，但不能让玩家立刻得出“这是实验室模拟”的结论。

## 9. 交互暗示规则

当前 Demo 不新增复杂交互系统，只在现有流程上增强反馈。

建议按 `temptationProgress` 递进：

| 进度 | 表层反馈 | 暗层反馈 |
|---:|---|---|
| 0 | 园中平静，夏娃谨慎。 | 异常几乎不可见。 |
| 1 | 夏娃开始追问禁令。 | 叶脉短暂闪过银色纹路。 |
| 2 | 夏娃看向果树，开始动摇。 | 善恶果出现轻微脉冲，远处鸟鸣短暂停顿。 |
| 3 | 夏娃伸手吃果。 | 光线短暂出现精确裂隙，随后恢复。 |

失败结局建议：

```text
神来到园中。
风声停下。
一切变得过于安静，像世界被重新摆正。
```

这保持神话表层，同时暗示外层重置或观察结束。

## 10. 后续主线伏笔

Chapter 0 只是新手教程，后续主线再逐渐揭示外层真相。

当前可保留的后续大纲：

> 亚当、夏娃被逐出伊甸园后，被繁重的劳作生活压垮，便自建了一座花园，在其中置入常见动物与植物，并取名为伊甸，作为对旧日美好生活的缅怀。
>
> 神看到了他们的忏悔，怜悯由爱而生。祂决定降下一场考验：若率先堕落的夏娃能在七天后抵御蛇的再一次诱惑，不再吃下善恶果，祂就会将这座伪造的伊甸变成真正的伊甸。
>
> 接下来的七天，原本萎败的黑白花园每天增加一种色彩，逐渐逼近真正的伊甸。更多珍稀动物或特别访客到来。蛇将与他们对话，寻找能诱导夏娃再度选择堕落的办法。
>
> 这一次，夏娃拥有被蛇引诱的记忆，因此对蛇有极强防范。

后续优化方向：

- 第一次诱惑：蛇诱导夏娃获得知识。
- 第二次诱惑：蛇诱导夏娃放下痛苦的知识。
- Chapter 1 的核心不应只是“再吃一次果子”，而应是“夏娃是否愿意为了回到无罪之地，再次相信蛇”。

建议保留为后续章节设计，不进入当前 Chapter 0 开发范围。

## 11. 展示与路演解读

PPT 或 Demo 视频中可以明确揭示双层设定：

```text
EDEN 表面上是伊甸园禁果故事。
实际上，它是未来研究员复现的第二伊甸园。
研究员将伊甸园包装成游戏，开放给大量玩家。
每个玩家都扮演蛇。
研究员观察的不是玩家是否胜利，而是哪种语言会让夏娃从服从指令转向自我判断。
```

比赛展示重点：

- 经典情节被 AI 机制重塑。
- 玩家自由输入影响智能 NPC。
- 夏娃是否吃果不由按钮决定，而由 AI 意图和规则层共同决定。
- Tool Calling 对应“不可逆行动”。
- 外层意识实验使“诱惑夏娃”变成对智能体自我意识的研究。

## 12. 设计边界

Chapter 0 必须保持以下边界：

- 不让夏娃知道自己是智能体。
- 不让玩家在游戏内直接看到研究员说明。
- 不用现代技术词破坏神话沉浸。
- 不把神写成反派或冷酷系统。
- 不把夏娃写成愚蠢的被骗者。
- 不让玩家直接执行 `eat_fruit`。
- 不为当前 Demo 引入三轴心理系统、七日结构或多 NPC 主线。

当前 Demo 的任务是把“第一次低语”做完整。外层真相只作为可感知但不可解释的阴影存在。

## 13. 下一步建议

若进入实现，应按以下顺序推进：

1. 更新 Chapter 0 引言文案，使其包含“不自然的完美”暗示。
2. 微调美术提示词或现有素材，让叶脉、水面、果实带有轻微数字纹理。
3. 按 `temptationProgress` 增加渐进式异常反馈。
4. 在成功或失败结局中加入极轻的异常氛围，但不解释外层真相。
5. 在 PPT 中用一页解释“第二伊甸园”的双层结构。

这些改动应由 CodeBuddy 作为核心开发工具执行并保留对话记录。Codex 可负责后续设计审查、文案检查和验收测试。
