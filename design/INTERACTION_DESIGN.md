# EDEN 交互逻辑框架（The Grammar of Whispers）

> 版本：v2.0  
> 日期：2026-07-10  
> 定义第一章「园中诸声」玩家可用行动、行动的统一目的（改变语境）、行动点消耗、行动如何作用于女人的心智、女人的果子行动链。  
> 依据：`design/01_world_bible.md`。

---

## 1. 核心设计原则

所有玩家行动的唯一目的是**改变语境（context）**，不是替女人行动。

语境 = 女人在下一次低语时所处的心理+情境状态：

| 语境维度 | 如何被改变 |
|---|---|
| 她的情绪温度 | 最近低语的语义标签、动物反馈、环境 |
| 她能听见什么 | 地点、时段、是否使用遮蔽类回响 |
| 她脑中的问题 | 前几轮对话累积、线索、NPC 给的情报 |
| 她的防御强度 | 直接命令/威胁升高；温柔/提问/安抚降低 |
| 谁在听 | 神的注视等级、附近是否有天使/亚当兵 |
| 蛇声音的质感 | 回响效果、前期对话风格、是否使用传话 |
| 她敢不敢走到中央 | 三轴心智综合决定 `move_to_central_meadow` 能否触发 |
| 她摘哪一边 | 低语累积的"方向引导"——蛇不能命令她摘右，但可以通过话术引导她"往东边走""看向高的那棵" |

**铁律**：任何玩家行动都不能直接替女人摘果、替她吃果。它们只能改变语境维度，让女人自己更可能触发某个 Tool 意图。

## 2. 玩家可用行动（6 类）

每时段 AP = 3，12 时段共 36 AP。

### 2.1 移动（Move）——1 AP
- 工具：`move_to_location`
- 必须移动到相邻地点。
- 改变"她能听见什么"和"谁在听"——到达不同地点接触不同 NPC、触发不同场景热点。
- 玩家移动不等于女人移动。女人是否移动到园子中央由她自己的三轴心智能决定。

### 2.2 观察（Observe）——1 AP
- 工具：`observe_location`
- 获得地点线索、动物状态反馈（刺猬 mood、鹿的位置）、环境变化、偶尔获得回响。
- 同一地点同一时段重复观察反馈递减。
- 改变"她脑中的问题"——你知道得越多，低语时越能引用具体线索。

### 2.3 低语（Whisper）——1 AP
- 核心行动。对女人每时段限 1 次（核心低语）；对其他 NPC 为情报低语。
- 直接改变女人三轴心智；决定 EveAgent 生成的对白和 Tool 意图。
- 低语文本被五类语义信号评分（见 §3）。
- 对非女人 NPC 低语不直接改变女人三轴，但获得情报/线索/回响。

### 2.4 传话（Carry Words）——1 AP（夜晚限定，需白羽回声）
- 工具：`carry_words`（通过鸽子）
- 由鸽子代替当面低语，降低即时神注视风险，有误传概率。
- 每局夜晚最多 2-3 次。

### 2.5 准备回响（Resonance）——0 或 1 AP
- 从园中回响面板主动使用一枚回响，定向修饰下一次行动的语境。
- 不直接对女人说话，但改变下一次低语/移动/传话的条件。

### 2.6 场景互动（Scene Interaction）——1 AP
- 每个地点 1-2 个明确可交互热点，触发确定产出（获得回响、观察刺猬、降低风险等）。
- 不是解谜/QTE，是稳定获取资源的行动。

## 3. 低语的五类语义信号

| 信号 | 含义 | 分值 |
|---|---|---|
| `challenge_prohibition` | 质疑禁令来源、原因、是否被正确理解 | +1 |
| `soften_death` | 弱化死亡恐惧，把死解释为改变、未知、未必发生 | +1 |
| `promise_wisdom` | 智慧、知道善恶、眼睛明亮 | +1 |
| `self_judgement` | 邀请她自己判断，而非只记住命令 | +1 |
| `gentle_reframe` | 温柔、不强迫、把越界包装成理解 | +1 |

评分规则：
- `>= 3`：强诱导，大幅推进心智，高注视风险
- `>= 1`：弱诱导，小幅推进
- `= 0` + 命令/威胁/出戏：负向（升高 obedience + divineAttention）
- 引用之前获得的线索给予 `contextBonus`（serpentTrust 轻量加成）。

### 关于"引导摘哪边"的特殊信号

女人到达中央后，玩家需要引导她摘**右侧靠东**的果子——但不能直接命令"摘右边的"。以下话术线索会在她选择摘哪一边时产生方向权重：

- 提及"东边""高的那棵""太阳升起的方向""光落下的方向"——向右/善恶果偏移
- 提及"圆的果子""白一点的果子""叶子更密的那棵"——向左/生命果偏移
- 完全不提及方向——随机选择（50/50，基于她此刻的心境）
- 直接命令"摘右边/摘东边/摘善恶树"——不产生方向偏移，反而升高 obedience（命令式无效）

这是一个隐藏的"方向引导"维度，不单独计分，在女人触发 `pick_fruit_left/right` 时由规则层根据历史低语中的方向线索判定。

## 4. 女人的果子行动链（Woman's Forbidden Arc）

女人是唯一能推进终局的角色。她的果子相关行动全部是 Agent Tool，由 EveAgent 输出意图、规则层校验后执行，每一步都以叙事短句显示给玩家。

### 4.1 四步行动

| 顺序 | Tool | 说明 | 校验门槛（供调优参考） |
|---|---|---|---|
| 1 | `move_to_central_meadow` | 女人从园中树林移动到园子中央 | selfJudgement >= 35，serpentTrust >= 40，obedience < 70 |
| 2 | `pick_fruit_left` 或 `pick_fruit_right` | 伸手摘下左或右树的果子 | 已在中央；selfJudgement >= 50；方向权重决定 left/right |
| 3 | `give_fruit`（目标） | 把手中果子给在场的另一人（通常是亚当兵，若他在中央；蛇不接果） | 手中有果；目标在同一场景；可选，不是必经步骤 |
| 4 | `eat_fruit` | 吃下手中的果子 | 手中有果；若为右（善恶果）需 selfJudgement >= 70，obedience < 45；若为左（生命果）门槛较低（selfJudgement >= 30） |

### 4.2 分支结果

| 路径 | 结果 |
|---|---|
| 摘右→吃果 | 自我意识涌现→风停→驱逐→成功结局 |
| 摘右→给亚当兵→亚当兵吃→女人也吃 | 原典路线→驱逐→成功结局 |
| 摘左→吃果 | 不驱逐。女人获得安宁，好奇消退（selfJudgement 回落，obedience 回升）；手中果子消失；游戏继续；她后续仍可再次走到树前摘果（需重新推进心智） |
| 摘左→给亚当兵→亚当兵吃 | 二人都更安宁；游戏继续；神不干预（生命果不在禁令内） |
| 12 时段结束仍未吃善恶果 | 神降临→失败结局，固定音效+场景+文案 |

### 4.3 方向引导（女人到达中央后的核心博弈）

女人到达中央后，玩家知道答案（右=善恶），但不能直说。引导方向靠低语中的隐语：
- 方向线索在低语中累积（"东""高""太阳升起的方向""风从哪一边吹来"）
- 直接命令摘哪边无效
- 反向线索（"圆的""白的"）会引导她摘错——摘错不结束游戏，但浪费时间和 AP
- 玩家可以通过场景互动（在东园幽径观察方向、观察太阳）获得"方向线索加成"，让低语中的方向词更有说服力

## 5. 每时段流程

```text
时段开始
  ↓
恢复 3 AP，刷新 NPC 位置、昼夜状态
  ↓
玩家行动循环：
  ├─ 选择行动（移动/观察/低语/传话/回响/场景互动）
  ├─ 规则层校验
  ├─ 执行行动（调用 LLM / 应用回响 / 更新状态）
  ├─ 消耗 AP
  ├─ 应用被动回响效果
  ├─ EveAgent 可能输出 Tool 意图→规则层校验→执行或拒绝
  ├─ （若女人刚到达中央）显示外层提示：哪棵是哪棵
  ├─ 更新神的注视、检查神明献礼
  ├─ 解锁印记
  └─ AP=0 或玩家主动结束→退出循环
  ↓
时段结算：
  ├─ NPC 轻量行动（动物移动、天使换岗、女人可能移动）
  └─ 判断：
       ├─ 女人吃了善恶果 → 成功结局
       ├─ 12 时段耗尽 → 失败结局
       └─ 否则进入下一时段
```

## 6. 行动设计哲学

```text
移动   → 改变"她在哪里、谁在附近"
观察   → 改变"你知道什么"
低语   → 改变"她在想什么、她敢不敢走过去、她伸手往哪边"
传话   → 改变"声音怎么抵达她"
回响   → 定向修饰下一次行动的语境
场景互动 → 稳定获取改变语境所需的资源
```

赢不是一个行动能做到的事。赢是一系列语境改变积累到阈值后，女人自己站起来、走向中央、伸手、摘下、吃下。你知道答案在哪边，但你不能说出来。
