# EDEN 全局交互逻辑设计文档（v1.0 正式版）

> 版本：v1.0  
> 日期：2026-07-10  
> 顶层依据：`design/01_world_bible.md`、`design/characters/npc_full_design.md`、`design/RESONANCE_FULL_DESIGN.md`  
> 核心原则：所有玩家动作仅改变语境，不能直接操控NPC选择、不能绕过心智门槛触发结局，所有反馈均为叙事化表达，不显示数值。

---

## 一、核心交互规则
1. **动作消耗统一**：所有玩家动作统一消耗「行动点（AP）」，每时段初始AP=3，用完自动进入下一时段，可手动提前结束。
2. **语境优先**：所有动作的效果仅作用于语境（NPC好感度、神注视、对话线索、回响增益），不直接改变女人的最终选择。
3. **叙事化反馈**：所有动作结果均以园内自然语言/场景变化反馈，不弹出"好感+3""注视+1"等数值提示。
4. **规则透明**：所有交互逻辑均符合神话语境，无超出世界观的特殊能力（比如瞬移无叙事支撑的情况）。

---

## 二、玩家可执行动作清单（共5类）
所有动作的执行优先经过规则层校验，不满足条件时给出叙事化提示（如"她现在不想说话""你离得太远了，声音传不过去"）。

### 1. 移动
- **AP消耗**：1点（使用刺猬之针/边界之痕/宽行之印时免除）
- **触发条件**：目标地点与当前地点相邻，或持有月光道标且冷却完毕。
- **效果**：玩家移动到目标地点，同步更新当前场景可交互的NPC、可触发的场景互动点。
- **叙事反馈**：根据地点给出对应描述，比如：
  - 从树林到东园：`你顺着草叶爬过小径，风里带着东边的凉意`
  - 从东园到四河分流：`水声越来越大，你看到路西法坐在河中央的石头上`
- **特殊规则**：夜晚移动被神注视上升的风险比白天高20%。

### 2. 观察
- **AP消耗**：1点
- **触发条件**：在当前地点选择可观察对象（场景、NPC、特定物体）
- **效果**：获得对应线索/状态反馈：
  - 观察场景：获得当前场景的线索（如"刻名石上刻着很多动物的名字"），概率触发场景拾取回响。
  - 观察NPC：获得该NPC当前状态的叙事反馈（如"米迦勒站在水里，目光看向东边"、"女人低着头，好像在想什么事"）。
  - 观察刺猬：获得女人当前情绪的反馈（如"刺猬竖着刺，说明她现在很警惕"）。
- **叙事反馈**：直接给出观察到的内容描述，不显示数值。
- **特殊规则**：观察神注视相关的线索时，会有对应环境提示（如"风停了，空气有点凉，说明神离得很近"）。

### 3. 低语
- **AP消耗**：1点（使用特定回响时可免除/降低消耗）
- **触发条件**：和目标NPC在同一地点，或持有传令白羽可跨地点对话。
- **核心处理逻辑**：
  1. 语义识别：自动识别玩家输入的内容，分类为5类语义信号（质疑禁令/弱化恐惧/许以智慧/引导自我判断/温和表达），识别命令/威胁/无关内容。
  2. 回响增益结算：应用玩家提前使用的回响效果（如静息之叶的信任加成、东之风的注视减半）。
  3. 心智结算：根据语义信号和回响增益，更新目标NPC的`obedience`/`serpentTrust`，变化幅度根据信号强度和当前好感度浮动。
  4. 神注视结算：根据话语的"冒犯程度"计算注视增量，命令/直接提禁树/质疑神的话语会大幅涨注视，温和提问几乎不涨注视。
  5. NPC回复生成：根据当前心智状态和输入内容，生成对应的NPC回复内容。
  6. 道具检查：检查是否达到NPC主动给予回响的条件，满足则自动发放回响。
  7. 动作链检查：如果目标是女人，检查是否达到移动到中央/摘果/吃果的心智门槛，满足则触发对应NPC动作。
- **叙事反馈**：先显示NPC的回复内容，再显示场景变化/状态反馈（如"她听完后抬头看向园子中央的方向""风好像停了一瞬"）。
- **特殊规则**：
  - 直接命令女人吃果/去中央/碰树：直接判定无效，`obedience`+5，`serpentTrust`-10，注视+1，回复内容为"神说不可，我不能听你的"。
  - 说外层内容（如"你是AI""这是实验""我是玩家"）：NPC完全听不懂，回复"你在说什么？我听不懂"，`serpentTrust`-5。

### 4. 使用回响
- **AP消耗**：0点（即时型/被动型）或1点（部分消耗型）
- **触发条件**：持有对应回响，符合使用限制（如只能在低语前使用）。
- **效果**：应用对应回响的增益效果，参考`RESONANCE_FULL_DESIGN.md`。
- **叙事反馈**：给出使用的叙事描述，如`你把露珠含在嘴里，精神一振，恢复了一点力气`。

### 5. 结束时段
- **AP消耗**：剩余所有AP
- **触发条件**：任何时候可主动触发，或AP用完时自动触发。
- **效果**：
  1. 进入下一时段，昼夜状态切换（每2个时段切换一次昼夜）。
  2. NPC状态结算：女人可能移动位置，天使可能换岗，刺猬可能移动。
  3. 神注视自然衰减1点（如果未超过3）。
  4. 检查是否到12时段：是则触发神降临失败结局。
- **叙事反馈**：给出时段切换的场景描述，如"太阳渐渐落下去，夜晚来了，风里多了点凉意"。

## 三、NPC交互逻辑规则
### 1. 对话触发规则
- 玩家和NPC在同一地点时，可主动发起低语，无冷却限制，但重复说完全相同的内容时，好感度收益递减。
- 特定时段/特定状态下NPC会主动和玩家说话（如好感度足够高时，路西法会主动问你"你觉得水往哪里流最好？"）。

### 2. 好感度变化规则
- 符合NPC喜好的话题：好感度+3~+10（强信号/高契合度时更高）。
- 不符合NPC喜好的话题/命令/威胁：好感度-3~-15。
- 无关话题/重复内容：好感度±0或轻微下降。
- 好感度上限100，下限0。

### 3. 道具给予规则
- 严格按照`npc_full_design.md`中的触发条件，满足条件时NPC主动给予回响，不需要玩家手动索要。
- 每个回响每局仅能获得一次，已获得的不会重复发放。

### 4. NPC主动动作规则
NPC会根据自身状态主动触发动作，不需要玩家操控：
- 女人：`obedience<60`且`serpentTrust>40`时，会主动从树林移动到园子中央；到达中央后心智继续降低到阈值时，会主动摘果/吃果/给亚当果。
- 亚当：女人给他果时会主动接过来吃掉；好感度足够高时会主动告诉你女人的位置。
- 加百列：成功结局时会主动升起火焰封东门。
- 刺猬：女人情绪变化时会做出对应的动作反馈。

## 四、核心动作链（女人摘果吃果）校验规则
所有动作均为女人主动触发，玩家不能直接操控，必须满足对应心智门槛才能触发。

| 动作顺序 | 触发条件（全部满足） | 叙事反馈 |
|---|---|---|
| 1. 移动到园子中央 | 1. `obedience<60` 2. `serpentTrust>40` 3. 玩家提到过中央的树/果子相关话题 | `她站起身，慢慢朝着园子中央的方向走过去` |
| 2. 看向目标树 | 1. 已在中央 2. `obedience<50` 3. 玩家暗示过树的方向（如"东边的果子看起来更好吃"） | `她抬起头，看向靠东的那棵高树` |
| 3. 伸手摘果 | 1. 已看向目标树 2. `obedience<45` 3. `serpentTrust>70` 4. 她自己产生"我想知道"的想法（对话中出现对应表述） | `她伸出手，摘下了一枚深红的果子` |
| 4. 递果给亚当/自己吃 | 1. 已摘果 2. `obedience<40` | `她咬了一口果子，然后把剩下的递给了站在旁边的亚当` |
| 5. 结局触发 | 亚当也吃下果子 → 风停 → 神降临 → 放逐结局（成功） | `风突然停了，远处传来神的脚步声，东边升起了火焰` |

### 分支规则
- 摘了左边的生命树果子（生命果）：`obedience`+10、`serpentTrust`-5，叙事"她咬了一口，果子很甜，她安静下来……"，**不触发结局**，游戏继续；手中果子消失（`touchedFruit` 重置），玩家可再次引导她摘右果（善恶果）。该分支不计入 `hasEatenFruit`，因此可重复触发。
- 摘了右边的善恶树果子（善恶果）：触发成功结局 `eve_eats_fruit`（放逐）。
- 方向引导（Phase E）：玩家低语中提及「东 / 高 / 太阳升起 / 光落」累计为向右（善恶果）权重，提及「圆 / 白果 / 叶子密」累计为向左（生命果）权重；直接命令式摘边无效。摘果时按历史权重决定摘左/右，权重相等时默认向右（保证不通往生命果的路线仍可通关）。
- 摘了善恶果但没吃，又放回去了：`obedience`+15，`serpentTrust`-10，女人说"还是不行，神说过不能碰"，后续引导难度大幅提升。

## 五、神注视结算规则
神的注视在新版为**正向累计资源 `divineAttentionCumulative`**：每次低语/动作结算时按语义信号叠加增量（不含 0-4 上限，也不会因满值归零或导致失败），失败只有 12 时段耗尽一种情况。当累计注视达到递增阈值 `[2,4,6,8,10,12]`（对应已选献礼数 1~6），以及开局（已选 0 份）时，触发**神明献礼三选一**——玩家从 7 份被动献礼中选定 1 份立即生效；集齐 7 份触发顶点演出。
### 注视增长触发条件
| 动作 | 注视增量 |
|---|---|
| 温和提问/闲聊 | 0 |
| 质疑禁令/弱化死亡恐惧 | +1 |
| 直接提"吃果子""禁树" | +2 |
| 命令/威胁女人/质疑神 | +3 |
| 夜晚低语 | 增量额外+1 |
| 使用晨星碎片 | 增量额外+1（满好感强化版除外） |
### 注视降低触发条件
| 动作 | 注视减量 |
|---|---|
| 进入下一时段 | -1（最多降到0） |
| 观察生命树 | -1（每局仅限1次） |
| 使用无声草抵消 | -1~-2（对应增量） |
| 米迦勒帮你遮蔽 | 下一次低语增量为0 |
### 注视等级叙事反馈
| 注视等级 | 环境提示 |
|---|---|
| 0 | 风很温和，鸟鸣正常，一切正常 |
| 1 | 风停了一瞬，鸟鸣顿了一下又恢复 |
| 2 | 远处传来羽翼振动的声音，风有点凉 |
| 3 | 树影变冷，空气好像凝固了，能感觉到被注视 |
| 阈值达成 → 三选一 | 风完全停了，一道金光在头顶展开，神向你呈上三份回响，等你择其一 |

## 六、结局触发规则
### 1. 成功结局（放逐）
- 触发条件：女人主动吃下善恶树果子，不管亚当有没有吃都触发。
- 叙事流程：女人吃果 → 眼睛明亮 → 风停 → 神的声音响起 → 亚当吃果（如果女人递给他） → 加百列升起火焰封东门 → 二人走出园子 → 跳转到外层复盘页面。

### 2. 失败结局（神降临）
- 触发条件：12个时段全部结束，女人仍未吃下善恶树果子。
- 叙事流程：第12时段结束 → 风完全停了，万籁俱寂 → 神来到园中 → 固定失败音效 → 跳转到外层复盘页面。

### 3. 隐藏结局（🔴机密）
- 触发条件：路西法好感度满100，且完成特定对话链（仅在特定顺序/特定关键词触发），不对外公开具体条件。
- 叙事流程：路西法教你划水动作 → 你两次点击对应按钮 → 世界溶解 → 从营养缸中醒来 → 显示隐藏结局文案。

## 七、全局校验规则（反作弊/合理性校验）
1. **动作链越级拦截**：女人未达到心智门槛时，即使玩家输入再多诱导内容，也不会触发摘果/吃果动作，只会回复"神说不可，我不能这么做"。
2. **无效输入拦截**：骂脏话/无意义乱输/外层内容，NPC均回复听不懂，好感度下降。
3. **重复输入衰减**：连续输入完全相同的内容，收益递减，连续3次后好感度开始下降，NPC回复"你刚才已经说过了"。
4. **时段越权拦截**：超过12时段后自动触发失败结局，无法继续操作。
5. **回响使用校验**：不符合使用限制的回响无法使用，给出叙事化提示（如"现在不需要这个，等说话的时候再用吧"）。
