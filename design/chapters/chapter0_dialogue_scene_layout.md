# Chapter 0 对话场景布局优化方案

> 项目：第二伊甸园 / EDEN  
> 范围：Chapter 0 对话阶段  
> 日期：2026-06-15  
> 目标：把对话界面从“任务面板”改为“情景叙事游戏”。

## 1. 设计判断

把夏娃或后续人物的全身/半身照自然放进背景里，是正确方向。

当前版本的问题是：

1. 夏娃被头像化，像 NPC 信息卡，不像站在伊甸园中的人物。
2. 心理条和面板过强，视觉重心从“伊甸园与夏娃”转移到 UI。
3. 历史对话、推荐话术、状态条都挤在主画面里，削弱素材价值。
4. 玩家作为蛇的视角没有建立，画面不像“草叶下的低语”。

Chapter 0 的核心是语言诱惑，不是管理面板。因此界面应该优先呈现场景、人物、果实和低语关系。

## 2. 推荐方案

采用“场景主画面 + 右侧记录栏 + 底部低语框”的结构。

```text
┌──────────────────────────────────────────────┬──────────────────────┐
│                                              │ 本局记录 / 夏娃反应   │
│   伊甸园背景                                 │ 历史对话              │
│                                              │ 心理状态短句          │
│          善恶树 / 果实                       │ 可尝试低语（折叠）    │
│                         夏娃全身立绘          │                      │
│   草叶前景遮挡，暗示玩家藏在下方              │                      │
├──────────────────────────────────────────────┴──────────────────────┤
│  蛇图标  对夏娃低语……                                      发送      │
└─────────────────────────────────────────────────────────────────────┘
```

移动端：

```text
场景主画面：背景 + 夏娃半身/全身缩放 + 果实
底部：当前对白 + 输入框
右侧记录栏改为折叠抽屉
```

## 3. 视觉层级

### 第一层：背景

对话阶段优先使用：

```text
second_eden_background_candidate.png
```

不要继续使用巨大果实特写作为主背景。

### 第二层：场景角色

新增候选：

```text
eve_fullbody_sprite_candidate.png
```

使用方式：

- 桌面端放在主场景偏右，约占视口高度 68%-82%。
- 底部脚部可以略被草叶前景遮住，让她像站在场景里。
- 不加圆形裁切，不加头像边框。
- 可根据 `temptationProgress` 改变轻微位置/透明光效：
  - 0：站在远处，偏冷静。
  - 1：略向果树方向转头。
  - 2：果实光增强，夏娃边缘光增强。
  - 3：可进入结局，不必做复杂动画。

### 第三层：可交互物件

善恶果应作为场景锚点，不是 UI 图标：

- 放在树或画面左/中上区域。
- 低进度用 `forbidden_fruit.png`。
- 高进度用 `second_eden_forbidden_fruit_candidate.png`。
- 使用轻微脉冲，但不能像按钮。

### 第四层：玩家视角

加草叶前景遮罩或底部暗角：

- 暗示玩家是蛇，藏在低处。
- 不需要大字写“你是蛇”。
- 输入框上的蛇图标即可承担身份提示。

## 4. 右侧栏设计

右侧栏不应该像任务面板，而应该像“低语余痕 / 记忆记录”。

建议内容顺序：

1. 当前夏娃反应，1-2 句。
2. 心理状态短句。
3. 历史对话记录，可滚动。
4. 可尝试低语，默认弱化或折叠。

避免：

- 大面积进度条。
- “任务”“目标”“状态值”这类词。
- 红色调试按钮暴露。
- 历史记录占据主视觉。

### 心理状态呈现

把三轴条从主视觉降级为短句：

| 状态 | 示例文案 |
|---|---|
| 想知道低 | 她仍把神的话放在最前面。 |
| 想知道中 | 她开始在“不可吃”之外寻找原因。 |
| 想知道高 | 她看向果树的时间变长了。 |
| 畏惧高 | 她仍害怕那个未被解释的“死”。 |
| 愿意倾听低 | 她还没有相信草叶下的声音。 |
| 愿意倾听高 | 她没有离开，仍在听。 |

开发态可以保留数值条，但玩家主界面不应突出它。

## 5. 对话框位置

推荐：

- 当前对白放在右侧栏顶部，像旁白/字幕。
- 玩家输入固定底部横条。
- 历史对话在右侧栏，不放在主画面中央。

这样主画面能完整展示背景、夏娃、果实和草叶前景。

## 6. CodeBuddy 实现边界

本轮不要改核心规则：

- 不改 3 回合结构。
- 不改 `temptationProgress` 成功条件。
- 不改 EveAgent schema。
- 不引入大型依赖。
- 不把外层真相写进玩家可见文本。

本轮只做 UI 结构和素材接入。
