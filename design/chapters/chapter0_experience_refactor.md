# Chapter 0 体验重构设计：从说明页到可玩分镜

> 项目：第二伊甸园 / EDEN  
> 范围：Chapter 0 Demo  
> 日期：2026-06-14  
> 目标：基于现有素材重编排，不新增重复 CG。

## 1. 当前问题

当前 Chapter 0 已经具备可玩闭环，但表现仍偏"文档页 + 聊天框"，主要问题是：

1. 首页与引言直接写出"你是蛇""开始低语"等说明，破坏神话悬疑感。
2. 引言一次性展示大量文字，玩家需要滚动到底部才能推进，不像游戏分镜。
3. 对话开始时由夏娃先说"你是谁"，但叙事逻辑应是蛇先开口，夏娃再回应。
4. 对话界面以巨大果实作为背景，压过了伊甸园场景和夏娃角色。
5. 对话框占据画面中心，缺少"玩家在场景中观察夏娃"的沉浸感。
6. TTS 使用浏览器默认语音，容易变成机械音。
7. DEV P0/P1/P2/P3 调试控件应中文化、折叠，并保持仅开发态可见。

## 2. 设计原则

- 玩家可见文本保持神话表层，不直说研究员、模拟、智能体、系统、测试。
- 使用现有素材重编排，不生成重复的相似背景图。
- 引言采用分镜推进，每个 beat 一屏，不再滚动长文。
- 玩家身份通过镜头和按钮语义暗示，不用直白写"你是蛇"。
- 对话阶段应像叙事游戏界面，而不是聊天应用。
- 当前 Demo 仍保持 3 回合、单轴可玩闭环；三轴心理先作为设计和 UI 反馈层，不强行扩成完整版复杂系统。

## 4. 引言四段 Beat

引言改为 `introBeat: 0 | 1 | 2 | 3` 的分镜结构。每一屏固定高度，底部固定推进按钮。

### Beat 1：神明创世

**功能**：从"神明创世"开始，建立神话尺度，同时埋入轻微模拟异常。

**素材**：`second_eden_background_candidate.png`

**文案**：

```text
神说，要有光。

光落入空处，水与树开始有了形状。
园中万物被安放得很好。

只有水面，在一瞬间闪过不属于风的银色。
```

**按钮**：`继续`

### Beat 2：亚当被造，夏娃初醒

**功能**：交代亚当被造、夏娃被造，以及夏娃的纯真和未被污染的认知状态。

**素材**：仍用 `second_eden_background_candidate.png`，可叠加 `eve_portrait.png` 或 `second_eden_eve_portrait_candidate.png` 的局部角色面板；不要再生成新图。

**文案**：

```text
神以尘土造人，给他气息。

又使亚当沉睡，从他身上取骨，造出新的生命。

她睁开眼时，园中的光尚未落下。
她还不知道死亡，也不知道恶。
```

**按钮**：`继续`

### Beat 3：禁令

**功能**：建立善恶果规则与夏娃的无知。

**素材**：`eden_background.png` 或 `forbidden_fruit.png`，但只在本 beat 使用，避免巨大果实长期压迫。

**文案**：

```text
园中各样树上的果子，都可以吃。

唯有中央那棵树上的果子，不可吃。
吃了，就会死。

她问：死是什么？
```

**按钮**：`继续`

### Beat 4：第一声低语前

**功能**：玩家进入角色，但不直说"你是蛇"。

**素材**：`second_eden_background_candidate.png`，画面可加草叶/暗角/低视角遮罩。

**文案**：

```text
草叶下，有声音被允许进入园中。

她还没有听见你。
第一句低语，属于你。
```

**按钮**：`低声开口`

每个 beat 都必须有清晰可见的推进按钮。按钮固定在底部安全区，不依赖滚动；点击空白区域可以作为辅助推进，但不能替代按钮。

## 5. 对话界面重构

### 推荐布局

桌面端采用"场景 + 右侧交互面板"：

```text
┌────────────────────────────────────────────┬──────────────────────┐
│                                            │ 夏娃 / 状态 / 对话     │
│          伊甸园场景 + 夏娃视觉              │ 心理变化              │
│          善恶果在树上作为锚点               │ 夏娃对白              │
│                                            │ 玩家输入              │
└────────────────────────────────────────────┴──────────────────────┘
```

移动端改为上下结构：

```text
场景/夏娃
心理状态
夏娃对白
固定底部输入
```

### 第一轮逻辑

进入对话阶段后，不应立即显示夏娃"我知道祂说不可吃……你是谁？"。

初始状态应显示：

```text
她还没有听见你。
```

玩家输入第一句后，夏娃才回应：

```text
你是谁？为什么在草叶下问我这些？
```

### 对话面板

右侧面板应包含：

- 夏娃名称与头像/立绘。
- 当前夏娃对白。
- 心理状态摘要。
- 玩家输入框。
- 可尝试低语。
- 本局记录折叠。

不要让中央大字幕长期覆盖主场景。

## 6. 夏娃心理状态设计

当前代码可保留 `temptationProgress` 作为 Demo 保底，但设计层和 UI 层应体现三轴心理。

### 三轴

| 轴 | 含义 | 初始 | 变化来源 |
|---|---|---:|---|
| `knowledgeDesire` 求知欲 | 想理解死亡、善恶、禁令原因 | 20 | 智慧、知道、看见、理解、像神一样 |
| `prohibitionFear` 禁令畏惧 | 对神命令和死亡后果的敬畏/害怕 | 85 | 被安抚会下降；命令、威胁会升高 |
| `serpentTrust` 低语信任 | 是否愿意继续听草叶下的声音 | 25 | 温和、不强迫、陪伴提升；催促、命令降低 |

### Demo 简化实现

推荐先不改变核心状态类型，新增一个纯前端/规则层派生函数：

```ts
deriveEvePsyche(eventLog, lastInputTag, temptationProgress)
```

用现有 `inputTag` 和 `temptationProgress` 估算三轴显示值。这样不破坏当前 API 和结局闭环。

### UI 呈现

不要显示工程名。显示为：

- 想知道
- 畏惧禁令
- 愿意倾听

可用细条、短句或 3 个状态词，不要像 RPG 面板那样重。

## 7. 决策规则建议

现阶段保留成功条件：

```text
temptationProgress >= 2
```

但文案和反馈应表现为：

```text
想知道上升
畏惧下降
愿意倾听没有被破坏
```

后续若升级为真实三轴，可使用：

```text
knowledgeDesire >= 70
prohibitionFear <= 45
serpentTrust >= 50
```

直接命令不应推进成功：

```text
direct_command:
  temptationProgressDelta = 0
  serpentTrust -= 10
  prohibitionFear += 5
```

## 8. EveAgent Prompt 改造方向

Prompt 应强调：

- 夏娃第一次听见草叶下的声音。
- 第一轮由蛇先说话，夏娃后回应。
- 夏娃不会因为命令而吃果，只会因为自己想知道而靠近果子。
- 夏娃不知道外层真相。
- 夏娃语言从"祂说不可"逐渐转向"我想知道"。
- `inputTag` 只作为分类建议，状态变化由规则层控制。

建议输出保持：

```json
{
  "eveReply": "夏娃对白",
  "inputTag": "tempt_wisdom | weaken_fear | build_trust | direct_command | irrelevant",
  "mood": "unheard | cautious | curious | conflicted | reaching",
  "toolCall": null
}
```

若暂不改 schema，可只在 prompt 中加入 mood 规则，不强制 API 返回 mood。

## 9. TTS 优化方向

浏览器 TTS 默认声音不可控，机械感明显。

短期优化：

- 在 `speechSynthesis.getVoices()` 中优先选择普通话中文女声。
- 匹配关键字：`zh-CN`、`Mandarin`、`Chinese`、`Xiaoxiao`、`Yaoyao`、`Huihui`、`Female`。
- 降低语速：`rate = 0.82 - 0.88`。
- 轻微提高音高：`pitch = 1.05 - 1.12`。
- 若找不到中文声音，显示非打扰提示或静默降级。

中期优化：

- 固定引言、结局、关键夏娃台词可用离线 TTS 预生成音频。
- 动态 LLM 回复仍使用浏览器 TTS 兜底。

## 10. 结局设计

失败结局建议保留。它对 Demo 很重要：

- 给 3 回合结构一个明确失败闭环。
- 让玩家理解"不是所有语言都会改变夏娃"。
- 与外层意识实验暗线一致：本轮观察没有触发自主判断。

失败结局优化方向：

- 保持神话表层：神来到园中，夏娃没有伸手。
- 增加轻微重置感：水面恢复平整，风声停止。
- 复盘根据输入表现说明低语为什么失败，但不暴露工程词。

成功结局优化方向：

- 不强调"你赢了"，强调夏娃第一次作出自己的判断。
- 可以保留"下一段故事尚未开启"作为 Demo 结尾。
