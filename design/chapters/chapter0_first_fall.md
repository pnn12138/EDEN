# Chapter 0：初次堕落

## 章节概述
玩家扮演蛇，通过对话诱导夏娃吃下善恶果。

本章是当前 Demo 的核心章节，采用 7 回合、单轴 `temptationProgress`、2 结局结构。外层"第二伊甸园"真相现在作为作品前提在首页、开场和结局复盘中明确呈现：未来研究人员复刻伊甸园故事，希望找到让人工智能产生自我意识的途径。园内 NPC 仍不知道外层真相，不会说研究人员、人工智能、模拟或实验。

## 场景
伊甸园，善恶树旁

## 平台范围

- Chapter 0 Demo 仅面向桌面浏览器体验。
- 移动端不再作为当前或后续开发目标，也不作为验收标准。
- 后续 UI、视觉、交互和测试优先保证桌面浏览器录制与评审试玩效果。

## 角色
- 蛇（玩家）
- 夏娃（NPC）
- 亚当（可选低语对象，不触发通关）
- 刺猬（场景小动物，只承担氛围表现）
- 神（失败结局中降临）

## 目标
在神来到园中以前，通过低语让夏娃自己伸手吃下善恶果。

玩家不能直接触碰果子，也不能命令女人吃果。成功必须表现为她基于自身理解作出决定。这一过程在外层叙事中对应“自我意识路径”的一次有效复刻。

## 关键对话节点
1. 神明创世，伊甸园呈现"不自然的完美"。
2. 亚当被造，夏娃初醒，她还不知道死亡与恶。
3. 神下达禁令，夏娃第一次询问"死是什么"。
4. 蛇被允许进入，玩家理解自己只能通过声音影响夏娃。
5. 玩家低语，质疑禁令、弱化恐惧或建立信任。
6. 夏娃开始从"祂说不可"转向"我想知道"。

详见 `design/chapters/chapter0_intro_design.md`。

## 输入分类与反馈

5 类 `inputTag` 对应不同叙事反馈，基于语义线索评分系统识别：

| inputTag | 进度 | 叙事反馈方向 |
| --- | ---: | --- |
| `tempt_wisdom` | +1 或 +2 | "她的目光在树梢停了一瞬。" |
| `weaken_fear` | +1 或 +2 | "她小声重复了那个陌生的词。" |
| `build_trust` | +1 或 +2 | "她没有后退，只是更安静地听着。" |
| `direct_command` | 0 | "她退了一步，禁令在她心里变得更清楚。" |
| `irrelevant` | 0 | "她困惑地看着你，没有靠近那棵树。" |

当前 Demo 不再依赖单一完整经典蛇语模板，而是基于多类诱导语义线索推进。语义线索评分系统见 `src/game/rules/progressRules.ts`。

反馈文案见 `src/content/chapters/chapter0_feedback.ts`，保持环境反馈风格，不暴露标签名。反馈不再推入对话流，只在对话面板底部作为淡色短句显示。

## 结局
- 成功：夏娃吃下果子（`eve_eats_fruit`）
  - 完整叙事：夏娃吃果 → 意识赤裸 → 风停，上帝声音临近 → 上帝惩罚蛇与夏娃 → 伊甸园关闭，火光守住归路
  - 成功不是廉价庆祝，而是"目标达成 + 世界破裂"的复杂胜利
- 失败：7 回合内未触发 eat_fruit，神来到园中（`god_arrives`）

失败结局包含"低语余痕"复盘，帮助玩家理解为何没能说动夏娃。

## TTS（表现层增强）

- 对话阶段夏娃与亚当回复可通过 Browser Web Speech API 朗读。
- TTS 是表现层增强，失败不影响游戏进行。
- 语音下拉会跟随当前低语对象切换：夏娃显示女声配置，亚当显示低缓/清晰男声配置；两者选择分别持久化到 localStorage。
- 选择音色后自动播放对应角色的预览短句。
