# 开场白设计（v1.0）

> 版本：v1.0  
> 日期：2026-07-10  
> 首页：直白、游戏化，交代"模拟人类第一次背离神指令"的前提。  
> 过场：逐页翻页，4-5页，每页一段，从外层切入内层。

---

## 1. 首页文案

```
EDEN
第二伊甸园

这个地方被建来模拟一件事——
人类第一次背离神的指令。

园子里有一个女人。
她不知道自己在被观察。
她只知道神说：不可吃。

你是蛇。
你不能替她伸手。
你只能说话。

让她自己走向那棵树。

[进入园子]
```

风格：直接、不隐晦、不卖关子。玩家打开页面就知道自己来干什么。

## 2. 过场文案（逐页翻页，4页）

### 第1页：清晨

```
清晨。

露水还在叶子上。
河从东方流出，分成四道。

亚当已经在这里了。
他给百兽起了名字，
领受了禁令。
神说：园中各样树上的果子都可以吃，
只是分别善恶树上的果子不可吃。
吃的日子，必定死。

女人刚被造出来。
她醒来不到几个黎明。
```

### 第2页：禁令

```
亚当把禁令告诉了女人。
他加了一句：也不可摸。
但他没指给她看，是哪一棵。

园子中央有两棵树并肩站着。
没有人分得清。

女人见过花落，见过叶枯，
见过小动物变冷。
她知道死是什么样子。
但她还不知道——死，会不会发生在自己身上。

两棵树，她都不敢碰。
```

### 第3页：蛇

```
你是蛇。

你不属于这里。
亚当没有给你起过名字。
你不在园子的秩序里。

你没有手，不能替她摘果子。
你没有牙，不能替她咬下第一口。

你只有声音。

风穿过草叶。
她还没有走过去。
```

### 第4页：进入

```
在神来到园中以前，
让她自己伸出手。

第一句低语，
会决定她看向你，
还是看向禁令。

[进入伊甸园]
```

## 3. 翻页交互

- 每页一段文案，底部显示"→"或点击翻页
- 背景：伊甸园清晨全景图，每页微调（光线变化、草叶摇动）
- 第3页出现蛇的剪影或草丛低视角
- 第4页出现"进入伊甸园"按钮
- 不播放音频，不加外层电子暗示

---

## 4. 开场白写完后自动跳转

- 首次进入 `/world` 时播放开场白，`localStorage` 记录已看过
- 再次进入跳过开场白，直接到游戏
- `/prologue` 页改为免责声明页（现有内容保留），不混入叙事
