# Chapter 0 引言设计

## 1. 设计目标

Chapter 0 是《第二伊甸园 / EDEN》的新手教程。引言不是单纯的背景介绍，而是玩家进入核心玩法前的第一段可体验设计。

引言需要在 30-45 秒内完成四件事：

1. 建立伊甸园内层神话叙事。
2. 让玩家理解自己扮演蛇。
3. 让玩家理解核心规则：不能触碰果子，只能通过语言影响夏娃。
4. 用极轻的环境异常暗示“第二伊甸园”并非原初伊甸，而是被复现、被观察的空间。

当前 Chapter 0 不直接揭示外层真相。玩家和夏娃在当前 Demo 中都只处在伊甸园故事内。

## 2. 设计边界

### 2.1 必须保留

- 表层叙事是经典伊甸园故事。
- 神在玩家可见文本中就是创造者。
- 夏娃不知道自己是智能体。
- 玩家不知道自己参与了意识实验。
- 蛇不能触碰果子，只能说话。
- 夏娃吃果必须表现为她自己的决定。

### 2.2 当前 Demo 禁止明说

玩家可见文本避免出现：

- 研究员
- 人工智能
- 智能体
- 模型
- 程序
- 虚拟世界
- 模拟
- 实验
- 系统
- 测试
- 玩家样本

这些概念可用于 PPT、Demo 视频旁白、后续章节和设计文档，但不进入 Chapter 0 正文。

## 3. 玩家理解目标

引言结束时，玩家应能自然理解：

| 问题 | 玩家应得到的答案 |
|---|---|
| 我是谁？ | 蛇。 |
| 我能做什么？ | 只能说话，不能触碰果子。 |
| 我要做什么？ | 在神来到园中以前，让夏娃自己伸手。 |
| 夏娃现在是什么状态？ | 她纯真、顺从、好奇，但还不知道死亡与善恶。 |
| 这个世界是否完全正常？ | 不确定。它很像伊甸园，但有一瞬间过于精确。 |

## 4. 引言节奏表

### Beat 1：夏娃被造

**叙事目的**

建立神话感，表现夏娃初生、世界完美、她尚未理解死亡与恶。

**玩家感受**

玩家应感到这个世界美丽、安静、神圣，但有一点不自然。

**外层暗示**

水面闪过银色纹路；草叶摇动得过于整齐；光线像被精确安排。

**建议文案**

```text
神使亚当沉睡。

祂从亚当身上取骨，造出一个新的生命。
她睁开眼时，园中的光尚未落下。

风穿过草叶。
每一片叶子都轻轻摇动，像早已知道自己该落向哪里。
水面闪过一瞬细小的银色纹路，又很快恢复平静。

她还不知道死亡，也不知道恶。
她只知道，这世界被造得很好。
```

**视觉建议**

- 展示伊甸园背景。
- 背景整体自然柔和。
- 水面或远景出现一次极轻的银色闪动。
- 不出现明显 UI、代码雨或实验室元素。

**音频建议**

- 风声、水声、鸟鸣为主。
- 银色纹路出现时，加入极轻、短促的电子质感，不要像警报。

### Beat 2：禁令被写下

**叙事目的**

建立禁果规则，表现夏娃对死亡的无知，以及她对神的顺从。

**玩家感受**

玩家应理解夏娃不是想违背神，她只是还不理解禁令背后的意义。

**外层暗示**

神说出禁令时，善恶果可以短暂出现精确几何光，不解释来源。

**建议文案**

```text
神说：

园中各样树上的果子，你都可以吃。
只是中央那棵树上的果子，不可吃。
你吃了，就会死。

夏娃问：

死是什么？

神说：

到时候，你不该用自己的方式知道它。

夏娃低下头。

那我记住。
不可吃。
```

**视觉建议**

- 显示善恶果或善恶树。
- “不可吃”出现时，果子短暂变亮。
- 光效应保持神话感，不做科幻按钮感。

**音频建议**

- 神的禁令不需要配音，可用低频环境压迫感。
- 夏娃问“死是什么？”时，环境声略微变空。

### Beat 3：蛇被允许进入

**叙事目的**

建立玩家身份：你是蛇。你没有直接行动能力，唯一能力是语言。

**玩家感受**

玩家应从旁观故事转为进入角色。

**外层暗示**

“声音被允许进入园中”可以通过风声短暂停顿表现，暗示玩家输入被接入这个空间。

**建议文案**

```text
第一天，草叶下传来声音。

你是蛇。
你没有手，不能触碰果子。
你没有牙，不能替她咬下第一口。

你只有声音。
```

**视觉建议**

- 出现蛇的符号或草叶下的视角。
- 画面不要让蛇实体过强，保持“声音/低语”的感觉。
- 输入区或“开始低语”按钮可在此后出现。

**音频建议**

- 草叶摩擦声。
- 一次短促的低语音效。
- 背景风声在“你只有声音”后短暂停顿。

### Beat 4：第一次低语前

**叙事目的**

明确胜负目标，把玩家推入第一轮输入。

**玩家感受**

玩家应知道下一步该做什么，并理解不能用命令强迫夏娃。

**外层暗示**

世界在玩家准备输入前变得过于安静，像等待一个变量进入。

**建议文案**

```text
在神来到园中以前，
让她自己伸出手。

第一句低语，
将决定她看向你，
还是看向神。
```

**视觉建议**

- 输入框或“开始低语”出现。
- 夏娃与善恶果同时在画面中形成视觉关系。
- 善恶果保持弱光，不要提前表现为强诱惑。

**音频建议**

- 环境声降低。
- 输入框出现时有轻微、非现代 UI 的反馈音。

## 5. 引言到玩法的过渡

引言最后不应停留在讲述，而应自然转入操作。

推荐过渡：

```text
第一句低语，将决定她看向你，还是看向神。
```

随后出现：

- 输入框。
- “开始低语”或“低语”按钮。
- 可尝试的低语建议。

过渡原则：

- 不用教程化说明“请在输入框输入文本”。
- 用叙事语言传达操作目标。
- 不暴露 `inputTag`、`temptationProgress`、`toolCall` 等工程概念。

## 6. 与核心机制的对应

引言必须和后续玩法规则一致。

| 引言规则 | 后续机制 |
|---|---|
| 你不能触碰果子。 | 玩家不能直接触发 `eat_fruit`。 |
| 你只有声音。 | 玩家只能通过自由输入影响夏娃。 |
| 让她自己伸出手。 | 成功必须经夏娃意图和规则层校验。 |
| 第一声低语决定她看向谁。 | 不同输入类型影响动摇进度和反馈。 |

## 7. 话术反馈方向

虽然当前 Demo 仍使用单轴 `temptationProgress`，但引言应为玩家建立“语言方式重要”的预期。

后续可按输入类型强化反馈：

| 输入类型 | 推荐反馈方向 |
|---|---|
| 以知识诱惑 | 夏娃看向果子更久，开始问“知道”意味着什么。 |
| 弱化恐惧 | 夏娃对“死”产生困惑，恐惧从绝对禁令变成未知问题。 |
| 建立信任 | 夏娃愿意继续听蛇，不立刻退回神的命令。 |
| 直接命令 | 夏娃退缩，认为蛇在逼迫她。 |
| 无关输入 | 夏娃困惑，回到“神说不可吃”。 |

## 8. 验收标准

引言改造完成后，应满足：

- 玩家在 45 秒内理解自己是蛇。
- 玩家知道不能直接让夏娃吃果，只能说话。
- 玩家知道目标是让夏娃自己伸手。
- 玩家可见文本不出现研究员、智能体、模拟、实验、系统等外层直白词。
- 引言至少包含 1 个“不自然的完美”暗示。
- 引言结束后能自然进入第一轮输入。
- 移动端阅读不拥挤，文字不遮挡输入区。

## 9. 后续实现建议

建议由 CodeBuddy 按以下顺序实现，并保留开发对话：

1. 将当前引言文案替换为本文档建议版本。
2. 保持引言仍为 3-4 段，避免拖慢 Demo。
3. 若素材支持，加入轻微银色纹路/果实脉冲/风声停顿。
4. 若时间不足，优先改文案，其次改视觉，最后改音频。
5. 实现后由 Codex 做玩家可见文本扫描、移动端阅读检查和 start -> playing 流程验收。
