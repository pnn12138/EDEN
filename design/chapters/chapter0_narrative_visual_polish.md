# Chapter 0 叙事与视觉精修方案

> 项目：第二伊甸园 / EDEN  
> 范围：Chapter 0 Demo  
> 日期：2026-06-15  
> 目标：让引言更接近《创世纪》神话叙事，让玩法界面更像叙事游戏而不是任务面板。

## 1. 当前问题判断

当前版本已经能玩，但表现仍粗糙：

1. 引言文案像概述，不像《创世纪》的开场。  
   "神说，要有光"之后立刻写"水与树开始有了形状"，跳过了神话文本的庄严节奏。
2. Beat 1 没有专属创世视觉。  
   用已经完成的伊甸园背景表现创世，会让玩家觉得世界一开始就存在。
3. Beat 2 的夏娃头像处理太像角色卡。  
   圆形头像悬在画面中央，像资料页，不像"亚当沉睡、夏娃初醒"的镜头。
4. 对话界面仍然偏"状态面板 + 任务 UI"。  
   夏娃被头像化，心理条太工具化，画面没有形成"玩家潜伏在草叶下观察夏娃"的空间关系。
5. "背景 + 任务"的表达太直白。  
   游戏目标应该由镜头、台词和操作自然传达，而不是靠面板告诉玩家。

## 2. 总体优化方向

推荐采用"圣经表层叙事 + 镜头化暗示"的方式：

- 表层文案尽量贴近《创世纪》语气，但不大段照搬。
- 每个 Beat 对应一个明确事件，而不是抽象情绪。
- 外层"第二伊甸园"只藏在光、水、边界、叶脉、声音停顿里。
- UI 从"任务栏"转向"观察场景 + 低语输入 + 夏娃反应"。
- 心理数值不取消，但弱化为环境和姿态反馈，避免像 RPG 数值面板。

## 3. 引言 Beat 重写

### Beat 1：光被造

**叙事目的**：以《创世纪》开场建立神话尺度，说明这不是普通花园开场。

**建议素材**：`genesis_creation_light_candidate.png`

**建议文案**：

```text
起初，地是空虚混沌，渊面黑暗。

神说：要有光。
于是有了光。

神看光是好的，便把光暗分开。

在水面最深处，
有一道银色的纹路比晨光更早醒来。
```

**暗线处理**：只让"银色纹路"出现，不解释它是什么。

### Beat 2：园被安置

**叙事目的**：从创世过渡到伊甸园，而不是让伊甸园一开始就存在。

**建议素材**：`second_eden_background_candidate.png`

**建议文案**：

```text
神在东方立了一个园子，名叫伊甸。

祂使各样的树从地里长出来，
可以悦人的眼目，也可以作食物。

园中有生命树，
也有分别善恶的树。

风经过树梢时，
每一片叶子的颤动都整齐得近乎安静。
```

**暗线处理**：用"整齐得近乎安静"暗示被复现的自然。

### Beat 3：亚当与夏娃

**叙事目的**：交代亚当被造、夏娃被造，但不要把夏娃做成头像卡片。

**建议素材**：先复用 `second_eden_background_candidate.png`，不要继续用圆形头像作为主表现；若后续生成新图，应是"亚当沉睡、夏娃初醒"的 16:9 场景 CG。

**建议文案**：

```text
神用地上的尘土造人，
将生命的气息吹在他鼻孔里。

后来，神使那人沉睡。
祂取下他的一根肋骨，造出女人，领她到那人面前。

她睁开眼时，
还不知道死亡，也不知道恶。
```

**暗线处理**：这一 Beat 不需要强行加技术暗示，保持纯净。

### Beat 4：禁令与第一声低语

**叙事目的**：把禁令和玩法目标自然接到一起。

**建议素材**：可短暂使用 `eden_background.png` 或果实局部，但对话阶段不要继续用巨大果实做背景。

**建议文案**：

```text
神吩咐那人说：

园中各样树上的果子，你可以随意吃。
只是分别善恶树上的果子，你不可吃。
因为你吃的日子必定死。

草叶下，有声音靠近。

你不能替她伸手。
你只能让她开始发问。
```

**按钮**：`低声开口`

说明：这里可以明确"你"的限制，但不必大字写"你是蛇"。玩家会从草叶视角、蛇图标、输入区自然理解身份。

## 4. 引言视觉结构

每个 Beat 不应只是"背景 + 黑色文字卡"。推荐三层结构：

1. **全屏场景层**：当前 Beat 的 CG 或背景。
2. **镜头暗示层**：水纹、边界辉光、叶脉银线、草叶遮罩。
3. **经文字幕层**：低透明文本，不做大黑卡，避免像说明书。

文字卡建议：

- 宽度不超过 640px。
- 背景透明度降低，不要整块黑板。
- 文案每屏 4-7 行。
- 按钮固定底部，但视觉上像"继续聆听 / 低声开口"，不要像网页 CTA。

## 5. 对话界面优化

当前对话界面的问题不是布局完全错，而是过度暴露"任务面板"感。

### 推荐桌面布局

```text
左侧 70%：伊甸园实景
- 夏娃在树下或水边的半身/远景位置
- 善恶果作为画面中的视觉锚点
- 玩家视角带草叶遮挡或低位暗角

右侧 30%：低语层
- 夏娃当前一句对白
- 轻量状态词，不显示硬条形数值
- 推荐低语折叠或弱化
- 输入框固定底部
```

### 心理状态改法

把三条进度条改成"状态短句 + 环境反应"：

| 当前 | 推荐 |
|---|---|
| 想知道 20% 条 | "她看向果树的时间变长了。" |
| 畏惧禁令 85% 条 | "她仍把神的话放在最前面。" |
| 愿意倾听 25% 条 | "她还没有离开草叶下的声音。" |

进度条可以保留在开发态或折叠详情里，玩家主界面不必一直看到。

### 夏娃表现

不要只显示头像。至少做到：

- 对话面板里使用较大的夏娃半身图或剪影。
- 场景中有夏娃位置标记。
- 夏娃对白用字幕或叙事框表达，不要像聊天气泡。
