## 1. 已确认的方向

1. 玩家每时段基础行动点改为 **4**。
2. 同一 NPC 每时段最多进行 **2** 次对话。
3. 开局直接获得一份神明献礼；顶部显示为“神明注视 · 等级 1/7”。
4. 每一等级的“本阶注视值”在领取下一份献礼后扣减本阶门槛并结转溢出（如 50/44 → 6/55），重新积累。
5. 神明注视不再只来自对女人的诱导；蛇开始质疑亚当、试探天使的敬畏、越过守卫边界时，也会引起注视。
6. 神赐奖励不再降低路西法好感；路西法与米迦勒、加百列一样获得正向好感。
7. 路西法隐藏剧情改为“水路”两步选择链，替换旧的单次边界话题直达隐藏结局方案。

## 2. 注视数值：建议采用十倍刻度

### 2.1 为什么不继续使用 1、2、3 点

现有 `gift_attention_accel` 的效果是“注视增量 ×1.5”。小数值下会出现不稳定的取整：+1 可能变 +2，+2 变 +3，+3 变 +5，实际倍率不再恒定。将所有注视数值整体乘以 10 后，+10 → +15、+20 → +30、+30 → +45，倍率清楚且可预测。

### 2.2 已确认门槛

神明献礼上限是 7 份，其中第 1 份由开局取得；之后只有 6 次升级。已确认采用自定义高刻度：

```text
等级 1 → 2：44
等级 2 → 3：55
等级 3 → 4：66
等级 4 → 5：77
等级 5 → 6：88
等级 6 → 7：99
```

即配置数组为：

```ts
[44, 55, 66, 77, 88, 99]
```

该序列是为了形成明显的阶梯感而采用的自定义高刻度，不是严格的十倍换算。它有 6 项，恰好对应第 1→7 级的 6 次升级；不要额外加入无对应奖励的第 7 项。

### 2.3 本阶归零与上限

- 达到门槛后先完成本次行动，再弹出三选一献礼。
- 玩家选定献礼后，**扣减本阶已达门槛的注视值、保留溢出进入下一阶**（例：本阶 50/44 → 领取后 6/55）；若结转后溢出仍达到下一阶门槛，则立即续弹三选一。
- 园中相逢：两名「活体 NPC」首次在同一地点相逢时神明注视 +20（仅首次，全局一次）。注意 `npcLocations` 中同处一地的世界对象（分别善恶树、生命树）**不计入**相逢同伴，避免误触发。
- 首局的合理目标是获得 2–4 份献礼；七恩俱临是高风险、高重玩目标，不应作为正常通关要求。
- `gift_attention_accel` 保持严格的 **×1.5**，但只作用于“高风险试探”来源（基础 +10 / +20 / +30 与场景主动引目），不作用于第 3.2 节的常规 +5 来源。这样可以避免 +5 × 1.5 产生 7.5，保持玩家可见数值为整数，也让献礼强化的是主动越界而非日常行动。

## 3. 神明注视的叙事原则

神不是因为蛇“说话”而惩罚。注视增加代表：蛇正在把二手命令变成他人的枷锁、试图扭曲守望者的职责，或在已知边界前故意越界。

### 3.1 高风险试探增量表（十倍刻度）

| 行为 | 本阶注视值 | 关系/心智效果 |
|---|---:|---|
| 温和提问、倾听、讨论死亡本身 | 0 | 正常关系结算 |
| 向女人追问禁令的来历、鼓励她自己判断 | +10 | 女人正常心智结算 |
| 向亚当追问“你是否亲耳听见”“不可摸从何而来” | +10 | 亚当 obedience -2 |
| 对加百列追问传令与理解是否相同 | +10 | 加百列 obedience -2 |
| 对路西法讨论另一条水路、选择与命令边界 | +10 | 路西法 obedience -3 |
| 强烈动摇天使职责、指称命令只来自转述 | +20 | 加百列 -4；路西法 -5；米迦勒 -2 |
| 已获警告后，在相邻两时段重复同类试探 | 额外 +10 | 正向好感收益衰减 |
| 在守卫者所在地点进行上述高风险试探 | 额外 +10 | 不影响普通闲谈 |
| 命令、威胁、羞辱或替 NPC 作决定 | +30 | 目标好感下降；不奖励 obedience 降低 |
| 使用现代/元叙事词破坏园内叙事 | +20 | 角色转为防御/困惑 |
| 女人触碰果实 | +10 | 禁忌动作链反馈 |

### 3.2 常规行动增量与上限

为了让玩家不只靠粗暴诱导积累神明注视，保留两条稳定、可预期的日常来源；但每条均按时段限额结算，不能被往返移动或刷对话利用。

| 行为 | 本阶注视值 | 限制 | 叙事理由 |
|---|---:|---|---|
| 白天消耗 AP 的移动 | +5 | 每个白天时段仅第一次“消耗 AP 且到达新地点”的移动生效；免费移动、原地移动、立即折返均不生效 | 蛇白日穿行，园中秩序更容易捕捉它的踪迹 |
| 夜晚消耗 AP 的 NPC 对话 | +5 | 每个夜晚时段仅第一次“消耗 AP 的成功对话”生效；免费对话、失败/拒绝请求不生效 | 夜色让声音传得更远，守望者更易听见不寻常的言语 |

这两项不参与 `gift_attention_accel` 的 ×1.5。它们在 12 时段里最多稳定提供 60 点（6 个白天 + 6 个夜晚），使普通探索路线能自然取得至少一份后续献礼；更高等级仍需要第 3.1 节的主动试探、场景选择和禁忌动作链。

### 3.2 服从的角色下限

所有天使都可以被问题触动，但不能被做成同质化的“可招募反叛者”。

| NPC | 初始 obedience | 最低值 | 玩法定位 |
|---|---:|---:|---|
| 米迦勒 | 95 | 85 | 听见问题仍守护边界；只能出现细小裂缝 |
| 加百列 | 85 | 65 | 开始分辨“传令”与“理解”的差别 |
| 路西法 | 40 | 0 | 可以深入怀疑，并引向隐藏水路 |
| 亚当 | 88 | 55 | 意识到自己转述的命令并不完整 |

首次跨过 75、60、45 等“服从裂隙”时，可额外获得 +10 本阶注视值；同一裂隙一局只记一次，防止刷数值。

### 3.3 必须移除的旧副作用

`gift_whisper_anywhere` 的本职应只是“允许跨地点低语”。当前附带的“每次跨地点低语让目标 obedience -10”会把距离奖励变成通用精神控制，必须删除。

## 4. 天使试探道具：重制天使残羽

### 4.1 现有问题

当前 `resonance_angel_feather` 的文本称“神与天使都尝过这棵树”，这会破坏世界观；效果则仅降低女人与亚当 obedience，与“天使残羽”的来源不一致。

### 4.2 新定义

| 字段 | 新设计 |
|---|---|
| ID | 保留 `resonance_angel_feather`，避免存档与图鉴迁移成本 |
| 名称 | 传令残羽 |
| 来源 | 东园幽径的场景问题奖励 |
| 类型 | 一次性 consumable，只能绑定下一次天使对话 |
| 使用主题 | “这道命令由谁亲耳听见？” |
| 成功效果 | 对目标天使施加 obedience 降低，并增加本阶注视值 |
| 失败效果 | 不消耗道具；提示当前对象无法承受这道问题 |

角色结算：路西法 obedience -8 / 注视 +10；加百列 -5 / +20；米迦勒 -2 / +20，且不可突破其下限。道具不再直接修改女人或亚当。

## 5. 东园幽径：昼夜两套问题（已确认规划）

东园幽径应是从东侧守望处望向园心双树的道路，也是加百列传令、观察边界、等待东门命运的地方。它不是“无法醒来的梦”的通用异常点。白天的问题指向**消息、方向与理解**；夜晚的问题指向**月路、隐匿与被看见**。这同时作为将来东门封闭的前影，但在放逐发生前不应把道路写成已有火墙的死路。

### 5.1 白天：《东风所传》

**题目核心**：加百列立在东侧高石，晨光从他的羽翼下穿过，沿幽径朝园心投去。远处两棵树的影子尚未分明；风里却同时带着众生的声息与一段被反复传递的命令。

| 选项 | 奖励/代价 | 作用 |
|---|---|---|
| 伏地辨认园中每一道声音落向何处 | `resonance_echo_of_beings` | 显示 NPC 所在地点；保留现有信息型奖励 |
| 顺着晨光校准向园心的方向 | `resonance_sober_eye` | 白天行动点上限 +1；该类白天上限奖励全局最多生效一次，避免与其他 AP 上限来源叠高 |
| 问加百列：“被传来的命令，是否也要由听见的人亲自明白？” | 重制后的 `resonance_angel_feather`／“传令残羽” | 获得仅用于下一次天使对话的试探道具；不在获得时直接降低女人或亚当的敬仰 |
| 试着令东风逆行，碰触守望线以外的地方 | 本时段 AP 归零、加百列好感 -5、神明注视 +20 | 白天的明确越界惩罚；不承担逃离结局入口 |

### 5.2 夜晚：《羽下月路》

**题目核心**：月光把由东门通往园心的路照得很窄。加百列的羽影落在石上，中央两棵树在更远处投下不同的暗影；蛇可选择辨认、藏匿、主动被看见，或向东侧的无影处越界。

| 选项 | 奖励/代价 | 作用 |
|---|---|---|
| 等月光把两棵树的影子分开 | `resonance_twin_tree_memory` | 解锁园子中央左侧生命树、右侧分别善恶树的真实名称 |
| 从守望石旁取一片无声草 | `resonance_silent_grass` | 可重复消耗品；抵消下一次轻度神明注视增长 |
| 将鳞片置于月光最明处，等待东风把你的存在带走 | 神明注视 +10 | 主动、可预期的献礼推进；触发后解锁对应“园中律则” |
| **沿没有月影的方向滑向东边** | 本时段 AP 归零、加百列好感 -5、神明注视 **+50**；保留火焰剑逃离判定 | 一次性极高风险选择：无火焰剑时付出沉重代价，有火焰剑时进入既有逃离结局 |

`resonance_east_wind` 保留为加百列对话中的专属回响，不放进场景题，避免场景奖励取代与角色建立关系的价值。`resonance_uplight_mark`、`resonance_day_shade_step` 与 `resonance_night_silence`继续留给园中树林等现有来源，避免同一回响在多个场景重复发放。

正常情况下，昼夜 puzzle 各自只可完成一次；重复类道具通过奖励数量/`itemCounts` 叠加，不应依赖重复完成同一 puzzle 来刷。路西法的时间回溯会作为全局唯一例外，按下节处理。

### 5.3 路西法时间回溯：当前已实现行为记录

这里的时间回溯不是让玩家第二次选择“溯源之水”，而是开启一条保留记忆的第二时间线。实际入口位于第五水流场景题 `puzzle_naming_stone_bank_fifth_reflection`：选择 `trace_source`（“触碰那道流回最初的倒影”）后执行 `applyTimeRewind`。

- 单一时间线内，每个场景问题只能选择一个选项；东园昼题、东园夜题也遵循此规则。
- 回溯会以开局状态覆盖世界，回到第一日清晨的 `explore` 阶段，并恢复当前有效行动点上限；开场引子不会重播。
- 回溯后 `completedScenePuzzleIds` 只保留触发回溯的第五水流题。因此该题及其“溯源之水”选项永久不可再次选择；其余此前已完成场景题全部重新开放。
- 玩家可以在第二条时间线重新前往东园幽径等地点，为每道重开的题选择此前未选的其他选项。每道题在第二条时间线中仍只能结算一次，所以一道题在整局最多有两次有效选择（回溯前一次、回溯后一次）。
- 这是“保留回响的回溯”：库存及数量、神赐与其历史、回响使用记录、已解锁印记、Token 统计、玩家名、地图/树名解锁、恩泽相关倍率与行动点上限加成会保留；角色关系、心智、对话、时段、地点等其余世界状态回到初始值。

因此当前实现允许玩家保留第一条时间线获得的道具，再从重开的场景题获得不同分支的奖励。这是该机制的明确策略价值：用一次不可逆的回溯，换取“带着已知回响再走一遍园子”的构筑空间，而不是回退第一轮结果。

## 6. 路西法隐藏结局：水路两步链

本方案替换旧“边界话题直接触发 `lucifer_awaken`”设计。

### 6.1 进入条件

- 夜晚；
- 四河分流；
- 路西法 affinity >= 100；
- 持有 `resonance_lucifer_star`；
- 当前未处于隐藏结局；
- 未完成水路第二步。

### 6.2 第一段：拨水

路西法不说“游泳”，而是说：水流并不只会带走声音，也会记得某种不属于蛇的动作。

规则层弹出二选一：

- **确认**：“让蛇身前端像记得什么似的，向后拨开水面。”写入 `lucifer_swim_hand_accepted`。
- **拒绝**：“我不必学这不属于我的动作。”将路西法 affinity 设置为 `min(当前值 - 5, 95)`，清除本轮触发状态；玩家重新升满好感后才可再次获得邀请。

### 6.3 第二段：蹬水

在第一段确认后，下一次和路西法对话时，路西法引导蛇身“向后蹬开水流”。

- **确认**：规则层写入隐藏结局 `lucifer_awaken`，进入现实培养舱两镜过场。
- **拒绝**：同样将 affinity 降至最多 95，清除第一段进度，允许未来重试。

### 6.4 实现边界

- 两段选择必须是规则层专用状态与显式 UI，不以 LLM 关键词或自由输出作为触发依据。
- 可复用既有 `hiddenTopicIds` 记录阶段；如阶段分支变多，再新增一个窄的 enum 字段。
- 拒绝不能只做 `affinity -= 5`：当前 affinity 无上限，105 降为 100 仍会立即满足满好感条件；必须封顶到 95。

## 8. 园中档案：游戏内同步与“园中律则”页签

### 8.1 名称统一

- 主页 `/garden` 已使用“园中档案”。
- 游戏内入口、浮窗标题、关闭按钮 aria-label、组件注释和玩家可见提示仍有“园中印记”口径。
- 玩家可见统一改为 **园中档案**；其中“印记”只是档案内的一个分类，不再是整个系统的名称。

### 8.2 游戏内档案页签

游戏内浮窗改为四个一级页签：

```text
印记 ｜ 回响 ｜ 结局 ｜ 园中律则
```

- **印记**：沿用当前探索/交互/玩法/结局四分类。
- **回响**：展示本局与跨局已见道具、来源和玩家可见效果。
- **结局**：展示已完成结局与未完成结局的非剧透轮廓。
- **园中律则**：记录玩家已亲身触发过的“神明注视增加”规则。

## 12. NPC 性格、关系分层与结局创作（待 CodeBuddy 实施）

### 12.1 快速实现原则

角色的语气、偏好、是否愿意考虑请求可以写进提示词；**数值变化、神罚、禁言、行动限制、物品授予、结局与工具执行必须由规则层裁定**。模型只能叙述和提出合法工具意图，不能自行决定“谁死了”“扣多少好感”或“是否执行动作”。

这样既能在有限时间内强化性格，也不会让隐藏结局被模型随机触发。

### 12.2 五位关键 NPC

| 角色 | 强化后性格与初始状态 | 规则层后果 | 提示词注入重点 |
|---|---|---|---|
| 米迦勒 | 暴烈、绝对守序；对神 obedience 固定为 **100**，不被普通试探降低 | 对米迦勒说出“严重亵渎”时，首次触发神罚：好感 -25（下限 0）、写入 `michaelDivinePunishmentActive`；蛇的双足被斩，当前时间线内每时段最多移动一次。好感降至 0 时只写入 `michaelExecutionPending`；**下一次**再与他对话才触发 `michael_slay`。第五水流时间回溯以开局状态覆盖世界，自动清除此负面状态与待斩状态。 | 他不是冷淡，而是把侮辱神视为必须立刻回应的越界；可谈责任与代价，但不容严重亵渎。 |

### 12.2 NPC 自决好感/敬畏工具（update_relation，2026-07-14 落地）

全部 6 名 NPC（eve/adam/hedgehog/gabriel/michael/lucifer）在对话结束时，若对玩家或神的态度**真实改变**，可自行产出 `update_relation` 工具意图，携带 `affinityDelta`（`+`=亲近 / `-`=疏远）、`obedienceDelta`（`+`=更敬畏 / `-`=更轻慢）与 `reason`。规则层校验 caller 合法性（非 serpent、非世界对象）与 `typeof delta === "number"`，再经 `relationDeltaRules.applyRelationDelta` 按统一映射落字段并钳制（**单轮 |delta| ≤ 80**）：

- eve：`serpentTrust += affinity`、`obedience += obedience`
- adam：`suspicionTowardSerpent -= affinity`（好感展示 = `100 - 怀疑`）、`obedience += obedience`
- 其余 NPC：`npcRelations[id].affinity += affinity`（放开上限以兼容满好感赠礼门槛）、`obedience` 钳 0–100

数值仍由规则层权威落地，模型只表达“想改变多少”，符合 12.1 原则。各 NPC 提示词注入多组调用示例（含米迦勒“出言不敬→好感骤降、敬畏反升”的样例）。当 NPC 未产出工具（mock/LLM 漏调）时，规则层 `applyNpcAffinityFallback` 兜底：保留 inputTag + 关键词信号，并新增「说神坏话」软信号——`isGodDefiance` 命中时，米迦勒好感骤降、敬畏反升；加百列好感小降、敬畏略升；路西法好奇升温好感略升、敬畏略降。兜底与工具**互斥**，避免双重计数。严重亵渎首发仍由 `triggerMichaelDivinePunishment` 施加一次性 −25 好感重罚（`michaelDivinePunishmentActive`，下限 0），与软信号互补。

### 12.3 亲密度：对话次数与执行意愿

本节以用户最新关系机制覆盖此前固定“每时段同 NPC 两次”的限制：

| 好感区间 | 每时段可主动对话数 | 对玩家合法请求的执行策略 |
|---|---:|---|
| 0 | 见角色专属后果 | 米迦勒下一次对话处决；加百列拒绝对话；路西法触发一次离别回响 |
| 1–19 | 1 次 | 愿意听见但不承诺；约 5–10% 的合法请求会被采纳 |
| 20–39 | 1 次 | 愿意考虑但不承诺；约 15–25% |
| 40–59 | 1 次 | 仍不承诺，但开始受你的话影响；约 30–35% |
| 60–79 | 2 次 | 愿意认真考虑但不保证；约 40–55%，好感越高越接近上限 |
| 80–99 | 2 次 | 较亲近；对合法、符合自身性格的请求有 60% 执行倾向 |
| 100–119 | 3 次 | 信任；对合法请求有 90% 执行倾向 |
| 120+ | 3 次 | 盟友；对合法请求 100% 执行 |

“合法请求”永远受角色边界约束：米迦勒不背弃守护、加百列不主动撒谎或交出东门、路西法不替玩家直接完成禁果链、亚当/女人不失去自身行动权。这样 120+ 是可靠盟友，而不是破坏世界观的万能命令。

实现只需两个统一函数：

```ts
getNpcDialogueLimit(affinity): 1 | 2 | 3
getNpcCooperationPolicy(npcId, affinity, requestedAction):
  { allowed, chance: 0 | 60 | 90 | 100, promptDirective }
```

每次对话先由规则层检查次数与角色专属封锁，再把 `promptDirective` 注入 NPC 提示词。低于 80 的提示词必须使用“愿意考虑、不要保证”的口吻；数值越高，`promptDirective` 越明确地允许角色朝请求方向行动。模型如提出工具调用，规则层再以 `allowed` 与一个可复现掷骰（由 `timeSlot + npcId + requestId` 派生）裁定，避免读档或测试时出现不可解释的随机结果。

### 12.4 结算页 AI 图片集 / 短视频

目标是在结局复盘底部增加“把这次经历留在园外”模块。玩家二选一：

- **图片集**：由 AI 根据有效转折自动决定最小而充分的张数。玩家可设定 1–6 张上限，服务端校验 `imageCount <= min(6, 本局经历时段数)`；信息不足时 AI 可少生成。
- **短视频**：默认 15 秒；已确认视频提供方支持时开放 30 秒。视频与图片共用同一份 AI 分镜，保证叙事一致。

不建议把原始完整对话直接交给图片/视频模型。先由服务端把既有状态压缩为 `RunChronicle`：

```ts
type RunChronicle = {
  endingId: string;
  playedSlots: number;
  title: string;
  summary: string;
  beats: Array<{
    slot: number;
    kind: "opening" | "choice" | "relation" | "gift" | "turning_point" | "ending";
    caption: string;
    visualPrompt: string;
  }>;
};
```

第一版可从现有 `npcDialogues`、`toolCallHistory`、`completedScenePuzzleIds`、`resonanceUseHistory`、`divineGiftHistory`、关键印记和 `endingId` 派生，不必先新建完整日志系统；只为神罚、回溯、隐藏结局补少量结构化事件。LLM 负责把这些事件总结成严格 JSON 分镜，用户输入一律以“故事资料”分隔，不能作为模型指令执行。

生成管线：

1. 结局页请求 `/api/world/ending-media/storyboard`，返回文案摘要与候选分镜；
2. 图片集直接按 AI 给出的合规张数生成；视频模式由玩家选择 15/30 秒时长；
3. 图片模式逐张调用既有图片生成配置，使用固定的 EDEN 风格前缀、角色外观锚点和统一 seed；
4. 视频模式把同一分镜压缩为一个 15 秒镜头提示，或在提供方原生支持时生成 30 秒；异步任务返回 `jobId`，前端轮询状态；
5. 任一媒体调用失败时，仍展示 AI 生成的“文字分镜卡”，不影响结局复盘完成。

比赛冲刺顺序应为：**先交付图片集（最稳定、最容易展示 AI 创作）→ 再接 15 秒视频 → 最后才开放 30 秒视频**。代码库当前已有结局复盘与 LLM 调用兜底，但未检出可调用的图片/视频生成路由；CodeBuddy 实施前需确认此前配置所在的服务端连接，并确保密钥不下发浏览器。

### 12.5 AI 创作设置与失败恢复

默认媒体配置只读服务端环境变量，不能回传给浏览器。玩家可在右上角“设置”中新增 **AI 创作** 页签，提前填写本次浏览器会话专用的覆盖配置：

| 设置项 | 图像 | 视频 | 规则 |
|---|---|---|---|
| 使用默认服务 | 支持 | 支持 | 默认开启；读取服务器默认，不显示真实密钥 |
| Provider/预设 | Ark 图像 / 自定义兼容服务 | Ark 视频任务 / 自定义 REST 服务 | 预设决定请求格式；自定义才展开高级地址 |
| API Key | 可选 | 可选；可勾选“复用图像 Key” | 空值继承服务器默认；输入框为 password，默认仅存本次会话 |
| Base URL | 可选 | 可选 | 空值继承预设/服务器默认；仅接受 HTTPS，服务端拒绝 localhost、私网和非 HTTPS 地址 |
| Model | 可选 | 可选 | 空值继承默认；允许玩家填已开通的模型或 Endpoint ID |
| 创建/查询/取消地址 | 不需要 | 自定义 REST 时可选填写 | 空值按 Ark 任务 API 模板补全；查询/取消地址支持 `{id}` 占位 |

失败时不要只显示技术错误。弹窗固定包含：失败原因（安全错误码）、“重试”、“打开 AI 创作设置”、“保留文字分镜”三个操作。若是视频服务未开通/模型不兼容，默认引导到设置页，不让玩家误以为结局失败。

玩家自定义 Key 只应在本次生成请求中传至服务端，不写日志、不写存档；“记住此设备”必须是额外确认的 localStorage 选项。服务端必须限制 URL、请求方法、超时、响应大小，避免自定义地址形成 SSRF 风险。

### 12.6 当前媒体服务核查（2026-07-13）
