# 园中档案 UI 优化设计

> 日期：2026-07-12  
> 范围：`/garden` 独立图鉴页  
> 平台：仅桌面浏览器，目标画布 1920×1080；不新增移动端适配  
> 性质：定向视觉重构，不改游戏规则、收藏数据与路由结构

## 1. 设计目标

把当前像“悬浮调试面板”的园中档案，重构为嵌入伊甸园场景中的桌面档案台。玩家进入页面后，应在一个视线中心明确、对比度稳定的工作区内完成三件事：查看跨局进度、切换印记/回响/结局、浏览收藏详情。

本轮只解决信息组织与视觉表达，不增加新的收藏类型、排序规则、详情弹窗或游戏状态。

## 2. 当前问题

1. 主内容最大宽度仅 980px，在 1920×1080 画布中占比过低，卡片和文字像被整体缩小。
2. 标题、统计、分页、筛选和卡片直接叠在高细节背景上，暗色遮罩不足以建立稳定阅读面。
3. 一级分页、印记分类和解锁筛选使用相似按钮形态，层级不够清楚。
4. 统计卡、筛选栏和卡片之间缺少共同的对齐基线，视线需要反复寻找入口。
5. 已解锁、普通锁定、隐藏锁定的区别主要依赖透明度，辨识度和收藏反馈都偏弱。
6. 截图首屏只露出少量卡片，右侧存在大片无效背景区域，页面重心失衡。

## 3. 视觉方向

设计语言：古典寓言、园林档案、暗绿石材与旧金箔。保留现有伊甸园背景、暖金强调色和中文衬线气质，不引入新的设计系统或大型依赖。

设计参数：

- 变化度：6。使用轻微不对称的页首，但主体保持稳定网格。
- 动效：3。仅保留分页、按钮、卡片悬停和焦点反馈。
- 信息密度：5。桌面首屏同时看到完整页首、工具栏和至少一行收藏卡。
- 页面主题：统一暗色，不在分页之间切换主题。
- 强调色：统一使用现有暗金色，不新增紫色或高饱和渐变。

## 4. 页面结构

### 4.1 场景层

背景图继续全屏铺设。遮罩改为“整体暗化 + 中心阅读区柔和聚光”，既保留伊甸园辨识度，又让四周景物退到氛围层。页面滚动时背景固定，内容独立滚动。

### 4.2 档案工作区

主容器宽度固定为 1200px，顶部留白缩小。内容放入一个连续的深绿半透明档案面板，使用单一 14px 圆角体系、细暗金边线和克制阴影。面板在不支持模糊时仍保持足够实色与对比度。

### 4.3 页首

页首由 `page.tsx` 继续渲染返回入口、标题和一行说明，横跨档案面板全宽。`GardenCodex.tsx` 继续负责四项跨局统计，并把统计作为页首下方的第一条横向信息带。两者共享同一面板和左右对齐基线，但不跨组件移动统计计算或 DOM。统计值为视觉重点，标签降低权重。

### 4.4 一级分页

“园中印记 / 园中回响 / 诸般结局”作为档案卷宗分页，横向占据工具栏左侧。激活项使用底边金线和较高文字对比度，非激活项不使用独立卡片背景。

### 4.5 二级工具栏

仅印记分页显示分类、解锁筛选和搜索。分类是主要筛选，解锁状态是次要分段控件，搜索固定在右侧。三者置于同一条工具栏，避免当前的三层按钮堆叠。

### 4.6 收藏区

印记桌面端使用 4 列网格；卡片最小高度一致。图标放大到约 64px，标题、说明、时间形成固定纵向秩序。

- 已解锁：清晰图标、暖金边线、标题高对比，可有轻微上浮反馈。
- 普通锁定：保留真实名称但降低饱和度，使用轮廓锁标，不用彩色 emoji。
- 隐藏锁定：只显示抽象问号纹样和“尚未发现”，不泄露名称与条件。

回响使用 3 列信息卡，保留来源分组与即时/消耗/永驻标签。结局固定使用单列宽卡，突出标题、类型和叙事摘要。

### 4.7 页尾提示

隐藏印记提示收进档案面板底部，作为低权重注脚，不再悬浮在背景上。

## 5. 组件与代码边界

保持现有组件职责：

- `src/app/garden/page.tsx`：页面场景、页首和数据读取。
- `GardenCodex.tsx`：统计、一级分页和内容切换。
- `AchievementGarden.tsx`：印记分类、筛选、搜索和卡片。
- `ItemsGallery.tsx`：回响分组与卡片。
- `EndingsGallery.tsx`：结局条目。
- `src/app/globals.css`：本轮全部视觉调整。

允许对 JSX 做小范围结构调整和补充语义包装，但不改变 props、不新增全局状态、不改 localStorage 键、不改成就/回响/结局判定。`GardenCodex` 内的统计计算与渲染职责保持不变。

由于 `AchievementGarden` 同时被 `/world` 游戏内浮窗复用，本轮所有印记视觉覆盖必须限定在 `.eden-garden-page` 祖先选择器下。未限定作用域的 `.eden-achievement-*` 基础样式和 `compact` 模式保持不变，确保游戏内浮窗不受影响。

## 6. 数据流与异常状态

数据流保持不变：`GardenPage` 从本地存档与跨局追踪器读取数据，传给 `GardenCodex`，再由各分页纯展示。

本轮补强以下展示状态：

- 数据尚未读取时，页面结构稳定，不出现整体跳动。
- 搜索无结果时，空态占满收藏区宽度并给出明确说明。
- 图标加载失败时保留有边界的占位区域，不塌陷卡片。
- 键盘焦点在返回、分页、筛选和搜索控件上清晰可见。

## 7. 不在本轮范围

- 移动端与窄屏布局。
- 收藏详情弹窗、排序、分页加载或虚拟列表。
- 新增或调整印记、回响、结局内容。
- 修改游戏内园中印记浮窗。
- 修改未限定在 `.eden-garden-page` 下的共享图鉴基础样式。
- 修改首页入口、路由地址、存档格式或追踪规则。
- 新增图像、字体、图标库或动画依赖。

## 8. 验收标准

1. 1920×1080 下档案主体以 1200px 为基准宽度，视觉重心合理，首屏可看到页首、筛选和至少一行印记卡。
2. 背景仍可识别为伊甸园，但所有正文、按钮与输入框在背景图明暗变化下保持可读。
3. 一级分页、分类、解锁筛选三层关系一眼可辨。
4. 已解锁、普通锁定、隐藏锁定有三种明确且一致的视觉状态。
5. 三个一级分页可正常切换，搜索与筛选逻辑保持不变。
6. 返回首页、键盘焦点、搜索空态和图标失败占位正常。
7. 不新增移动端 CSS，不改变任何游戏规则或存档数据。
8. `npm run lint`、`npm run build` 通过；相关静态检查或浏览器烟雾测试无回归。
9. `/world` 游戏内园中印记浮窗及其 `compact` 模式视觉保持不变。

## 9. 比赛价值

该优化把已完成的 28 枚印记、园中回响和多结局从“功能存在”提升为可展示的跨局收藏系统，能在 Demo 视频和评审试玩中更直观地呈现内容量、探索深度与 AI 视觉资产成果，同时不扩张核心玩法范围。
