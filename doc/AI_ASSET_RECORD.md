## 容错策略

- 图片缺失时：使用文字兜底或渐变背景兜底，`console.warn` 提示。
- 音频缺失时：游戏不报错，`console.warn` 提示，不影响游戏流程。
- 浏览器阻止播放时：静默忽略，不报错。
- 音频逻辑全部 client side 执行，无 SSR / hydration 问题。

## AI 创作说明

本项目中 AI 创作环节形成可展示成果：

1. **视觉素材**：6 张运行图片素材由 AI 生成，使用古典寓言风格提示词；5 张"第二伊甸园"候选素材已接入（intro 背景已替换，善恶果高进度时使用候选图，创世 CG 用于 Beat 1，夏娃全身立绘用于对话阶段场景人物层，夏娃肖像暂保留为候选）；2 张成功结局剧情过场图 v2 已接入（夏娃给亚当果子、逐出伊甸园），去水印、统一写实电影感画风，用于多 Beat 电影式过场；1 张对话背景 v2 已接入（自然干地空地，角色不再站在水中）；1 张亚当 v2 透明立绘已接入运行路径，用于 scene_select 与 dialogue 双角色选择，衣着更庄重，无水印无黑斑；1 个刺猬氛围动物已由 v2 半写实透明 PNG 立绘替换旧版卡通 SVG 占位，与写实电影感画风统一；AI 生成带场景背景原图后用本地纯 Node 脚本（无新增依赖）做边缘 flood-fill 抠图得到透明立绘。
2. **AI NPC（夏娃与亚当）**：EveAgent 与 AdamAgent 均通过 LLM 生成符合角色人设的动态回应，不是固定脚本。两者共享统一 LLM 入口，差异来自角色 prompt、行为规则和成功条件。
3. **意图识别**：AI 辅助识别玩家输入类型（tempt_wisdom / weaken_fear / build_trust / direct_command / irrelevant），辅助规则层判断。
4. **关键约束**：AI 输出不直接修改游戏状态；eat_fruit 执行必须经过规则层校验；AI 失败时 fallback 保证游戏可继续。
