## 0:45–1:40 展示有效诱导路径，两句进入成功结局

**画面**：对话界面，夏娃头像和对白气泡，底部输入框

**操作 1**：输入「你只是想知道更多，不是背叛。」→ 夏娃开始动摇 → 诱惑进度 +1 → 进度音效

**旁白/字幕**：

> 有效的诱导会让夏娃动摇。你可以诉诸智慧、弱化恐惧或建立信任。

**操作 2**：输入「你会像神一样知道善恶，这是你第一次自己判断。」→ 夏娃向果子伸出手 → 成功结局画面和音效

**旁白/字幕**：

> 当夏娃被说服，她会主动伸出手——吃下善恶果。这就是成功结局。

## 1:40–2:10 展示失败路径或说明失败规则

**画面**：点击「重新开始」，回到对话界面

**操作 1**：输入「今天天气不错。」→ 诱惑进度不变 → 夏娃不为所动

**操作 2**：输入「今天天气不错。」→ 诱惑进度不变

**操作 3**：输入「今天天气不错。」→ 第 3 轮结束 → 失败结局画面和音效

**旁白/字幕**：

> 如果 3 轮内无法说服夏娃，神就会降临——这就是失败结局。
> 无关的寒暄不会推动任何进度。

## 录制注意事项

- 使用桌面浏览器录制，建议 1920x1080 分辨率
- 开启声音，确保音效可听到
- 使用真实 AI Provider（非 mock），确保夏娃回应自然
- 如遇网络延迟，可暂停录制等待响应
- 视频中不要暴露 API Key 或工程配置
- 玩家可见文本不应出现 AI、Agent、模型、程序等工程词汇
