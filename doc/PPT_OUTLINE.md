## 第 3 页：核心玩法

**标题**：核心玩法循环

**内容**：
- 玩家输入低语 → 夏娃 AI 回应 → 诱惑进度变化 → 结局
- 成功路径：有效诱导 → 进度达标 → 夏娃主动吃果 → 成功结局
- 失败路径：无关输入 → 进度不变 → 3 轮耗尽 → 失败结局
- 关键机制：诱惑进度（0→3 单轴），5 种输入标签

**视觉元素**：玩法流程图或示意图

## 第 4 页：AI 使用点

**标题**：AI 能力展示

**内容**：
- **EveAgent**：AI 驱动的夏娃 NPC，实时生成角色回应
- **意图识别**：AI 辅助识别玩家输入类型（诱导/弱化恐惧/建立信任/命令/无关）
- **Tool Calling**：AI 可以请求 `eat_fruit` 意图，但必须经过规则层校验
- **后端兜底**：诱惑进度达标时，即使模型未输出 toolCall，后端也会补充生成合法意图
- **AI 失败 fallback**：LLM 超时/报错时降级到本地固定回复，游戏不中断

**关键原则**：AI 只能表达意图，不能直接修改游戏状态

## 第 6 页：技术实现

**标题**：技术架构

**内容**：
- 前端：Next.js 14 + React 18 + TypeScript + Tailwind CSS
- AI 接入：统一 LLM Provider（Volcengine / DeepSeek / Mock）
- 架构关键点：
  - API Route 调用 EveAgent → 规则层校验 → 状态更新
  - toolCall 意图 → rule guard → executeEatFruit
  - 前端 API 失败降级到本地 runChapter0Turn
- 测试：fake provider 45/45 通过 + 真实 Provider 验证
