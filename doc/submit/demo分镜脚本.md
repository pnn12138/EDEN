# EDEN Demo 演示视频分镜脚本（≤3 分钟，≤100MB）

> 状态：**脚本已就绪，实拍 `.mp4` 需开发者录屏**（Agent 无法代为录屏 / 持有账号）。
> 录制参数：1920×1080，桌面浏览器，建议 Edge / Chrome，包含鼠标操作。

## 顺序（严格对应赛题要求）

### ① 首页展示（0:00–0:20）
- 展示 EDEN 首页：项目名、副标题、"园中诸声"第一章定位。
- 鼠标移到右上角登录区：输入昵称登录（2–10 位），验证游客模式可跳过。
- 点击「进入伊甸园」。

### ② 核心玩法（0:20–1:40）
- 探索 3 个以上地点：点击地图热点（亚当修理看守地 → 园子中央 → 万物受名处）。
- 与夏娃/亚当/天使对话：在对话框输入低语（如"神岂是真说…你们不一定死"），展示夏娃动态回应。
- 触发禁忌动作链：持续低语让夏娃自行 look→approach→touch→eat，触发 `eve_eats_fruit` 成功结局。
- 展示回响面板（分类 / 悬浮 shortEffect / 使用叙事提示）、神注视等级变化（脉动 / 光晕）。

### ③ 新增功能（1:40–2:30）
- 润色按钮：输入一段低语 → 点击润色 → 成功替换 / 失败兜底"风打断了低语"。
- 存档：保存 / 读取 / 重新开始；展示自动保存时间。
- 印记图鉴：从首页 / 顶栏 / 结局页三处入口打开，切换 4 分类、3 筛选，隐藏印记显示「？？」。
- 低语反馈：状态变化时对话区下方 3 秒叙事提示。

### ④ 结局与 AI 亮点（2:30–3:00）
- 展示结局复盘页（堕落轨迹、状态、日志）。
- 收尾说明 AI 亮点：智能 NPC、AI 生成世界观 / 视觉 / 叙事、规则层安全、纯前端可部署、CodeBuddy 全程开发。

## 技术提示
- 录制前可用 `LLM_PROVIDER=mock` 或配置真实 Provider；mock 下 NPC 仍走本地 fallback 可玩。
- 若用真实 Provider，确保 `.env.local` 密钥不出现在录屏中。
- 导出 H.264 MP4，码率控制在 100MB 内。
