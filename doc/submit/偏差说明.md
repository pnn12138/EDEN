# EDEN 提交偏差说明（Phase 3）

> 本文档记录本次提交相对"理想完整方案"的 4 个合理偏差点，以及 3 个需开发者手动完成的环节，供评审理解。

## 一、4 个合理偏差点

### 1. 纯前端登录替代原 KV 方案
- 原计划 Task 2.4 考虑 Vercel KV 云端登录，本轮按 v1.1 修订与赛题"纯前端可独立部署、无云依赖"的偏好，改为纯前端 `localStorage` 用户名登录（键 `eden:user:username`）。
- 合理性：更契合赛题约束，零云依赖、零运维、无密钥泄漏面；游客模式保证无阻断游玩。

### 2. `mark_echo_collector` 阈值下调至 18
- 设计文案写作 30，但实际可获取回响池上限约 25 个，30 在技术上不可达。
- 处理：阈值设为 18，保证多周目可稳定解锁该印记，且不影响其他印记平衡。

### 3. 隐藏印记触发点未实装
- 4 个隐藏印记（`mark_hidden_scene` / `mark_hidden_dialog` / `mark_hidden_operation` / `mark_hidden_ending`）对应隐藏结局为机密内容。
- 处理：判定逻辑已就位（不会误触发），但触发点按"玩家自行探索"设计意图未实装，图鉴中显示为「？？」且不暴露获取条件。

### 4. 路西法映射至乌列尔 NPC
- 代码中无独立「路西法」NPC。
- 处理：`mark_lucifer_trust` 映射至现有「光照天使乌列尔（晨星）」隐藏身份，逻辑自洽，未新增独立角色。

## 二、3 个需开发者手动完成的环节（非代码偏差，受 Agent 权限限制）

### 5. 在线试玩链接（部署）
- 原因：Agent 无法代为登录 EdgeOne Pages / CNB 或持有账号凭证。
- 已备：仓库根目录 `edgeone.config.js` / `cnb.config.js`（Serverless 模式，无硬编码密钥），`doc/submit/在线链接.md` 含逐步部署说明。
- 完成方式：开发者在平台导入仓库并按说明授权，即可获得公开 URL 回填。

### 6. Demo 演示视频（.mp4）
- 原因：Agent 无法录屏或生成真人操作视频。
- 已备：`doc/submit/demo分镜脚本.md` 提供逐秒分镜（首页→核心玩法→新增功能→结局与 AI 亮点）。
- 完成方式：按脚本用桌面浏览器 1920×1080 录制 ≤3 分钟、≤100MB MP4。

### 7. 社交媒体发布（加分项）
- 原因：Agent 无法代为发布到小红书 / 视频号 / B 站。
- 已备：`doc/submit/社交媒体链接.md` 含标题、正文、话题标签与回填位。
- 完成方式：开发者发布后回填链接即可。
