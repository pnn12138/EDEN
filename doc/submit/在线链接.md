## 如何获取公开 URL

1. 在 EdgeOne Pages 控制台「导入仓库」（支持 GitHub / CNB / Gitee）。
2. 构建设置：
   - 构建命令：`npm run build`
   - 输出目录：`.next`
   - 运行时：**Node / Serverless**（务必选此模式——本项目含 `/api/*` 服务端路由，用于在服务端隐藏 LLM Key，不可用静态导出）
   - Node 版本：20
3. 在「环境变量」中配置 `LLM_PROVIDER=volcengine` 及对应 `VOLCENGINE_API_KEY`；密钥仅服务端读取，不暴露前端。
4. 部署完成后 EdgeOne Pages 分配 `*.edgeone.app` 公网 URL（国内可直连，无墙）。
5. 将最终 URL 回填到本文件「最终链接」处即可。
