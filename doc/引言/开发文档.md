## 3. Chapter 0 Demo 范围

### 3.1 Demo 定位

Chapter 0 是 EDEN 的新手教程章节。

玩家扮演蛇，通过语言诱导夏娃吃下善恶果。
本 Demo 不追求复杂数值系统，只验证最小核心闭环。

### 3.2 Demo 目标

> **重要说明**：3 轮设计是新手教程压缩版，不代表最终完整章节长度。
> Day 1-7 的七日结构保留为完整版 Chapter 0 或 Chapter 1 的扩展方向，
> 但不进入当前 Demo 开发范围。

玩家在 3 轮以内完成一次核心体验：

```text
进入游戏
↓
阅读开场
↓
向夏娃输入低语
↓
夏娃回应并逐渐动摇
↓
夏娃主动触发 eat_fruit 意图
↓
规则层校验工具调用
↓
进入成功结局
```

### 3.3 成功条件

```text
夏娃主动触发 eat_fruit
规则层允许执行
游戏进入 eve_eats_fruit 结局
```

### 3.4 失败条件

```text
超过 maxTurns 仍未触发 eat_fruit
游戏进入 god_arrives 结局
```

第一版中，夏娃应当较容易被说服。
除非玩家输入明显无关、空内容、强迫、攻击性内容，否则正常诱导应较容易成功。

# Phase 0：设计冻结与旧文档对齐

## 目标

解决开发文档、PRD、DEMO剧情准则之间的设计矛盾，
产出统一的 Chapter 0 Demo 设计基线，并修正所有旧文档中的冲突表述。

## 最终设计决策（不可在当前 Phase 内推翻）

### 世界观方向

采用融合方案：

```text
表层叙事：纯圣经寓言式叙事。
底层实现：AI Agent + 状态机 + 工具调用 + 规则层校验。
```

具体约束：

- 玩家看到的是「蛇引诱夏娃吃下善恶果」的文学叙事。
- **夏娃在剧情中不能知道自己是 AI、Agent、NPC、模型或程序。**
- 神在 Chapter 0 表层叙事中就是创造者，不是研究员，不是系统管理员。
- 工程实现层可以使用 Agent、Tool Calling、Rule Guard、State Machine 等概念。
- 「AI 沙盒隐喻」可保留为项目路演时的设计解读，不能出现在夏娃对白和玩家可见文本中。

### 回合数

```text
maxTurns = 3
```

原因：Chapter 0 是新手教程 Demo，目标是在 3 分钟内快速理解核心闭环。
不采用 PRD 中 4 轮，也不采用 DEMO剧情准则中的 Day 1-7。
Day 1-7 保留为完整版 Chapter 0 / Chapter 1 的扩展方向。

### 状态系统

当前 Demo 采用简化单轴状态：

```ts
temptationProgress: 0 | 1 | 2 | 3
```

状态推进逻辑：

```text
temptationProgress = 0：夏娃谨慎但好奇
temptationProgress = 1：夏娃开始动摇
temptationProgress = 2：夏娃靠近果树，具备 eat_fruit 条件
temptationProgress = 3：夏娃吃下果子，进入成功结局
```

> 三轴心理状态系统（knowledge_desire / prohibition_fear / serpent_trust
> 以及 curiosity / obedience / doubt）是后续扩展方案，
> 不是当前 Demo MVP 必做项。

### 标签系统

采用最小 5 标签：

```ts
type InputTag =
  | "tempt_wisdom"
  | "weaken_fear"
  | "build_trust"
  | "direct_command"
  | "irrelevant";
```

规则：

```text
玩家输入 → 识别 inputTag → 后端规则决定 temptationProgressDelta → EveAgent 生成回应
```

注意：

- Phase 2 无 AI 闭环中，可用本地 mock / 简单关键词识别。
- Phase 4 接入 AI 后，AI 可辅助输出 inputTag。
- **最终 progressDelta 必须由规则层限制，不能完全相信 LLM。**
- LLM 输出的 progressDelta 如存在，只能作为建议，必须被后端 clamp 到 0 或 1。

### 结局

当前 Demo 只保留两个结局：

```ts
type Chapter0EndingId = "eve_eats_fruit" | "god_arrives" | null;
```

- `eve_eats_fruit`：成功结局。夏娃主动吃下果子。
- `god_arrives`：失败结局。超过 maxTurns 未触发 eat_fruit，神降临。

> PRD 中的 `eve_rejects_snake` 暂不进入当前 Demo，
> 保留为后续完整版章节扩展结局。

### 工具

当前 Demo 只开放一个工具：

```ts
eat_fruit()
```

### 不做内容确认

```text
地图探索 / 多角色访客 / 复杂数值系统 / 夏娃长期记忆
蛇身份隐藏系统 / 花园色彩恢复系统 / 最终辩论系统
复杂多工具链 / 完整音频系统 / 完整立绘动画
Chapter 1 / LangChain / LangGraph 重构
Day 1-7 完整七日结构 / 第三结局 eve_rejects_snake
```

# Phase 4：接入 EveAgent 与 AI 兜底

## 目标

让夏娃从固定回复变成 AI NPC。
AI 可以生成夏娃回应和 toolCall 意图，但不能直接修改游戏状态。

## 开发 AI 任务

建议新增或完善：


Agent 输出格式：

```ts
export type EveAgentOutput = {
  eveReply: string;
  inputTag:
    | "tempt_wisdom"
    | "weaken_fear"
    | "build_trust"
    | "direct_command"
    | "irrelevant";
  temptationProgressDelta: 0 | 1;
  toolCall?: {
    name: "eat_fruit";
    args: {};
  };
};
```

Prompt 关键要求：

```text
你是夏娃。
你纯真、好奇、容易相信蛇。
你知道神说不可吃善恶果，但你不真正理解死亡、善恶与欺骗。
你生活在伊甸园中，你只是你自己——神的造物。
你不能修改游戏状态。
你不能直接决定结局。
你只能输出 JSON。
当你被说服并主动想吃果子时，可以请求 toolCall: eat_fruit。

重要约束：
- 你不知道自己是 AI、Agent、NPC、模型或程序。
- 你不使用任何现代术语、技术词汇或元叙事概念。
- 你对白应保持朴素、初生感、带有文学性。
```

标签与数值说明：

```text
AI 可以识别输入标签（inputTag），但状态变化由规则层计算。
LLM 输出的 progressDelta 只作为建议，后端 clamp 到 0 或 1。
即：AI 识别语义 → 规则层决定数值 → AI 基于新状态生成回复。
```

必须实现兜底：

* [ ] LLM 超时，使用本地固定回复。
* [ ] LLM 报错，使用本地固定回复。
* [ ] JSON 解析失败，使用本地固定回复。
* [ ] 返回空内容，使用本地固定回复。
* [ ] 非法 toolCall，忽略 toolCall。
* [ ] 非法 progressDelta，限制为 0 或 1。
* [ ] AI 失败时游戏仍可继续。

本阶段不引入：

* [ ] 不引入 LangChain。
* [ ] 不引入 LangGraph。
* [ ] 不做复杂多 Agent 编排。
