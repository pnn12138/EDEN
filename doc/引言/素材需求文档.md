## 1. 当前素材目标

Chapter 0 当前是 3 轮以内的新手教程。

素材目标：

```text
1. 建立伊甸园氛围
2. 明确夏娃、蛇、善恶果三个视觉锚点
3. 区分成功 / 失败结局
4. 提供基础音效反馈
5. 方便后续 AI 加工、归档和接入游戏
```

当前不做：

```text
完整配音
角色动画
CG 视频
Chapter 1 素材
宣传图
PPT 素材
```

柔和光影
暗金绿色调

## 8. 音效来源建议

优先使用：

```text
Pixabay
Mixkit
Freesound
OpenGameArt
```

使用原则：

```text
1. 优先选择 CC0、免署名、可商用素材
2. 不使用 Non-Commercial 限制素材
3. 不使用来源不明素材
4. 下载后记录来源链接
5. 需要署名的素材必须记录作者
```

## 10. 后续 AI 处理要求

后续开发 AI 或素材处理 AI 读取本文件时，应遵守：

```text
1. 不随意改文件名
2. 不移动 image/、audio/ 目录
3. 新素材必须登记到素材记录表
4. 替换素材时保留旧素材来源信息
5. 接入游戏前检查文件是否存在
6. 图片缺失时页面必须有文字兜底
7. 音频缺失时游戏不能报错
8. 玩家可见内容不得出现 AI / Agent / NPC / 模型 / 程序 / 沙盒 / 系统 等元叙事词
```
