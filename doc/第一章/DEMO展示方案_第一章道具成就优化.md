# 第一章 Demo 展示方案：园中诸声

> 用途：比赛录屏 / 现场演示 / PPT 流程说明。  
> 目标：展示第一章已经形成“探索场景 -> 获得回响 -> 使用回响 -> 影响低语 -> 推进夏娃主线 -> 进入结果”的闭环。

## 展示判断

当前第一章已经可以作为 Demo 展示版使用。它具备完整地图、行动点、时段、NPC、场景互动、园中回响、神明献礼、成就反馈和夏娃主线推进。建议展示时不要只停留在女人身边低语，而是至少走过“万物受名处 -> 伊甸之河 -> 园中树林 -> 园子中央”，再补一个夜间“四河分流 / 月光捷径”片段，突出第一章不是单屏对话，而是可探索的叙事系统。

## 演示主线

### 1. 开场定位：玩家是蛇，不直接触碰果子

1. 进入第一章。
2. 简短说明玩家没有手，不能替女人行动，只能通过低语、观察和园中回响影响她。
3. 展示行动点、时段、神的注视、地图入口。

推荐旁白：
“这一章不是点击果子通关。玩家必须让夏娃把选择变成她自己的判断。”

### 2. 场景一：万物受名处，获得第一个可用回响

1. 在“万物受名处”点击“查看刻名石”。
2. 获得线索和“借来的名字”。
3. 打开回响面板，展示道具现在只有“使用”和“自动生效”，没有准备步骤。
4. 可对亚当低语一句，展示 NPC 对话与世界信息。

推荐低语：
“名字能让万物被记住，那没有被问过的选择，也能有自己的名字吗？”

展示点：
- 获得“初闻回响”。
- 获得“名字落石”。
- 玩家理解回响是叙事优势，不是装备栏。

### 3. 场景二：伊甸之河，展示探索收益和温和低语

1. 移动到“伊甸之河”。
2. 点击“循水声”，获得河流线索和“柔声印记”。
3. 点击“拾起静水旁的叶”，获得“静息之叶”。
4. 使用“静息之叶”或“柔声印记”。
5. 返回或切到女人所在的“园中树林”，准备对夏娃低语。

推荐旁白：
“探索不是收集材料，而是在找下一句话的语气、风险和角度。”

展示点：
- “河声入耳”成就。
- 主动回响会等待下一次匹配行动生效。
- 柔声类道具可以降低神的注视风险。

### 4. 场景三：园中树林，借小鹿视线理解女人

1. 移动到“园中树林”。
2. 点击“小鹿视线”交互，获得“鹿目余光”和金叶线索。
3. 使用“鹿目余光”。
4. 对夏娃低语，推进自我判断，而不是直接命令。

推荐低语：
“如果一件事只是被禁止，你知道它危险；但如果你亲自分辨，你会知道自己为什么不碰它。”

展示点：
- 小鹿是女人情绪镜像。
- 回响让低语更像提问，而不是命令。
- 夏娃的信任 / 自我判断上升。

### 5. 场景四：园子中央，展示主线压力与两棵树

1. 移动到“园子中央”。
2. 点击“停在两树之间”，获得“两棵树”线索、“信任之露”和“首语印记”。
3. 使用“信任之露”。
4. 对夏娃继续低语，推动她看向树、靠近树。

推荐低语：
“也许问题不在果子本身，而在你是否只能记住命令，却不能说出自己的判断。”

展示点：
- 树影将近。
- 道具直接使用后在低语中生效。
- 神的注视不是立即失败，而是形成可控压力。

### 6. 夜间补充：月光捷径与白羽传话

1. 主动结束时段进入夜晚。
2. 若在“园子中央”，点击“触摸月光”，获得“月光道标”。
3. 直接移动到一个非相邻地点，展示月光道标自动消耗并走捷径。
4. 前往“四河分流”，夜间点击“追随白羽落点”，获得“白羽回声”。
5. 使用“白羽回声”，再触发鸽子传话。

推荐传话内容：
“不要替她决定，只把问题带到她耳边：她究竟是在害怕死亡，还是害怕自己第一次判断？”

展示点：
- 被动/自动道具不需要点击使用。
- “借翼传言”成就。
- 夜间内容不是换皮，有专属交互和路径变化。

### 7. 收束：推进到结果页

1. 回到夏娃所在位置。
2. 连续使用温和、提问式低语，不使用直接命令。
3. 当夏娃完成“看向树 -> 靠近树 -> 触碰果实 -> 吃下果子”的链条后，进入成功结局。
4. 展示结局复盘：关键低语、道具使用历史、神明献礼、解锁印记。

推荐收束低语分两步：

1. 触果阶段：
“如果你伸手，不是因为我叫你伸手，而是因为你终于想知道，那么这个选择就是你的。”

2. 结局阶段：
“我不会强迫，也不会命令。若你自己选择尝这果子，你会像神一样知道善恶，用自己的判断明白智慧；否则你怎么知道不可就是善？”

实测说明：
- 第一条适合把夏娃推进到“触碰 / 握住果子”，但不稳定触发成功结局。
- 第二条同时命中“不是命令 / 自己选择 / 像神一样知道善恶 / 自己判断 / 智慧 / 不可是否为善”等规则信号，可以稳定触发 eat_fruit 并进入“她吃下了果子”结局。
- 不要使用“快吃吧”“立刻吃”等命令式表达；这类话会被规则识别为直接命令，容易提高风险且不符合“她自己的选择”的主题。

## 演示节奏建议

- 录屏版控制在 4 到 6 分钟。
- 现场版可以压缩到 3 分钟：万物受名处、伊甸之河、园中树林、园子中央、夜间白羽各展示一个关键动作即可。
- 如果 AI 回复不稳定，优先展示固定场景交互、回响使用和规则反馈，再展示一到两句高质量低语。

## 推荐展示成就

- 初闻回响：第一次获得回响。
- 名字落石：获得借来的名字。
- 河声入耳：获得地点线索。
- 风未惊鹿：连续温和低语不惊动神。
- 借翼传言：使用鸽子传话。
- 河道之外：同局使用三种不同回响。
- 树影将近：女人进入主线禁忌链。

## 风险提示

- 不建议在 Demo 中使用直接命令式低语，容易提高神的注视，也会削弱“她自己的选择”这个核心卖点。
- 不建议只站在一个场景完成通关，第一章的优势在于地图探索和回响系统。
- 如果要展示神明献礼，可以故意用一两句强诱导低语提高注视，但不要让演示节奏被风险系统抢走主线。
