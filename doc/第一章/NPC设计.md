# 伊甸园核心地图 NPC 与对话设计 V1.1

## 1. 交互原则

玩家扮演蛇，当前唯一主动交互方式为“对话”。

每位可交互 NPC 的设计遵循以下规则：

* 一次核心对话，对应一条明确情报或一个简单奖励。
* 不设计跟随、采集、解谜、战斗、计时等额外操作。
* 奖励自动生效，不需要额外背包、装备或使用按钮。
* 奖励只影响“接近夏娃时的对话条件”，不能直接强制夏娃吃果子。
* 动物不使用人类语言，不开启正式对话框，仅作为环境状态提示。

## 2. 对话奖励类型

| 类型    | 作用                   |
| ----- | -------------------- |
| 地图情报  | 告知安全路径、人物活动区域或场景关系   |
| 对话关键词 | 解锁与夏娃交谈时更自然、低风险的开场选项 |
| 安抚信物  | 自动降低夏娃初始警惕，不需要主动使用   |
| 剧情预兆  | 提示道路、后果或结局变化，不直接帮助诱惑 |

# 3. 各场景 NPC 设计

## 3.1 伊甸之河

### 场景定位

开场区域、天使引导区。
此区域不放小动物，只保留瀑布、河流、晨雾与三位天使。

加百列、拉斐尔、乌列尔在本作中设定为“河源随行使者”。这是游戏扩展关系，不视为《创世记》中的直接设定。

### NPC：加百列

| 项目    | 设定                                |
| ----- | --------------------------------- |
| 身份    | 河源随行使者的领队                         |
| 位置    | 瀑布前方的浅水岩台                         |
| 气质    | 平静、温和、克制                          |
| 对话主题  | 河流、声音、隐藏与意图                       |
| 核心情报  | 河水能遮住移动的声音，但无法遮住不合时宜的靠近           |
| 对话奖励  | **河声情报**                          |
| 奖励效果  | 告知玩家：从伊甸之河侧边进入东园幽径，比穿越开阔草地更不易引起注意 |
| 对玩家态度 | 不帮助诱惑，只提供中性环境知识                   |

### NPC：拉斐尔

| 项目    | 设定                                |
| ----- | --------------------------------- |
| 身份    | 河源随行使者，负责守护生机与平息扰动                |
| 位置    | 伊甸之河中段，平缓石滩附近                     |
| 气质    | 温和、敏锐、有距离感                        |
| 对话主题  | 平静、信任、受惊的生灵                       |
| 核心情报  | 夏娃在安静环境中更愿意停留与倾听；急促、压迫或突兀的言辞会使她远离 |
| 对话奖励  | **静息之叶**                          |
| 奖励效果  | 自动生效：玩家首次与夏娃对话时，夏娃初始警惕降低一级        |
| 对玩家态度 | 不直接评价蛇的计划，但会提醒“平静不等于遗忘界限”         |

### NPC：乌列尔

| 项目    | 设定                                |
| ----- | --------------------------------- |
| 身份    | 河源随行使者，负责观察光影与道路                  |
| 位置    | 瀑布左侧高岩或树梢平台                       |
| 气质    | 冷静、锐利、话语简短                        |
| 对话主题  | 光影、视线、提问与沉默                       |
| 核心情报  | 夏娃会回应真诚的问题，却会警惕直接的断言与命令           |
| 对话奖励  | **林影之语**                          |
| 奖励效果  | 解锁夏娃对话中的低警惕开场选项：以“提问”而非“诱导结论”开始谈话 |
| 对玩家态度 | 容易识破玩家夸张或矛盾的说辞                    |

## 3.2 园子中央

### 场景定位

地图中央的神圣区域，仅保留两棵树。

### NPC 规则

* 不设置常驻 NPC。
* 不设置小动物。
* 不放天使。
* 不设置常规任务。

### 场景作用

* 作为最终关键对话发生地。
* 夏娃从园中树林进入。
* 亚当从万物受名处进入外围。
* 玩家与夏娃完成前置对话后，才可触发此处核心剧情。

---

## 3.3 万物受名处

### 场景定位

亚当与动物共处的区域，体现命名、照料与园中秩序。

### NPC：亚当

| 项目    | 设定                                 |
| ----- | ---------------------------------- |
| 身份    | 园中劳作与动物命名者                         |
| 位置    | 左下动物草甸、园圃边缘与石块附近巡游                 |
| 气质    | 温和、专注、朴素                           |
| 对话主题  | 名字、秩序、园中的生灵                        |
| 核心情报  | 女人常在园中树林停留；她更愿意接近那些愿意倾听、而非急于指引她的存在 |
| 对话奖励  | **夏娃行迹**                           |
| 奖励效果  | 解锁夏娃的常驻区域与前往园子中央的可能路径              |
| 对玩家态度 | 初始不敌对；若主线推进后园中出现异常，会减少与蛇的交流        |

### 动物配置

动物仅作为环境角色，不开启对话。

| 动物  | 位置      | 功能            |
| --- | ------- | ------------- |
| 白羊群 | 草甸与园圃边缘 | 体现亚当照料与园中和平秩序 |
| 小鹿群 | 石块与草地交界 | 靠近亚当活动区域      |
| 野兔  | 草丛与石缝附近 | 增加场景生机        |
| 斑鸠  | 果树与低枝上  | 强化安静、和谐的氛围    |

---

## 3.4 园中树林

### 场景定位

夏娃的主要活动区域，也是玩家建立对话机会的核心场景。

### NPC：女人（夏娃）

| 项目     | 设定                       |
| ------ | ------------------------ |
| 身份     | 核心剧情 NPC、主要对话对象          |
| 位置     | 林间空地、花草旁、古树下、林缘位置        |
| 气质     | 好奇、敏感、愿意思考，但不轻易接受陌生结论    |
| 对话主题   | 园中的美善、命令、果实、自由、后果        |
| 核心作用   | 推进主线；决定玩家能否进入园子中央的关键对话   |
| 警惕状态   | 平静、留意、戒备                 |
| 对话奖励来源 | 静息之叶可降低初始警惕；林影之语可解锁低风险开场 |

### NPC：小鹿

| 项目   | 设定                                 |
| ---- | ---------------------------------- |
| 身份   | 夏娃身边唯一的小动物陪伴者                      |
| 位置   | 夏娃附近的林间草地                          |
| 行为   | 低头觅草、跟随夏娃、听见异常动静后抬头或后退             |
| 交互规则 | 不开启正式对话                            |
| 状态作用 | 小鹿平静时，表示夏娃当前警惕较低；小鹿后退或躲避时，表示夏娃警惕上升 |
| 设计目的 | 作为无文字的情绪提示，不抢占夏娃的主线地位              |

---

## 3.5 东园幽径

### 场景定位

园中树林下方的小道。树影、石缝、落叶与低矮灌木较多，是蛇接近树林前的过渡区域。

### NPC：基路伯

| 项目    | 设定                       |
| ----- | ------------------------ |
| 身份    | 东侧边界的守望者                 |
| 来源    | 《创世记》相关角色；开局提前出现属于游戏预兆设定 |
| 位置    | 东园幽径最东侧的出口附近             |
| 开局状态  | 无火焰剑，静立于道路尽头             |
| 结局状态  | 放逐剧情后，出现旋转火焰之剑并封锁道路      |
| 对话主题  | 边界、道路、不可回返之事             |
| 对话奖励  | **东门预兆**                 |
| 奖励效果  | 解锁地图提示：东园幽径会在结局后永久改变     |
| 对玩家态度 | 不提供诱惑建议；不可攻击、不可说服、不可击败   |

### NPC：刺猬

| 项目   | 设定                            |
| ---- | ----------------------------- |
| 身份   | 东园幽径的小型环境角色                   |
| 位置   | 树根、石缝、落叶堆与草丛边缘                |
| 外观   | 深棕色身体、金褐色背刺，体型小               |
| 行为   | 缓慢嗅闻落叶、在石缝旁停留、受惊后蜷缩           |
| 交互规则 | 不开启正式对话                       |
| 场景作用 | 增加幽径的隐秘感与生命感；作为蛇在低矮视角下可见的近景生物 |

---

## 3.6 四河分流

### 场景定位

地图下游的分叉区域。画面应开阔、安静，不加入小动物。

### NPC：米迦勒

| 项目    | 设定                                         |
| ----- | ------------------------------------------ |
| 身份    | 独立巡守天使                                     |
| 来源    | 后续经文角色 / 游戏扩展                              |
| 位置    | 河道交汇处的高岩、浅滩石台或河中小岛                         |
| 气质    | 严肃、克制、少言                                   |
| 对话主题  | 选择、流向、代价与后果                                |
| 核心情报  | 每一条道路都会抵达某处；玩家的言语也会带来无法完全收回的结果             |
| 对话奖励  | **四河回声**                                   |
| 奖励效果  | 在主线对话前，向玩家展示已获得的关键情报摘要：河声情报、夏娃行迹、林影之语、东门预兆 |
| 对玩家态度 | 不阻止探索，不帮助诱惑，只提供后果层面的提醒                     |

# 4. 简化主线流程

## 阶段一：伊甸之河

玩家依次与加百列、拉斐尔、乌列尔对话。

获得：

* 河声情报
* 静息之叶
* 林影之语

## 阶段二：万物受名处

玩家与亚当对话。

获得：

* 夏娃行迹
* 夏娃主要活动范围与前往园子中央的路径信息

## 阶段三：东园幽径

玩家与基路伯对话。

获得：

* 东门预兆
* 对结局道路变化的提前认知

刺猬只作为环境生物出现，不承担任务。

## 阶段四：园中树林

玩家与夏娃进行核心多轮对话。

* 静息之叶：降低夏娃初始警惕。
* 林影之语：提供更自然的开场话题。
* 小鹿状态：提示夏娃是否开始戒备。
* 夏娃接受继续交谈后，主线推进至园子中央。

## 阶段五：园子中央

不新增 NPC，不新增任务。

玩家与夏娃进行关键剧情对话，亚当在外围进入事件。

## 阶段六：四河分流

玩家与米迦勒对话。

获得：

* 四河回声
* 已收集情报与剧情后果的简要回顾

# 6. 实现约束

1. 所有可完成内容只通过对话面板实现。
2. 不设计跟随、采集、战斗、小游戏、限时任务或复杂道具栏。
3. 安抚信物与情报均在获得后自动生效。
4. 动物不使用人类语言，不开启正式文本对话。
5. 园子中央保持空旷，不放常驻角色、小动物或天使。
6. 加百列、拉斐尔、乌列尔、米迦勒均需在图鉴中标明“游戏扩展角色”。
7. 基路伯开局无火焰剑；火焰剑仅在放逐剧情后出现。
