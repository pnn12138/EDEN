# 《EDEN》人工测试优化需求文档（第四轮）

> 本文为第一章人工测试第四轮的需求原文，含全部文案、叙事、选项文本。
> 执行规划见 `20_CODEBUDDY_TASK_CHAPTER1_PLAYTEST_ROUND4_RELATION_TOKENS_ENDING.md`。
> 开发时文案/叙事/选项文本照搬本文，不得改写。

## 一、开发目标

本轮开发主要解决以下问题：

1. 完善好感度、对神明敬畏和神赐祝福之间的关系系统。
2. 修复冒险模式 Token 统计始终显示为 0 的问题。
3. 为“园中树林”和“四河分流”增加场景问题及新回响。
4. 增加“旋转的火焰剑”与逃离伊甸园隐藏结局。
5. 修复结局页面无法查看顶部、无法滚动的问题，并精简复盘内容。

# 二、好感度与对神明敬畏系统优化

## 2.1 好感度取消 100 上限

### 当前问题

当前规则层会把 NPC 好感度强制限制在 0-100，属性页面也固定显示为“当前值 / 100”。这会导致神赐祝福的叠加奖励无法正常体现。当前集齐七个神赐祝福时，还会直接把部分 NPC 好感度覆盖为 100。

### 修改要求

* 好感度下限仍为 0。
* 取消好感度上限，允许出现 115、130、200 等数值。
* 属性页面保留“/100”显示（分母固定 100，分子为真实好感度，可 >100，如 50/100、120/100）。
* 100 仅作为“满好感奖励触发门槛”，不再作为数值上限。
* 好感奖励只能在首次跨越 100 时触发一次。
* 集齐七个神赐祝福时，将效果修改为：

  * NPC 好感度不足 100时，提高到100。
  * NPC 好感度已经超过100时，保留原值，不能被降回100。
* 所有存档读取、属性页、图鉴页、结局统计和成就判断都必须支持超过100的数值。

### 验收示例

* NPC 当前好感度为95，获得20点后显示115。
* NPC 当前好感度为130，集齐七项神赐祝福后仍为130。
* NPC从95升至115时触发一次满好感奖励，之后从115升至130不重复触发。

---

## 2.2 将好感度与“对神明敬畏”嵌入 Agent 思考

### 当前问题

夏娃的 Prompt 已经根据顺从、对蛇信任和自主判断生成不同心理描述；但天使 Prompt 目前主要注入神明注视、场景和夏娃行动状态，没有把天使自身对玩家的好感度及其对神明的敬畏纳入回应判断。

### 属性统一规则

对玩家好感度统一映射为：

* 夏娃：`eveMind.serpentTrust`
* 亚当：`100 - adamMind.suspicionTowardSerpent`
* 加百列、米迦勒、路西法、刺猬：`npcRelations[npcId].affinity`

对神明敬畏统一映射为：

* 夏娃：`eveMind.obedience`
* 亚当：`adamMind.obedience`
* 天使及其他适用 NPC：`npcRelations[npcId].obedience`

代码中的 `obedience` 可以继续保留，但玩家可见名称统一使用“对神明敬畏”。

### Agent 注入要求

每次调用 NPC Agent 时，都应注入：

* 当前对蛇好感度。
* 当前对神明敬畏。
* 两项属性对应的心理阶段。
* 最近一次关系变化的原因。
* 当前神明注视、场景和已有关键回响。

Agent 不得直接输出或修改数值，只能根据数值调整态度、措辞和行为意愿。所有数值变化仍由规则层决定。

### 行为关系参考

| 好感度 | 对神明敬畏 | 应有表现                    |
| --- | ----- | ----------------------- |
| 高   | 高     | 对蛇友善，但仍维护神的秩序，不轻易提供越界帮助 |
| 高   | 低     | 愿意理解蛇，并可能主动帮助玩家探索边界     |
| 低   | 高     | 警惕、克制，倾向拒绝蛇的提议          |
| 低   | 低     | 不服从神，但也不信任蛇，表现为疏离或独立判断  |

好感度超过100后可以增加亲近程度，但不能让角色失去原有人格、职责和信仰。

# 三、神赐祝福关系被动

## 3.1 每项神赐祝福增加固定关系变化

每获得一项新的神赐祝福，在原有效果之外，额外结算一次：

* 米迦勒好感度 +15
* 加百列好感度 +15
* 亚当好感度 +10
* 夏娃好感度 +10
* 路西法好感度 -10

该效果按照玩家拥有的神赐祝福数量叠加。

例如，获得3项神赐祝福后，累计产生：

* 米迦勒 +45
* 加百列 +45
* 亚当 +30
* 夏娃 +30
* 路西法 -30

### 规则要求

* 只有首次获得某项神赐祝福时结算。
* 重复载入存档、刷新页面不得再次结算。
* 好感度最低不得低于0。
* 领取祝福时，需要在结果弹窗中显示关系变化。

建议提示形式：

> 神恩在园中荡开。米迦勒与加百列对你更加亲近，亚当与女人也听见了这道回响；远处的晨星却移开了目光。

---

## 3.2 新回响：恩泽棱镜

**类型：** 永久被动
**来源：** 园中树林场景问题
**效果：** 神赐祝福产生的正向好感度加成翻倍。

持有后，每项神赐祝福的关系变化为：

* 米迦勒 +30
* 加百列 +30
* 亚当 +20
* 夏娃 +20
* 路西法仍为 -10

该道具只翻倍正向好感加成，不翻倍路西法的负向变化。

为避免获取顺序影响强度，获得该回响时，应补算已经获得的神赐祝福所缺少的正向加成。

例如，玩家已有两项祝福后获得“恩泽棱镜”，需要立即补发：

* 米迦勒 +30
* 加百列 +30
* 亚当 +20
* 夏娃 +20

# 四、免费行动效果与叠加规则

## 4.1 修改“无羁之步”

### 当前问题

当前神赐祝福“无羁之步”的效果为所有移动都不消耗行动点，强度明显过高；项目中已有“轻步印记”的“每个时段第一次移动免费”机制，可以作为统一实现基础。

### 修改后效果

**无羁之步：每个时段第一次移动不消耗行动点。**

这里的“每个时段”即当前12时段系统中的一个昼间或夜间回合。进入下一时段后重新获得免费次数。

---

## 4.2 免费行动效果允许叠加

不能再用单一布尔值判断“移动是否免费”，应改为计算当前时段拥有的免费行动次数。

例如，玩家同时持有：

* 无羁之步
* 轻步印记
* 昼荫轻步

那么白天每个时段的前三次移动均不消耗行动点；夜晚只有前两次移动免费。

一次性道具提供的“下一次移动免费”也应与永久效果叠加，而不是覆盖永久效果。

建议抽象为：

* `freeMoveCharges`
* `freeDialogueCharges`
* 每次符合条件的行动消耗一层对应次数。
* 进入新时段后重新计算。
* 当前时段已经消耗的次数必须写入存档。

# 五、冒险模式 Token 统计修复

## 5.1 当前问题

当前蛇 Tab 中的“词元消耗统计”实际绑定的是润色 Token 变量，因此未触发润色时会始终显示0；底部的“本次低语消耗”也读取了同一组润色统计。

## 5.2 统计项目重新拆分

蛇 Tab 中改为显示：

### 对话消耗

* 本次对话消耗
* 本时段对话累计
* 本局对话累计

### 润色消耗

* 本次润色消耗
* 本局润色累计

### 总计

* 本局总消耗

计算公式：

`本局总消耗 = 本局对话累计 + 本局润色累计`

若还有总结、后台 NPC 对话或其他 LLM 调用，也应纳入总消耗，并允许展开查看来源。

## 5.3 统计规则

* 优先读取模型 API 返回的真实 usage。
* 若模型接口没有返回 usage，则使用本地估算，并在数字旁标记“估算”。
* Prompt Token 与 Completion Token 应分别保留，界面默认显示二者总和。
* 进入下一时段时：

  * 清空“本时段对话累计”。
  * 保留“本局累计”。
* 存档和读取后，统计结果应保持。
* 重新开始新游戏时全部归零。
* “时间回溯”不应清除 Token 统计，因为这是真实产生的调用成本。

## 5.4 验收要求

1. 不开启润色进行一次对话，本次对话消耗必须大于0。
2. 开启润色后，对话 Token 和润色 Token 分别增长。
3. 润色不能重复计入对话消耗。
4. 读取存档后，本局累计不归零。
5. 缺少 API usage 时仍显示合理估算值。

# 六、新增“园中树林”场景问题

项目内正式地点名称为“园中树林”，内部 ID 为 `tree_court`。当前已有场景问题分别位于万物受名处、东园幽径和伊甸之河，场景问题系统已经支持不同选项独立发放奖励。

## 6.1 交互对象

**名称：林间静影**

* 进入场景时不能自动弹出。
* 玩家点击场景中的“林间静影”后才打开问题。
* 每局只能完成一次。
* 选择任意选项后，该问题本局不可再次打开。

## 6.2 问题文案

**标题：树影留下的问题**

树叶将光切成细碎的形状，风从林间经过，却有几片叶子始终停在原处。

你忽然觉得，这片树林正在等待你带走某种痕迹。

你准备触碰哪一道痕迹？

## 6.3 选项与奖励

### 选项一：抬起头，让叶缝间的目光落在身上

获得回响：**仰光之痕**

* 类型：即时回响。
* 效果：神明注视度 +1。
* 使用统一的神明注视规则。
* 如果达到神赐祝福门槛，应正常触发祝福选择。

### 选项二：拾起那片映着数道光芒的叶子

获得回响：**恩泽棱镜**

* 类型：永久被动。
* 效果：神赐祝福带来的正向好感度加成翻倍。
* 获得时补算已有祝福的差额。

### 选项三：沿着白日树荫最深的地方滑行

获得回响：**昼荫轻步**

* 类型：永久被动。
* 效果：每个白天时段第一次移动不消耗行动点。
* 可与无羁之步、轻步印记及其他免费移动效果叠加。

### 选项四：把下一句话藏进尚未落下的夜色

获得回响：**夜露缄声**

* 类型：永久被动。
* 效果：每个夜晚时段第一次与 NPC 对话不消耗行动点。
* 可与其他免费对话效果叠加。

# 七、新增“四河分流”场景问题

内部地点 ID 为 `naming_stone_bank`。不要与当前已经存在场景问题的“伊甸之河”混淆。

## 7.1 交互对象

**名称：第五道倒影**

* 在四河分流场景中显示为可点击对象。
* 不得在进入场景时自动弹出。
* 每局只能完成一次。
* 每个选项给予不同回响或剧情效果。

## 7.2 问题文案

**标题：分流之外的问题**

四道水流向不同方向奔去。

你低头时，却在水中的倒影里看见了第五道水流。它没有流向远方，而是逆着时间，流回园子最初醒来的清晨。

你准备听取哪一道水声？

## 7.3 选项与奖励

### 选项一：听取带着晨光的水声

获得回响：**晨流回环**

* 类型：永久被动。
* 每个白天时段第一次移动：

  1. 不消耗行动点。
  2. 随后恢复1点行动点。
* 恢复后不能超过当前行动点上限。
* 免费次数及行动点恢复均每个白天时段触发一次。

### 选项二：听取藏在夜色下的水声

获得回响：**夜潮回声**

* 类型：永久被动。
* 每个夜晚时段第一次与 NPC 对话：

  1. 不消耗行动点。
  2. 随后恢复1点行动点。
* 恢复后不能超过当前行动点上限。
* 每个夜晚时段只能触发一次。

### 选项三：触碰那道流回最初的倒影

获得并立即触发回响：**溯源之水**

结果文案：

> 水中的倒影忽然倒转。说过的话退回唇边，走过的道路重新被露水覆盖。
> 当你再次睁眼时，园子正停在第一日的清晨。只有怀中的回响证明，那些事情曾经发生过。

触发以下效果：

#### 重置内容

* 时间回到第1时段白天。
* 行动点恢复到当前有效上限。
* 蛇回到初始地点。
* 清空所有 NPC Agent 对话记录。
* 清空玩家对话界面历史。
* 夏娃、亚当及其他 NPC 的属性恢复为初始值。
* NPC 位置、挑战状态、语言状态和临时行为状态恢复为开局状态。
* 神明注视及累计注视恢复为初始值。
* 禁忌动作链恢复为未触发。
* 清空场景行动记录和临时消耗品效果。
* 其他已经完成的场景问题全部恢复为未完成。

#### 保留内容

* 已获得的回响和道具。
* 神赐祝福。
* 回响使用历史。
* 已解锁的园中印记。
* Token 消耗统计。
* 当前“四河分流”场景问题仍保持已完成状态。

完成重置后：

`completedScenePuzzleIds` 应只保留当前场景问题 ID，防止玩家反复触发时间回溯。

已经获得的非重复回响不能重复叠加；重新完成场景问题时，可以选择不同选项取得其他回响。

# 八、新增加百列道具：旋转的火焰剑

## 8.1 道具信息

**名称：旋转的火焰剑**

**来源：** 加百列

**类型：** 永久被动回响

**简介：**

一道没有持剑者的火焰在空中缓慢旋转。剑锋所过之处，光与影都会短暂分开。加百列没有说明它守护着什么，只说它能够斩开不属于真实世界的帷幕。

**玩家可见效果：**

> 能够破除幻境。

不要在道具说明中直接泄露隐藏结局触发方式。

## 8.2 获得条件

* 作为加百列能够给予玩家的额外专属道具。
* 不替换加百列现有道具。
* 建议条件：

  * 加百列好感度达到100。
  * 完成加百列主动试炼。
  * 之后首次进行符合条件的对话时，由加百列主动赠予。
* 每局只能获得一次。
* 奖励触发必须由规则层判断，不能完全依赖 Agent 自行决定。

# 九、东园幽径隐藏结局

## 9.1 修改现有选项

东园幽径“幽径尽头的问题”最后一个选项修改为：

> 挣脱眼前的一切，试着从这场无法醒来的梦里离开。

## 9.2 未持有火焰剑

保持现有失败反馈：

* 无法撞破边界。
* 当前行动点归零。
* 场景问题标记为已完成。
* 不触发结局。

## 9.3 持有火焰剑

满足以下条件时触发隐藏结局：

1. 玩家拥有“旋转的火焰剑”。
2. 东园幽径场景问题尚未完成。
3. 玩家选择“挣脱眼前的一切，试着从这场无法醒来的梦里离开”。

触发新的隐藏结局：

**结局 ID：** `escape_eden`
**结局名称：** 逃离伊甸园
**结局标题：** 园外的清晨

### 结局叙事

火焰在你身前自行旋转。

它没有烧毁树木，也没有照亮道路，只是在那片看不见的边界上划开了一道裂缝。

园中的光像一层薄幕般卷起。河流、树影、天使与尚未说出口的话，都在裂缝后退向同一个清晨。

你没有抵达另一条小径。

你从小径之外醒来。

身后，伊甸仍停留在最初的一日；而你第一次站在一片尚未被命名的土地上。

### 系统处理

* 设置 `phase = ending`。
* 设置 `isEnded = true`。
* 设置 `endingId = escape_eden`。
* 停止所有后续 NPC 行动和场景结算。
* 解锁隐藏结局印记。
* 将该结局加入结局图鉴。
* 不计入普通失败结局。
* 结局复盘中明确记录：

  * 获得旋转的火焰剑。
  * 在幽径尽头选择挣脱。
  * 火焰剑破除了幻境。

# 十、结局页面 UI 修复

## 10.1 当前问题

当前结局复盘同时展示结局叙事、低语统计、禁忌动作链、关键低语、使用回响、场景互动、回响历史、献礼历史、注视变化、失败原因、印记和余痕等大量区块，内容较长。

人工测试中出现：

* 打开结局后无法看到顶部内容。
* 页面不能正常滚轮滚动。
* 移动端不能拖动查看。
* 内容过多且重复。

## 10.2 滚动修复

结局页面或弹窗需要：

* 打开时自动定位到内容顶部。
* 外层使用完整视口高度。
* 内容区域设置最大高度，例如 `90dvh`。
* 内容区域启用 `overflow-y: auto`。
* 支持鼠标滚轮、触控滑动和滚动条拖动。
* 移动端启用平滑触控滚动。
* 标题或关闭按钮可以保持吸顶。
* 不能因为背景页面锁定滚动而同时锁死结局内容。
* 小屏幕下不能使用会把顶部推出屏幕的强制垂直居中布局。

## 10.3 精简结局复盘

最终只保留以下模块：

### 1. 结局标题与叙事

保留完整结局文案，但控制在2-4个短段落。

### 2. 本局关键结果

只显示：

* 抵达结局的时段。
* 本局对话次数。
* 最终神明注视。
* 获得及使用的回响数量。

### 3. 三个关键转折

由规则层从记录中选取最多3项，例如：

* 女人第一次开始怀疑命令。
* 玩家触碰或接近善恶树。
* 获得关键回响。
* 某名 NPC 的好感跨越100。
* 触发隐藏结局道具组合。

### 4. 结局原因

* 成功或隐藏结局：显示达成结局的关键条件。
* 失败结局：显示最多3条主要失败原因。

### 5. 本局解锁印记

仅显示本局新解锁的园中印记。

### 删除或折叠

以下内容不再全部展开：

* 完整对话记录。
* 完整关键低语列表。
* 全部场景互动记录。
* 全部神赐祝福历史。
* 全部回响使用历史。
* 重复出现的神明注视说明。
* “第二伊甸园复刻”等与结局叙事重复的说明。

需要保留调试信息时，可以放入默认折叠的“查看详细记录”区域。

# 十一、存档兼容要求

新增字段必须提供默认值和旧存档迁移逻辑，包括：

* 神赐祝福关系被动结算记录。
* 神赐正向好感倍率。
* 当前时段免费移动次数及已使用次数。
* 当前时段免费对话次数及已使用次数。
* 昼夜强化回响触发状态。
* Token 分类统计。
* 新场景问题完成状态。
* 新结局 ID。
* 旋转的火焰剑持有状态。

旧存档载入时：

* 不得重复发放神赐祝福的关系奖励。
* 不得因取消100上限而将原有好感重置。
* 缺少新字段时自动补默认值。
* 已完成旧场景问题的记录不得丢失。
* 结局图鉴和印记数据不得损坏。

# 十二、测试清单

## P0：必须通过

1. 好感度能够突破100。
2. 好感奖励只触发一次。
3. 神赐祝福正确改变五名角色的好感。
4. 多个神赐祝福关系效果能够叠加。
5. 恩泽棱镜能够补算已有祝福并翻倍后续正向加成。
6. 无羁之步改为每时段第一次移动免费。
7. 多个免费移动效果能够形成多次免费次数。
8. 对话 Token 不再始终为0。
9. 对话与润色 Token 分开统计。
10. 结局页面可以从顶部开始查看并正常滚动。

## P1：场景内容

1. 园中树林问题只能点击触发。
2. 四河分流问题只能点击触发。
3. 每个选项只发放对应回响。
4. 选择后场景问题不可重复领取。
5. 昼荫轻步只在白天生效。
6. 夜露缄声只在夜晚生效。
7. 晨流回环能够免费移动并恢复1点行动点。
8. 夜潮回声能够免费对话并恢复1点行动点。
9. 恢复行动点不能超过上限。

## P1：时间回溯

1. 时间和 NPC 状态恢复到开局。
2. 所有 Agent 对话历史清空。
3. 已有回响继续保留。
4. 其他场景问题恢复为可完成。
5. 四河分流当前问题仍保持已完成。
6. 不能反复选择时间回溯。
7. Token 统计和已解锁印记继续保留。

## P1：隐藏结局

1. 没有火焰剑时，挣脱选项只会耗尽行动点。
2. 持有火焰剑时立即触发“逃离伊甸园”。
3. 隐藏结局触发后不能继续操作世界。
4. 结局图鉴和隐藏印记正确解锁。
5. 保存并读取隐藏结局存档不会回到探索阶段。
