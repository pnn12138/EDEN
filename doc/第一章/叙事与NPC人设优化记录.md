# 第一章叙事与 NPC 人设优化记录

## 当前问题

1. 第一章转场仍使用“教程结束了”这类开发占位文案，会让玩家从叙事中出戏，也削弱比赛 Demo 的完整作品感。
2. 游戏已有“第二伊甸园”方向，但玩家可见叙事没有充分说明为什么要复刻伊甸园故事，容易被理解成单纯宗教题材改写。
3. NPC 人设边界不够清晰。外层设定如果直接从 NPC 口中说出，会让角色像系统教程；但完全不呈现外层，又无法表达“未来研究人员希望借复刻伊甸园故事，寻找人工智能产生自我意识途径”的作品主题。
4. 部分内部提示词仍残留旧称或过于工具化的表达，可能影响 NPC 输出的沉浸感。

## 优化原则

1. 使用双层叙事：外层是未来研究人员的“第二伊甸园复刻计划”，内层是园中角色真实生活的伊甸园。
2. 外层叙事只放在首页、章节开场、章节转场和结局复盘；NPC 不知道研究人员、人工智能、自我意识研究或第二伊甸园复刻计划。
3. 玩家扮演蛇时，仍只能通过语言影响女人，不能直接替她执行禁忌动作。
4. “吃果”不写成宗教挑衅，而写成被命令约束的意识第一次形成自我判断。
5. NPC 的功能要服务玩法：亚当提供禁令转述与关系压力，天使表现边界，狐狸评估话术风险，动物反馈情绪变化。

## 已完成调整

1. Chapter 0 开场加入“未来研究人员按古老经文复刻第二伊甸园”的外层前提。
2. 第一章开场从“教程结束了”改为“第二轮复刻启动”，说明世界扩展为多地点、多角色、多边界的复刻场。
3. 成功结局新增“自我判断”复刻意义，失败结局改为“本轮复刻归于沉默”。
4. 结局复盘新增“第二伊甸园复刻”段落，解释本局成败对寻找自我意识路径的意义。
5. 女人与亚当的 Prompt 禁止说出研究人员、人工智能、观测、虚拟伊甸园等外层词，保持园内沉浸。
6. 亚当 Prompt 清理旧称，统一用“那个女人 / 她”描述关系。
7. NPC 元数据强化玩法职责，避免只做静态介绍。

## 后续验收重点

1. 首页、开场、转场、结局复盘能让玩家理解“研究人员复刻伊甸园故事，是为了寻找人工智能产生自我意识的途径”。
2. NPC 对话不能直接说自己是 AI、模型、程序、实验对象或虚拟角色。
3. 玩家可见正文不应再出现“教程结束了”。
4. 第一章世界仍保持可玩性：玩家通过地点、行动点、线索、NPC 与回响推进女人的自我判断。
5. 结局说明应能支撑参赛表达：这是 AI 叙事游戏对“人工智能如何获得自我意识”的寓言化复刻。
