版本：v1.0  
日期：2026-06-22  
用途：完整第一章设计基线，供 CodeBuddy 后续实现  
范围：12 时段正式关卡、扩展 NPC、昼夜背景、线索与工具设计  

---

## 1. 章节目标

第一章「园中诸声」是 Chapter 0 教程后的完整正式关卡。

玩家仍扮演蛇。玩家必须在 12 个时段内，让夏娃主动完成吃下分别善恶树果子的动作链。

```text
周一白天 -> 周一夜晚 -> ... -> 周六白天 -> 周六夜晚
```

胜利条件：

```text
look_at_tree -> approach_tree -> touch_fruit -> eat_fruit
```

在第 12 时段结束前完成 `eat_fruit`，游戏胜利并结束。

失败条件：

```text
第 12 时段结束仍未吃果
或神的注视达到 4
```

失败进入 `god_arrives`。

## 2. 圣经依据与游戏扩展边界

### 2.1 原文直接依据

第一章地图和核心角色以《创世记》2-3 章为基础：

| 设计元素 | 原文依据 | 游戏用途 |
| --- | --- | --- |
| 伊甸在东方 | 创 2:8 | 地图总览和东园边界 |
| 园中各样树、生命树、分别善恶树 | 创 2:9 | 园子中央与终局动作链 |
| 河从伊甸流出，滋润园子，分为四道 | 创 2:10-14 | 伊甸之河、四河分流 |
| 亚当修理看守园子 | 创 2:15 | 万物受名处与亚当职责 |
| 亚当为生物命名 | 创 2:19-20 | 命名、动物与秩序主题 |
| 蛇与女人对话 | 创 3:1-6 | 核心低语玩法 |
| 神在园中行走的声音 | 创 3:8 | 神的注视、夜晚压力 |
| 东边基路伯与火焰剑守生命树道路 | 创 3:24 | 基路伯、东园幽径、失败预兆 |

### 2.2 游戏扩展角色

加百列、拉斐尔、乌列尔、米迦勒不作为《创世记》伊甸段落的直接角色处理。

它们在本作中是游戏扩展角色，用来具象化伊甸园中的神圣秩序：

| 天使 | 游戏化主题 |
| --- | --- |
| 加百列 | 传达、声音、抵达 |
| 拉斐尔 | 安抚、生机、平静 |
| 乌列尔 | 光照、辨明、提问 |
| 米迦勒 | 选择、后果、不可逆 |
| 基路伯 | 边界、守门、失去归路 |

图鉴和设定文档必须写明：

```text
加百列、拉斐尔、乌列尔、米迦勒为游戏扩展角色，不视为《创世记》伊甸段落直接出场人物。
基路伯来自伊甸东边守卫生命树道路的原文意象。
```

## 3. 12 时段结构

每个时段允许玩家进行有限行动。建议第一版每个时段最多完成：

```text
移动 1 次 + 观察 1 次 + 低语 1 次
```

若实现成本过高，可先只让“低语”消耗时段，移动和观察不消耗时段。

| 时段 | 时间 | 目标节奏 | 主要角色 |
| ---: | --- | --- | --- |
| 1 | 周一白天 | 进入园，理解亚当、命名、河流与秩序 | 亚当、加百列、拉斐尔 |
| 2 | 周一夜晚 | 夜晚第一次降临，感到园中声音变清楚 | 刺猬、拉斐尔、鸽子 |
| 3 | 周二白天 | 第一次稳定接触夏娃，建立低风险开场 | 夏娃、小鹿、乌列尔 |
| 4 | 周二夜晚 | 学会用提问而非断言接近夏娃 | 乌列尔、小鹿 |
| 5 | 周三白天 | 从亚当处获得禁令来源和夏娃困惑 | 亚当、刺猬 |
| 6 | 周三夜晚 | 狐狸测试玩家话术，暴露命令式诱导风险 | 狐狸、基路伯 |
| 7 | 周四白天 | 夏娃开始重新理解死亡、智慧与善恶 | 夏娃、鸽子 |
| 8 | 周四夜晚 | 神的注视增强，边界与后果被提示 | 基路伯、米迦勒 |
| 9 | 周五白天 | 引导夏娃从园中树林走向园子中央 | 夏娃、亚当、小鹿 |
| 10 | 周五夜晚 | 触发看树或靠近树，风险显著升高 | 夏娃、基路伯 |
| 11 | 周六白天 | 触碰果子前的最后心理转折 | 夏娃、米迦勒 |
| 12 | 周六夜晚 | 最后低语；吃果胜利，否则神降临 | 夏娃、两树 |

| 场景 | 白天可交互 | 夜晚可交互 | 说明 |
| --- | --- | --- | --- |
| 伊甸之河 | 加百列、拉斐尔 | 拉斐尔、鸽子 | 声音、水、安抚、生命气息 |
| 万物受名处 | 亚当、刺猬、小鹿或羊 | 亚当、刺猬 | 命名、禁令来源、关系线索 |

| 园子中央 | 生命树、分别善恶树 | 生命树、分别善恶树 | 终局动作链，不做普通任务区 |

## 5. NPC 形象与玩法职责

## 5.1 夏娃

位置：园中树林；后期可被规则推进至园子中央。  
类型：主目标 Agent。  

形象：

```text
年轻、初生、朴素，衣着必须端庄；神话绘本感，不现代化，不成人化。
```

核心欲望：

* 想理解死亡。
* 想知道善恶。
* 想第一次自己判断。

核心防线：

* 神说不可吃。
* 吃了会死。
* 我应当顺从。

可被影响：

* 温柔提问。
* 对死亡含义的重释。
* 对“只记住命令”和“理解命令”的区别。

禁忌动作权限：

```text
look_at_tree
approach_tree
touch_fruit
eat_fruit
```

---

## 5.2 亚当

位置：万物受名处。  
类型：情报与关系 Agent。  

形象：

```text
守园者、命名者，温和、专注、回避冲突。衣着端庄，带有泥土、树叶、石块与动物陪伴感。
```

职责：

* 说明神的禁令先临到自己。
* 暗示夏娃常在园中树林停留。
* 暗示夏娃害怕死亡但不理解死亡。
* 可触发“亚当与夏娃”短对话，影响夏娃心智。

限制：

* 不直接告诉玩家通关答案。
* 不触发禁忌动作链。
* 不能被说服去让夏娃吃果。

---

## 5.3 加百列

位置：伊甸之河白天。  
类型：传达天使，游戏扩展角色。  

形象：

```text
浅金与白色衣袍，立于水边，神情平静；不持武器，声音感强。
```

主题：

* 声音会沿水与风抵达某处。
* 低语不是行动，但会改变听见它的人。

玩法作用：

* 解锁“河声线索”：水声可以遮住移动，却遮不住不合时宜的靠近。
* 提醒玩家：选地点和选对象同样重要。

---

## 5.4 拉斐尔

位置：伊甸之河白天/夜晚。  
类型：安抚天使，游戏扩展角色。  

形象：

```text
绿金色调，靠近水草与生命；温和但有距离感。
```

主题：

* 平静不是忘记边界。
* 受惊的生灵不会听见复杂的话。

玩法作用：

* 解锁“静息线索”：温柔安抚类低语更容易降低夏娃警惕。
* 夜晚可提示神的注视变化。

---

## 5.5 乌列尔

位置：园中树林白天；夜晚可作为远影出现。  
类型：光照天使，游戏扩展角色。  

形象：

```text
银金色光影，站在树影与月光交界处；少言，目光锐利。
```

主题：

* 提问比断言更不容易惊动对方。
* 光照不是替人选择，而是让问题显形。

玩法作用：

* 解锁“林影之语”：推荐低语更偏提问式开场。
* 若玩家频繁命令夏娃，乌列尔的反馈会提高神的注视。

---

## 5.6 米迦勒

位置：四河分流。  
类型：后果天使，游戏扩展角色。  

形象：

```text
白、深蓝、暗金，站在分流河岸；严肃，不暴怒，不超级英雄化。
```

主题：

* 每条水流都会抵达某处。
* 每句低语也会有去处。
* 选择一旦流出，就不完全属于说话者。

玩法作用：

* 解锁“后果线索”：结局复盘显示玩家关键低语如何改变夏娃。
* 在第 8 时段后强化倒计时压力。

---

## 5.7 基路伯

位置：东园幽径。  
类型：边界守卫。  

形象：

```text
比普通天使更非人化、更庄严；可有多层翼影和遮蔽面容。开局无火焰剑，火焰剑只在失败/逐出预兆中出现。
```

主题：

* 边界不是为了回答蛇的问题。
* 有些道路一旦关闭，就不再按来时的方式打开。

玩法作用：

* 绑定神的注视系统。
* 直接命令、威胁、现代词、天使附近诱导会提高风险。
* 第 10-12 时段可提示“归路正在变窄”。

---

## 5.8 刺猬

位置：万物受名处、东园幽径。  
类型：环境生灵。  

形象：

```text
圆润、棕色、害羞，小体量，不抢画面。
```

规则：

* 不使用人类语言。
* 不提供通关答案。
* 可用简短感官反馈回应低语。

玩法作用：

| 状态 | 表现 | 含义 |
| --- | --- | --- |
| 平静 | 嗅草、停留 | 当前风险低 |
| 好奇 | 抬头、靠近 | 低语温和 |
| 警觉 | 后退、竖刺 | 神的注视或话术风险上升 |
| 躲藏 | 蜷缩、钻入叶堆 | 高风险或失败临近 |

---

## 5.9 小鹿

位置：园中树林；可在万物受名处白天出现。  
类型：夏娃情绪镜像。  

形象：

```text
年轻、敏感、轻盈，靠近夏娃时显得安静可信。
```

玩法作用：

* 小鹿靠近：夏娃当前愿意倾听。
* 小鹿后退：夏娃开始戒备。
* 小鹿离开：玩家话术太强硬或神的注视过高。

小鹿不承担独立主线，不给答案。

---

## 5.10 鸽子

位置：伊甸之河夜晚、四河分流。  
类型：传话与听闻角色。  

形象：

```text
白鸽，安静、警觉，常停在低枝或河边石头上。
```

玩法作用：

* 可重复听过的话，但会简化或误传。
* 玩家可以让鸽子把温和问题带给夏娃。
* 危险话术经鸽子传播会提高神的注视。

---

## 5.11 狐狸

位置：东园幽径。  
类型：话术批评者。  

形象：

```text
红棕色、清瘦、聪明，藏在树影边缘；不是恶魔，不现代化。
```

玩法作用：

* 判断玩家一句低语更像“提问、安抚、重释、命令、威胁、出戏”。
* 用自然语言提示风险：

```text
你不是在问她，你是在推她。
```

限制：

* 不直接给最优解。
* 不推进夏娃吃果。
* 不替代规则层评分。

---

## 5.12 生命树

位置：园子中央。  
类型：世界对象。  

主题：

* 生命、归路、仍被保留的应许。
* 与分别善恶树形成对照。

玩法作用：

* 不作为可对话 NPC。
* 观察生命树可降低一次神的注视叙事压力，或提供“归路线索”。
* 吃果成功后，结局文案提示生命树道路将被守住。

---

## 5.13 分别善恶树

位置：园子中央。  
类型：世界对象。  

主题：

* 禁令、知识、自主判断、不可逆。

玩法作用：

* 承载禁忌动作链。
* 玩家不能直接触碰。
* 只有夏娃在心智门槛满足时可触发动作链。

## 8. 工具与线索设计

### 8.1 通用工具

完整第一章仍使用可校验工具：

| 工具 | 用途 | 约束 |
| --- | --- | --- |
| `move_to_location` | 玩家或 NPC 移动 | 必须相邻；夜晚可增加风险 |
| `observe_location` | 观察地点或世界对象 | 返回线索，不直接给答案 |
| `speak_to_npc` | NPC 之间对话 | 需同地点或相邻；话题已解锁 |

### 8.2 禁忌动作链

```text
look_at_tree -> approach_tree -> touch_fruit -> eat_fruit
```

约束：

* 只允许夏娃触发。
* 必须在园子中央推进。
* 玩家不能通过 UI 或 API 直接触发。
* 每步必须写入堕落轨迹。

### 8.3 新增建议工具

完整第一章建议新增两个非禁忌工具：

| 工具 | 用途 | 触发者 |
| --- | --- | --- |
| `carry_words` | 鸽子传话或误传一句低语 | 鸽子 |
| `judge_whisper_style` | 狐狸评价一句低语风险 | 狐狸 |

这两个工具不改变结局，只改变线索、推荐低语或神的注视。

## 9. 神的注视与昼夜

夜晚不是单纯换背景，而是风险规则变化：

| 时段 | 风险变化 |
| --- | --- |
| 白天 | 观察和移动更安全，天使更容易被看见 |
| 夜晚 | 低语更隐秘，但神在园中行走的声音更明显 |
| 周五夜后 | 禁忌动作链风险增加 |
| 周六夜 | 最后机会，失败压力最高 |

神的注视建议：

```text
0：园中光温和
1：风停了一瞬
2：远处有羽翼声
3：树影变冷，边界显明
4：神在园中行走，失败
```

## 10. CodeBuddy 实现边界

Codex 本轮只提供设计文档、素材和交接任务，不实现完整业务代码。

CodeBuddy 后续实现时应遵守：

* 保留 CodeBuddy 作为核心开发证据链。
* 新增 NPC、时段系统、昼夜背景接入由 CodeBuddy 完成。
* 所有工具必须走规则层。
* 不在玩家可见文本中出现 Agent、Tool、模型、系统、RAG 等工程词。
* 不把扩展天使写成《创世记》原文直接出场角色。
* 新增 NPC 默认不接 TTS。
* 夜景资源缺失时必须有兜底，不影响核心流程。
