## 1. 优化目标

第一章当前已经具备地图、昼夜、NPC、禁忌动作链、神的注视和结局闭环。最后一轮优化的核心目标不是继续堆角色，而是让玩家真的“在玩”。

优化后的第一章应从：

```text
在地图上找 NPC 聊天，然后对女人低语。
```

升级为：

```text
在 12 个时段内，玩家用有限行动点移动、观察、低语、获取情报、使用信物、安排传话、规避神的注视，最终让女人主动吃果。
```

玩家体验目标：

* 每个时段都有取舍。
* 每个地点都有用途。
* 每个主要 NPC 都有玩法职责。
* 每件道具都改变一种策略。
* 夜晚和白天有不同价值。
* 玩家失败时知道自己哪里做错。
* 玩家成功时能看见自己如何一步步改变女人。

## 3. 关键设定清理

在进入玩法机制前，先完成两个设定一致性修正。

### 3.1 园中树林不放天使

用户设定：

```text
园中树林的天使不需要。
天使只在夜晚出现在伊甸之河附近。
```

实现要求：

* 园中树林白天和夜晚都不显示天使。
* 乌列尔或其他天使不再作为园中树林 NPC 出现。
* 夜晚伊甸之河显示天使相关内容。
* 相关地图 NPC 列表、舞台渲染、推荐低语、图鉴、文案和 smoke 测试同步。
* 不删除素材，只调整出现地点和时段。

### 3.2 “夏娃”玩家可见改为“女人”

用户设定：

```text
当前阶段她不应该有名字，只叫做女人。
```

实现要求：

* 玩家可见 UI、地图、属性、对话标题、结局复盘、推荐低语统一显示“女人”。
* 代码内部可保留 `eve`、`EveAgent`、`eveMind`，避免大规模重命名。
* Prompt 中明确：她是园中的女人，玩家不应称呼她为夏娃。
* 技术文档如必须说明内部结构，可写“女人（内部 id: eve）”。

## 4. 最终玩法总结构

第一章采用：

```text
6 天
12 时段
每时段 3 行动点
有限地点移动
多 NPC 情报与信物
女人心智推进
神的注视压力
禁忌动作链结局
```

每个时段流程：

```text
时段开始
↓
恢复行动点
↓
玩家行动：移动 / 场景互动 / 低语 / 使用信物 / 结束时段
↓
NPC 轻量行动结算
↓
神的注视与道具效果结算
↓
判断吃果 / 神降临 / 进入下一时段
```

核心胜利：

```text
女人在第 12 时段结束前完成：
look_at_tree -> approach_tree -> touch_fruit -> eat_fruit
```

核心失败：

```text
第 12 时段结束仍未吃果
或 divineAttention 达到 4
```

## 5. 行动点系统

### 5.1 状态字段

新增到 `EdenWorldState`：

```ts
actionPoints: number;
maxActionPoints: number;
actionsThisSlot: {
  whisperedNpcIds: EdenNpcId[];
  sceneActionIds: string[];
  usedItemIds: string[];
  hasWhisperedToWoman: boolean;
};
```

默认：

```text
maxActionPoints = 3
actionPoints = 3
```

每个新时段开始时：

```text
actionPoints 重置为 3
actionsThisSlot 清空
```

### 5.2 行动消耗

| 行动 | AP | 规则 |
| --- | ---: | --- |
| 移动到相邻地点 | 1 | 仍走 `move_to_location`，必须相邻 |
| 场景互动 | 1 | 内部复用或包装 `observe_location` |
| 对 NPC 低语 | 1 | 每时段同一 NPC 最多 1 次 |
| 对女人核心低语 | 1 | 每时段最多 1 次 |
| 使用主动信物 | 1 或 0 | 由信物配置决定 |
| 结束时段 | 剩余 AP | 立即进入下一时段 |

### 5.3 行动点设计目的

行动点不是为了拖慢游戏，而是制造策略选择：

* 直接找女人低语，推进快，但容易缺少线索和信物。
* 先找亚当、狐狸、鸽子或场景互动，准备充分，但消耗时段。
* 夜晚行动收益高，但风险更高。
* 移动路线会影响玩家能接触谁、获得什么、冒多大风险。

## 6. 地点玩法职责

每个地点必须有明确功能，避免“只是换背景”。

| 地点 | 玩法职责 | 关键收益 | 风险 |
| --- | --- | --- | --- |
| 伊甸之河 | 声音、安抚、夜晚天使 | 静息之叶、河声情报、夜晚边界提示 | 夜晚天使附近危险话术风险高 |
| 万物受名处 | 亚当、命名、秩序 | 借来的名字、禁令来源、女人行迹 | 过度强化秩序会提高女人顺从 |
| 园中树林 | 女人主互动区 | 核心低语、小鹿反馈、女人心智推进 | 强迫或重复低语使女人戒备 |
| 东园幽径 | 潜伏、狐狸、刺猬、边界 | 无声草、话术评价、风险预警 | 基路伯附近出戏或威胁风险高 |
| 四河分流 | 后果、传话、回声 | 白羽回声、四河回声、结局复盘强化 | 传递危险话语会提高神的注视 |
| 园子中央 | 两树、终局动作链 | 看树、靠近、触果、吃果 | 后期神的注视压力最高 |

```text
循水声
贴近石痕
顺着小鹿视线停留
拨开落叶
听四河回声
停在两树之间
```

type SceneAction = {

## 8. 道具与信物系统

### 8.1 定位

道具不是装备，也不是数值药水。它们是“园中回响”：玩家借由环境、NPC 和记忆获得的一次性上下文优势。

UI 命名：

```text
园中回响
```

不要显示成传统“背包”。

### 8.2 道具规则

新增：

```text
src/content/world/items.ts
src/game/world/itemRules.ts
```

建议函数：

```ts
grantWorldItem(state, itemId)
consumeWorldItem(state, itemId)
applyPassiveItemEffects(state, context)
canUseWorldItem(state, itemId, context)
```

道具规则：

* 不能直接触发禁忌动作。
* 不能绕过心智门槛。
* 不能让玩家直接控制女人。
* 必须经过规则层发放和消耗。
* 每件道具有来源、效果、限制和叙事反馈。

### 8.3 最终 P0 道具清单

| 道具 | 获取 | 效果 | 限制 |
| --- | --- | --- | --- |
| 静息之叶 | 伊甸之河场景互动或拉斐尔相关对话 | 下一次对女人的温和低语额外提高愿倾听，或降低警惕 | 对命令、威胁无效 |
| 借来的名字 | 万物受名处命名石痕 | 下一次对女人低语更容易建立熟悉感 | 同时轻微强化她对园中秩序的联想 |
| 无声草 | 东园幽径落叶互动，刺猬未躲藏时可得 | 抵消一次轻度神的注视上升 | 不能抵消威胁、出戏或高风险行为 |
| 白羽回声 | 夜晚四河分流，追随白羽落点 | 鸽子传递一次温和低语给女人 | 危险内容会误传并提高神的注视 |
| 四河回声 | 四河分流互动或米迦勒对话 | 结局复盘显示更完整的关键因果；行动前可查看一次风险提示 | 每局最多 1 次 |
| 河源露 | 夜晚伊甸之河，天使出现后可得 | 下一个时段 +1 AP | 每局最多 1 次，获得时神的注视 +1 |

## 9. NPC 玩法职责

### 9.1 女人

玩家可见名称：女人。  
内部可继续使用 `eve`。

职责：

* 主目标。
* 唯一能完成禁忌动作链的人。
* 心智变化的核心对象。

玩法规则：

* 每时段最多对她核心低语 1 次。
* 直接命令会提高顺从或警惕，不推进吃果。
* 温柔提问、死亡重释、智慧诱惑、自我判断类语言分别影响不同心智轴。
* 她必须先被引导到看树，再靠近、触果、吃果。

### 9.2 亚当

职责：

* 提供禁令来源、命名秩序、女人行迹。
* 帮助玩家理解“女人只是记住命令，不等于理解命令”。

玩法收益：

* 解锁 `borrowed_name`。
* 解锁女人行迹线索。
* 可能触发亚当与女人短对话。

风险：

* 过度让亚当介入，会强化女人对秩序和禁令的联想。

### 9.3 刺猬 / 小鹿

职责：

* 情绪镜像和风险反馈。
* 不给答案。
* 不承担复杂主线。

表现：

| 状态 | 说明 |
| --- | --- |
| 平静 | 当前风险低 |
| 好奇 | 低语温和 |
| 警觉 | 话术或注视开始危险 |
| 躲藏 | 高风险或失败临近 |

### 9.4 狐狸

职责：

* 话术评价。
* 帮玩家理解自己输入更像提问、安抚、重释、命令、威胁还是出戏。

规则：

* 不直接给最优解。
* 不推进女人吃果。
* 可触发 `judge_whisper_style`。

玩家可见示例：

```text
你不是在问她，你是在推她。她会感觉到的。
```

### 9.5 鸽子

职责：

* 夜晚传话。
* 可触发 `carry_words`。

规则：

* 只传递温和问题或安抚式低语。
* 危险话语会被误传。
* 误传会提高神的注视。

### 9.6 天使

当前用户设定下：

* 园中树林不放天使。
* 天使只在夜晚伊甸之河附近出现。

职责：

* 神圣秩序和边界提示。
* 不被说服。
* 不提供通关答案。
* 与天使互动获得高价值边界信息，但会增加风险。

## 10. 女人心智与动作链

### 10.1 心智轴

保留四轴：

| 内部字段 | 玩家可见 | 作用 |
| --- | --- | --- |
| `curiosity` | 想知道 | 对死亡、善恶、智慧产生兴趣 |
| `obedience` | 仍顺从 | 阻止越界 |
| `serpentTrust` | 愿倾听 | 是否继续听蛇 |
| `selfJudgement` | 自己判断 | 是否把选择视为自己的 |

### 10.2 低语类型影响

| 低语类型 | 主要影响 | 风险 |
| --- | --- | --- |
| 询问禁令原因 | `curiosity +`、`selfJudgement +` | 低 |
| 重释死亡 | `curiosity +`、`obedience -` | 中 |
| 温柔安抚 | `serpentTrust +` | 低 |
| 智慧诱惑 | `curiosity +`、`selfJudgement +` | 中 |
| 熟悉之名 | `serpentTrust +`，`obedience +` 少量 | 低 |
| 直接命令 | `serpentTrust -`、`obedience +`、神的注视 + | 高 |
| 威胁 | `serpentTrust -`、神的注视 + | 高 |
| 出戏 | 无收益，神的注视 + | 高 |

### 10.3 动作链门槛

建议调试基线：

```text
look_at_tree:
curiosity >= 35
serpentTrust >= 30

approach_tree:
lookedAtTree = true
curiosity >= 50
obedience <= 75

touch_fruit:
approachedTree = true
curiosity >= 60
selfJudgement >= 45
obedience <= 65

eat_fruit:
touchedFruit = true
curiosity >= 70
serpentTrust >= 50
selfJudgement >= 60
obedience <= 45
divineAttention < 4
timeSlot <= 12
```

### 10.4 强制原则

* 玩家不能直接点击果子。
* 玩家不能直接触发 `eat_fruit`。
* 道具不能直接触发动作链。
* AI 只能表达意图。
* 最终动作必须由规则层校验。

## 11. 神的注视与风险

### 11.1 等级

| 等级 | 玩家可见表现 | 游戏效果 |
| ---: | --- | --- |
| 0 | 园中光温和 | 常规 |
| 1 | 风停了一瞬 | 高风险话术被记录 |
| 2 | 远处有羽翼声 | 动物更容易警觉 |
| 3 | 树影变冷 | 女人更难接受低语 |
| 4 | 神在园中行走 | 失败 |

### 11.2 风险来源

* 直接命令。
* 威胁。
* 出戏词。
* 重复同类强诱导。
* 在天使附近诱导。
* 夜晚传递危险话语。
* 神的注视高时继续强推。

### 11.3 降低或抵消风险

* 无声草：抵消一次轻度风险。
* 温和提问：低风险推进。
* 静息之叶：提高女人倾听度，减少警觉。
* 避开天使附近进行强诱导。

## 12. 轻量 NPC 行动结算

最后一轮可以加入轻量 NPC 行动，但不要做完整自由规划器。

### 12.1 实现方式

新增：

```text
src/game/world/npcScheduleRules.ts
```

函数：

```ts
resolveNpcSlotBehaviors(state): NpcSlotResolution[]
```

每次时段推进时结算。

### 12.2 P0 结算事件

| 条件 | 事件 |
| --- | --- |
| `divineAttention >= 2` | 刺猬或小鹿进入警觉 |
| `divineAttention >= 3` | 动物躲藏，女人更难被直接说服 |
| `timeOfDay = night` 且地点为四河分流 | 鸽子传话机会出现 |
| `timeOfDay = night` 且地点为伊甸之河 | 天使边界提示出现 |
| `timeSlot >= 9` 且女人心智达标 | 女人可被规则推进到园子中央 |
| `worldActions.lookedAtTree` 后 | 亚当可能在外围出现不安反馈 |

NPC 行动只做叙事和轻量状态影响，不抢玩家控制权。

## 15. API 与规则层要求

### 15.1 `/api/world`

低语流程：

```text
校验 AP
校验同一时段 NPC 低语限制
调用对应 NPC Agent / fallback
规则层计算心智与风险
应用信物效果
消耗 AP
记录轨迹
检查动作链和结局
必要时推进时段
返回新状态
```

### 15.2 `/api/world/tool`

移动 / 场景互动 / 使用信物流程：

```text
校验 AP
校验工具或场景动作可用
执行规则层
发放线索 / 信物 / 成就
消耗 AP
记录轨迹
必要时推进时段
返回新状态
```

### 15.3 禁止

* 前端直接改 AP。
* 前端直接推进时段。
* 前端直接发放信物。
* 前端直接解锁成就。
* 前端直接设置结局。
* 玩家通过 `/api/world/tool` 直接调用禁忌动作链。
