### 优化 2 · 中央黑色矩形 DevTools 定位 ✅ 已处置
- **前序风险**：上轮仅降 alpha 未锁定根因，柔化≠消除。
- **现状**：开发用 Playwright 像素亮度扫描 + 中央元素枚举核查 central_meadow / adam_garden_work / tree_court 三地点（浏览态+对话态），结论：中央区域为画面最亮（lum 80-100），无中央暗色矩形；唯一暗色矩形为右侧 `.eden-float-panel`（预期 UI）。
- **代码核对**：`.eden-stage::before` 侧边暗角 alpha 0.08/0.05、`::after` 底部 20%/0.26、`.eden-grass-foreground` 0.22/0.06（均上轮已降，本轮未改写）；`.eden-stage-character` background: transparent，立绘阴影仅 `filter: drop-shadow`。
- **判定**：方法合理（自动化亮度扫描而非肉眼），结论与 CSS 现状一致。本轮无新增 CSS 改写属合理（实测已无矩形）。
