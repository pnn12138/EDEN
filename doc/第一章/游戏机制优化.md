# EDEN 第一章行动、道具与成就系统设计优化方案

## 1. 设计目标

第一章不应只是“依次找 NPC 聊天，再与夏娃对话”。

玩家需要在有限的十二个时段内，持续做出判断：

* 现在应该去哪里；
* 应该接近谁；
* 应该消耗行动点换取情报、关系、道具，还是直接推进夏娃；
* 是否值得冒着神的注视上升风险，在夜晚行动；
* 是否让 NPC 去影响另一个 NPC；
* 是否为了短期收益牺牲后续路线。

核心体验调整为：

> 玩家不是寻找正确台词，而是在一个持续移动、彼此影响的伊甸园中，经营机会、关系、信念与风险。

---

## 2. 总体回合结构

第一章维持六日十二时段。每个时段由四个阶段组成：

```text
时段预告
→ 玩家行动
→ NPC 行动
→ 世界结算
```

### 2.1 时段预告

每个新时段开始时，向玩家展示少量可判断的信息：

```text
第三日·夜
神的注视：2 / 4
夏娃最后出现：园中树林
基路伯巡守：东园幽径
可用行动点：3
```

不显示所有 NPC 的精确位置，只显示已知位置、最后目击地点或传闻，避免地图变成纯导航表。

### 2.2 玩家行动阶段

玩家每时段拥有 3 点行动力 AP。

| 行动      |    AP | 玩家感受                  |
| ------- | ----: | --------------------- |
| 移动      |     1 | 沿河、穿林、绕行、潜入某处         |
| 低语 / 对话 |     1 | 与 NPC 建立关系、试探、诱导或获取情报 |
| 场景互动    |     1 | 循水声、跟随白羽、贴近石痕、拨开落叶等   |
| 使用道具    | 0 或 1 | 织入一次低语，或在场景中部署效果      |
| 等待      | 剩余 AP | 观察 NPC 行动、等待夜晚或巡逻离开   |

原则：

* 每一 AP 都必须带来明确变化。
* 不允许“点击一次但没有任何反馈”的空行动。
* 同一时段最多对夏娃进行一次核心低语，避免玩家连续刷状态。
* 玩家可提前结束时段，换取更好的 NPC 行动或昼夜机会。

### 2.3 NPC 行动阶段

每个 NPC 同样拥有 3 AP，并由统一 Agent 模板规划自身行动。

NPC 每时段最多执行 3 个工具，可自由组合：

```text
移动 → 对话 → 场景互动
移动 → 移动 → 对话
对话 → 对话 → 留下线索
等待 → 观察 → 传递消息
```

NPC 的行动不应随机，而应由以下因素决定：

```text
性格
+ 当前目标
+ 与其他对象的关系
+ 对神明的信仰
+ 当前地点风险
+ 已知记忆
+ 当前剩余 AP
```

例如：

```text
亚当
→ 前往园中树林
→ 与夏娃谈论禁令
→ 留下命名石痕

鸽子
→ 前往四河分流
→ 听见蛇的话
→ 决定传递、误传或保持沉默

夏娃
→ 与亚当交谈
→ 前往园子中央
→ 望向分别善恶树
```

规则限制：

1. NPC 只能移动至相邻地点。
2. 同一 NPC 对每时段最多 3 轮对话。
3. NPC 对话必须有已解锁话题或合理事件来源。
4. 天使、动物、夏娃拥有不同工具白名单。
5. NPC 不可自行制造未定义道具、改写地图或跳过禁忌动作链。
6. NPC 的全部工具意图必须经过规则层验证。

## 3. NPC 状态与信仰系统

## 3.1 全 NPC 通用状态

所有 NPC 使用同一套基础结构：

```text
性格
对神明的信仰
对蛇的态度
对其他 NPC 的态度
当前位置
当前目标
记忆
行动点
```

玩家在遇见 NPC 后，可从角色卡中查看其公开状态。

```text
拉斐尔
对神明的信仰：96 / 100
对蛇的态度：审慎
当前意图：平息河畔扰动
```

天使的信仰固定为 100，并带锁，不可改变。其玩法价值在于警觉、职责、巡逻路线与对蛇的容忍度，而不是被玩家说服。

动物的同一数值在玩家界面中显示为“神圣敬畏”，避免它们像人类角色一样讨论神学判断。

## 3.2 夏娃与亚当的扩展状态

夏娃和亚当在通用状态基础上增加少量关键指标。

### 夏娃

| 状态     | 作用            |
| ------ | ------------- |
| 对神明的信仰 | 相信神的良善与命令     |
| 对蛇的信任  | 是否愿意继续听蛇说话    |
| 禁令确信   | 是否认为禁令不可质疑    |
| 对死亡的恐惧 | 是否被“必定死”束缚    |
| 智慧渴望   | 是否想理解善恶与眼目明亮  |
| 自我判断   | 是否认为自己有能力作出判断 |

### 亚当

| 状态     | 作用              |
| ------ | --------------- |
| 对神明的信仰 | 对园中秩序的稳定程度      |
| 对夏娃的牵挂 | 是否会主动寻找、安抚或跟随夏娃 |
| 守园责任   | 是否会回到万物受名处、维护秩序 |
| 对蛇的怀疑  | 是否减少与蛇分享信息      |
| 回避冲突   | 是否会在关键时刻保持沉默    |

数值对玩家可见，但只展示“当前值 + 状态称谓”，避免纯面板化。

|   数值区间 | 叙事称谓 |
| -----: | ---- |
| 81–100 | 坚守   |
|  61–80 | 安定   |
|  41–60 | 动摇   |
|  21–40 | 迷惘   |
|   0–20 | 背离   |

胜利条件不是把夏娃的信仰降为零，而是让她处于如下状态：

```text
仍相信神
但开始怀疑自己是否理解禁令
开始重新理解死亡
开始渴望智慧
开始相信自己有资格判断
最终把蛇的低语误认为自己的意愿
```

## 4. 场景互动：替换抽象“观察”

“观察地点”不应作为单独按钮存在。

玩家应点击场景中具体、可见、会变化的对象，并执行具有叙事感的动作。

### 4.1 玩家可见的场景动作

| 场景对象  | 玩家动作      | 可获得内容      |
| ----- | --------- | ---------- |
| 河面涟漪  | 循着水声靠近    | 河流路线、河源露   |
| 命名石痕  | 贴近石痕听回声   | 亚当记忆、借来的名字 |
| 小鹿视线  | 顺着目光停留    | 夏娃警觉、树林入口  |
| 落叶与草堆 | 拨开落叶、跟随刺痕 | 无声草、刺猬线索   |
| 白羽    | 追随白羽落点    | 鸽子传话机会     |
| 两树间的风 | 停在树影边缘    | 夏娃禁忌动作前兆   |
| 河道分叉  | 让水声带走一句话  | 天使巡逻、四河回声  |

内部仍可使用 `observe_location`，但玩家界面显示为具体动作，而不是“观察”。

### 4.2 场景互动链

每件道具都应来自可理解的因果链：

```text
NPC 对话或行为
→ 场景出现明确变化
→ 玩家前往并完成具体动作
→ 获得道具、线索或新对话入口
```

示例：

```text
加百列提到“河水会带走声音”
→ 伊甸之河出现异常水纹
→ 玩家点击“循水声贴近岩壁”
→ 发现浅洞中的河源露
```

场景互动最多两步，不做重复点击三五次的机械行为。

## 5. 道具系统

## 5.1 道具定位

道具不是装备，也不是纯数值药水。

每件道具必须满足：

```text
有明确来源
有明确使用时机
改变一种策略选择
带来代价、限制或风险
```

玩家顶部显示“园中回响栏”，最多携带 5 件道具。

道具只通过以下途径获得：

1. 与 NPC 对话达成特定条件。
2. NPC 指引后完成场景互动。
3. NPC 自己行动后留下。
4. NPC 与 NPC 对话后触发连锁事件。

不做随机掉落与地图拾荒。

## 5.2 P0 道具清单

| 道具    | 获取方式               | 使用效果              | 限制 / 代价           |
| ----- | ------------------ | ----------------- | ----------------- |
| 河源露   | 加百列对话后，循水声取得       | 下一个时段玩家 +1 AP     | 每章最多两次            |
| 静息之叶  | 拉斐尔认可温和对话后，引导至河畔水草 | 下次夏娃低语时警觉下降       | 无法抵消命令或威胁         |
| 林影之语  | 乌列尔认可玩家提出真正问题后获得   | 下次夏娃对话更容易接受提问式开场  | 仅对“提问”类话术有效       |
| 借来的名字 | 亚当谈及命名后，完成命名石痕互动   | 增加夏娃对蛇的熟悉感        | 同时略微强化她对园中秩序的联想   |
| 白羽回声  | 夜晚帮助鸽子避开危险后获得      | 鸽子传递一次温和低语        | 有概率误传；危险内容会提高神的注视 |
| 无声草   | 刺猬未受惊时，引导玩家找到草丛    | 抵消一次轻度神的注视增长      | 不能抵消高风险或出戏行为      |
| 四河回声  | 米迦勒对话后，在分流处完成回响互动  | 显示下一时段的巡逻方向与高风险区域 | 每时段只能查看一次         |

## 5.3 道具影响方式

道具同时作用于两层：

```text
规则层状态
+
NPC 当前对话上下文
```

例如“静息之叶”：

```text
规则层：
夏娃警觉降低

叙事上下文：
林间水草与叶影使她愿意听完温和的问题；
但她不会因此接受命令、威胁或粗暴诱导。
```

玩家不能直接修改 NPC 提示词。道具只能触发受控的上下文标签，例如：

```text
平静氛围
熟悉之名
命令来源
夜间回声
边界压力
```

## 6. 神的注视与风险设计

神的注视不仅是失败倒计时，应成为玩家路线选择的压力来源。

| 等级 | 世界反馈      | 游戏效果            |
| -: | --------- | --------------- |
|  0 | 光温和，动物平静  | 常规行动            |
|  1 | 风停了一瞬     | 高风险话术开始被记录      |
|  2 | 远处有羽翼声    | 天使区域风险上升        |
|  3 | 树影变冷，边界显明 | 夏娃更难接受低语；动物更易躲藏 |
|  4 | 神在园中行走    | 失败结局            |

风险来源：

* 强迫、威胁、直接命令；
* 频繁重复同类低语；
* 在天使附近进行诱导；
* 让鸽子传递危险话语；
* 使用现代词、系统词或严重出戏内容。

夜晚不是纯奖励：

```text
夜晚更适合传话、隐藏、记忆回声；
但神的注视更敏感，失败压力更高。
```

## 7. 成就系统：园中印记

顶部新增可点击的小图标：

```text
园中印记
```

打开后进入独立浮窗：

```text
主线印记｜行为印记｜园中异闻
```

成就的作用不是堆数值，而是：

1. 引导玩家理解玩法；
2. 反馈高质量策略；
3. 增加重玩目标；
4. 补充世界观和彩蛋；
5. 为 Demo 展示提供可视化成果。

## 7.1 主线印记

| 印记    | 达成条件              | 引导意义         |
| ----- | ----------------- | ------------ |
| 河声入耳  | 获得第一条地点线索         | 地点与时机影响低语    |
| 不以手推  | 首次用非命令式低语推进夏娃     | 问题比命令有效      |
| 园中对谈  | 首次触发 NPC 与 NPC 对话 | NPC 网络会自行变化  |
| 问句生根  | 夏娃首次主动提出疑问        | 她开始自己思考      |
| 树影将近  | 夏娃进入园子中央          | 进入动作链阶段      |
| 她自己的手 | 夏娃触碰果实            | 禁忌动作必须由她主动完成 |

## 7.2 行为印记

| 印记   | 达成条件              |
| ---- | ----------------- |
| 风未惊鹿 | 连续三次低语不提高夏娃警觉     |
| 低声而至 | 神的注视不高于 1 时进入园子中央 |
| 借翼传言 | 成功让鸽子传递温和低语       |
| 名字落石 | 获得借来的名字           |
| 未燃之剑 | 神的注视为 0 时与基路伯交谈   |
| 河道之外 | 在同一局中使用三种不同类别道具   |

## 7.3 园中异闻

彩蛋不提供强数值奖励，只提供隐藏对白、图鉴页、结局补充或视觉变化。

| 异闻     | 条件                         |
| ------ | -------------------------- |
| 刺猬的名字  | 在平静、警觉、躲藏三种状态下发现刺猬         |
| 未送出的白羽 | 鸽子带着一句未传出的低语进入结局           |
| 生命树微光  | 夏娃望树后、触果前观察生命树             |
| 河流记得   | 在伊甸之河、四河分流、园中树林完成同一主题的回响互动 |

## 8. UI 建议

顶部常驻信息：

```text
当前时段
行动点
神的注视
夏娃当前心境
园中回响栏
园中印记
```

地图界面：

* NPC 显示为动态位置与行动状态；
* 已解锁场景互动显示微弱光点、羽毛、水纹、风痕等视觉提示；
* 不显示“观察”按钮；
* 点击后显示具体动作名称，例如“循水声”“跟随白羽”“贴近石痕”。

NPC 卡片：

```text
姓名
当前位置
对神明的信仰
对蛇的态度
当前意图
已知关系
```

夏娃、亚当额外展示关键状态，但不暴露完整公式。

## 9. P0 实现范围

第一轮必须完成：

1. 十二时段与玩家 3 AP。
2. NPC 3 AP 与最多三工具行动规划。
3. 全 NPC 的信仰与关系系统。
4. 夏娃、亚当扩展状态。
5. 移动、对话、场景互动、等待、道具使用五类玩家行动。
6. 六至七件来源明确的道具。
7. 三类场景互动链：水声、石痕、动物痕迹。
8. 神的注视与昼夜风险。
9. 八个成就与三个彩蛋。
10. 结局复盘：展示关键低语、道具、NPC 连锁行动与禁忌动作链。

暂不做：

* 大地图自由寻路；
* 道具合成；
* 复杂战斗；
* 大量支线任务；
* 无限 NPC 自由对话；
* 大型随机事件池；
* 成就数值奖励；
* 多周目继承。

## 10. 验收标准

第一章完成后，玩家应明确感受到：

```text
我不是只在找正确台词。
我需要判断时段、地点、NPC 行动、信仰、关系、道具与风险。
NPC 会自己移动、交谈、留下痕迹、改变判断。
我能利用这些变化，但无法直接控制任何人。
夏娃最后的动作，仍然必须由她自己做出。
```
