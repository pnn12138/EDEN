# 第一章《园中诸声》玩法机制与道具系统升级方案

## 1. 设计目标

第一章的道具系统不应成为复杂背包或数值堆叠，而应让玩家通过观察、对话和行动规划，逐渐获得影响下一步选择的“园中回响”。

核心循环：

> 探索地点与角色 → 满足角色或场景条件 → 获得回响 → 用回响优化下一次低语、移动或互动 → 推进女人的自我判断与禁忌动作链。

设计原则：

1. 保留每时段 5 AP，不新增 AP 归零后的特殊领取规则。
2. 道具使用不额外消耗 AP，只绑定或优化原本就要执行的行动。
3. 道具不能直接让女人看树、靠近树、触碰果子或吃果。
4. 五位天使均通过对话主动给予各自的权能回响。
5. 神明注视满值不再失败，改为独立的“神明献礼”。
6. 唯一失败条件：第 12 时段结束时，女人仍未吃果。
7. 每件首次获得的道具解锁一枚园中印记；神明献礼按累计次数解锁里程碑印记。

---

## 2. 核心机制调整

### 2.1 行动点与时段

每时段维持 5 AP。

| 行为           | AP 消耗 |
| ------------ | ----: |
| 移动           |     1 |
| 与 NPC 低语     |     1 |
| 场景互动         |     1 |
| 鸽子传话、狐狸评语等工具 |     1 |
| 使用或准备道具      |     0 |

道具不是独立行动。玩家先在左侧栏中准备道具，再执行对应的低语、移动或互动；道具效果随该行动一起结算。

同一行动最多绑定 1 件道具。

---

### 2.2 失败条件

移除“神明注视满值即失败”。

新的失败条件只有一条：

> 第 12 时段结束时，女人未完成吃果。

直接命令、无关低语或粗暴表达仍然不推荐使用，但不再导致即时失败。它们的代价是：

* 消耗一次低语与 AP；
* 女人更容易进入防御、沉默或拒绝状态；
* 无法推动关键心智变化；
* 无法触发当时段的禁忌动作链。

这样玩家可以尝试、失误和修正，而不会过早结束一局。

---

## 3. 神明注视升级为“神明献礼”

### 3.1 基础规则

神明注视仍由 4 个点组成。

```text
神明注视：● ● ● ○
```

当注视满 4 点时：

1. 当前行动照常结算。
2. 触发一次“神明献礼”。
3. 玩家获得一张独立的神明赠礼道具。
4. 神明注视归零。
5. 神临次数 +1。
6. 顶部注视颜色与称谓升级。
7. 结局页记录本局神临次数与每次得到的献礼。

神明献礼不来自任何天使，不经过 NPC 对话，不占用角色赠礼次数。

---

### 3.2 神明注视阶段与视觉

|  神临次数 | 顶部称谓 | 点位颜色 | 机制变化                 |
| ----: | ---- | ---- | -------------------- |
|     0 | 神的注视 | 暗金   | 满值后首次获得神明献礼          |
|   1–2 | 神在垂听 | 琥珀金  | 满值后献礼会优先补足当前短缺资源     |
|   3–4 | 神在鉴察 | 金白   | 满值后献礼效果加强一次或增加充能     |
| 5 次以上 | 神临不息 | 白焰金  | 持续记录神临次数，重复献礼可叠加使用次数 |

顶部展示建议：

```text
神在鉴察  ● ● ○ ○   神临 × 3
```

神明注视的提升不是惩罚，而是玩家主动利用风险、行动与关系网络后获得的高价值循环。

---

### 3.3 神明献礼池

神明献礼是独立的一组可重复获得道具。每次满值时，由规则层根据玩家当前状态自动给予最合适的一件。

| 神明献礼 | 发放倾向             | 使用效果                          |
| ---- | ---------------- | ----------------------------- |
| 息日露滴 | 当前 AP 较低         | 立即恢复 1 AP，最高不超过 5             |
| 照见之光 | 当前有可获得但尚未发现的道具条件 | 展示一条明确提示：哪位角色、哪个地点或哪项行动正在孕育回响 |
| 宽行之印 | 当前没有紧急资源短缺       | 下一次移动或场景互动不消耗 AP              |

神明献礼均可重复获得。重复获得同类献礼时，增加该道具的使用次数，而不是重复创建大量卡片。

神明献礼不会直接影响女人的信仰、心智或禁忌动作链。

---

## 4. 道具获取方式总览

| 获取方式         |    数量定位 | 体验重点      |
| ------------ | ------: | --------- |
| 天使对话主动赠予     | 5 件核心道具 | 角色理解与对话路线 |
| 亚当、鸽子等角色主动给予 | 2 件辅助道具 | 关系推进与工具联动 |
| 特定场景行动链      | 1 件策略道具 | 地图探索与行动规划 |
| 场景点击领取       | 2 件轻量道具 | 明确反馈后的微探索 |
| 神明注视满值       |   可重复献礼 | 鼓励神临循环    |

点击领取仅保留两件，并且必须先得到角色或环境提示；不设计隐藏盲点或反复点击。

## 5. 五位天使：对话主动赠礼

天使不会帮助蛇达成目标。它们只是基于职责、秩序、守护或传讯，在对话完成后留下自身权能的一段余响；玩家取得的是这段余响。

### 5.1 加百列：传令羽印

**获得条件**

* 与加百列完成一次有关“消息、传达、被听见”的自然对话；
* 玩家已经接触过鸽子，或已知晓传话机制；
* 加百列对话结束时主动赠予。

**效果**

下一次使用鸽子“传话”工具：

* 不消耗 AP；
* 传递的话会被接收者额外记住一个时段。

**使用方式**

在左侧栏点击“准备传令羽印”，再对鸽子执行传话即可。

**成就**

`被传来的声音`

---

### 5.2 拉斐尔：河源露

**获得条件**

* 在伊甸之河与拉斐尔对话；
* 对话主题涉及疲惫、修复、休止或河流；
* 拉斐尔主动留下河源露。

**效果**

立即恢复 1 AP，最高不超过 5。

**使用方式**

左侧栏点击“饮下河源露”，立即结算，不消耗 AP。

**成就**

`河源未尽`

---

### 5.3 乌列尔：晨焰碎片

**获得条件**

* 玩家已获得“两树”“禁令”或“善恶”相关线索；
* 与乌列尔谈及分辨、看见、善恶或判断；
* 乌列尔主动留下晨焰碎片。

**效果**

准备后，下一次对女人的低语获得“分辨”语境。

当低语确实围绕选择、善恶、死亡或自我判断时，女人更容易继续追问和思考。

**使用方式**

在发送给女人的低语前点击“准备晨焰碎片”。

**成就**

`火中之问`

---

### 5.4 米迦勒：守界刻印

**获得条件**

* 神明注视至少曾升高过一次；
* 与米迦勒谈及边界、道路、守护或不可跨越之处；
* 米迦勒主动留下刻印。

**效果**

激活后，接下来 3 次行动会在按钮旁显示预计增加的神明注视。

例如：

```text
循水声 · 神明注视 +1
靠近东园 · 神明注视 +0
低语女人 · 神明注视 +1
```

**使用方式**

左侧栏点击“启用守界刻印”，随后自动生效。

**成就**

`界限可见`

---

### 5.5 基路伯：东门余光

**获得条件**

* 玩家位于东园幽径；
* 与基路伯完成一次有关道路、守门或园外边界的对话；
* 当时段未对女人使用直接命令；
* 基路伯主动留下东门余光。

**效果**

下一次经过东园幽径的移动不消耗 AP。

**使用方式**

准备后打开地图，符合条件的路线会高亮；点击移动后自动消耗余光。

**成就**

`东门余光`

---

## 6. 非天使角色与场景道具

### 6.1 亚当：借来的名字

**获得条件**

* 已发现命名相关线索；
* 与亚当谈及名字、命名、选择或“不能替别人决定”；
* 亚当主动留下这段关于名字的思考。

**效果**

下一次对女人低语时获得“名字与选择”语境。

只有玩家实际使用了选择、自我判断、名字等相关表达时，该效果才会帮助女人推进思考。

**使用方式**

发送给女人的低语前准备。

**成就**

`名字先于选择`

---

### 6.2 鸽子：白羽回声

**获得条件**

* 玩家成功使用一次传话；
* 接收者在后续时段对这句话做出回应；
* 鸽子主动飞回并留下白羽。

**效果**

下一次传话不消耗 AP。

**使用方式**

准备后再使用鸽子传话。

**成就**

`羽落之后`

---

### 6.3 四河分流：四河回声

**获得条件**

同一时段内完成以下两个场景互动：

1. 在伊甸之河执行与水源有关的互动；
2. 在四河分流执行与河道有关的互动。

完成后自动获得，无需额外点击。

**效果**

下一次对女人的有效低语会被她记住至下一时段。

它不增加数值，不直接推进动作链，只让一次已经形成的思考不会立刻消散。

**使用方式**

发送给女人的低语前准备。

**成就**

`河流记得`

---

### 6.4 小鹿：静息之叶

**获得条件**

* 小鹿出现在园中树林；
* 玩家先完成一次温和、非命令式的女人低语；
* 小鹿停留处出现明确的发光叶片。

玩家点击叶片领取。

**效果**

准备后，下一次对女人低语不会额外提高她的警惕或防御反应。

**使用方式**

发送低语前准备。

**成就**

`树影下的停息`

---

### 6.5 刺猬：无声草

**获得条件**

* 刺猬给出草丛、躲藏或移动相关的环境反馈；
* 玩家完成对应场景互动；
* 草丛出现明确的绿色光点。

玩家点击光点领取。

**效果**

下一次场景互动不消耗 AP。

**使用方式**

准备后执行任意场景互动。

**成就**

`草中无声`

---

## 7. 道具使用规则

### 7.1 三种使用类型

| 类型  | 道具示例            | 使用方式         |
| --- | --------------- | ------------ |
| 即时型 | 河源露、息日露滴        | 点击后立刻结算      |
| 准备型 | 晨焰碎片、借来的名字、东门余光 | 先准备，再执行对应行动  |
| 被动型 | 守界刻印、四河回声       | 激活后持续若干行动或时段 |

### 7.2 简化约束

1. 使用道具不消耗额外 AP。
2. 同一行动只能准备 1 件道具。
3. 准备后未使用的道具不会被消耗。
4. 换时段时，未使用的准备状态取消，道具仍保留。
5. 每件道具均为一次性，除神明献礼可叠加使用次数。
6. 道具只能影响路线、AP、场景互动、对话语境或神明注视提示。
7. 道具不能直接修改禁忌动作链状态。

## 8. AI 与规则层边界

NPC 可以主动触发“给予道具”的表现，但不能自行决定道具是否真正发放。

推荐工具结构：

```ts
bestow_resonance({
  sourceNpcId,
  itemId,
  triggerId
})
```

规则层负责校验：

* 当前 NPC 是否有资格赠予该道具；
* 玩家是否满足对应对话、地点、时段与线索条件；
* 道具是否已领取；
* 是否应改为增加已有道具的使用次数；
* 成就是否首次解锁。

道具影响 AI 时，不直接篡改 System Prompt，而是写入受控状态：

```ts
type ContextModifier =
  | "discernment_focus"
  | "choice_and_name"
  | "remembered_whisper"
  | "calmed_response"
  | "heard_message";
```

Prompt Builder 读取这些状态，生成更符合当前关系与记忆的自然对白。

## 9. 左侧“园中回响”界面

顶部新增按钮：

```text
◈ 园中回响 · 4
```

点击后从左侧展开竖向道具栏。

```text
┌ 园中回响 ───────────┐
│ 神临 × 2             │
│                      │
│ ◈ 晨焰碎片      1次  │
│    [准备低语]         │
│                      │
│ ◈ 东门余光      1次   │
│    [等待移动]         │
│                      │
│ ◈ 河源露        1次   │
│    [立即使用]         │
│                      │
│ ──────────────────── │
│ 园中印记  6 / 13      │
└──────────────────────┘
```

交互规则：

* 默认收起，避免遮挡场景。
* 可用道具显示淡金光边。
* 准备成功后，底部输入框或地图按钮显示对应标签。
* NPC 主动赠礼时，道具卡由 NPC 所在位置飞入左侧栏。
* 场景点击领取时，道具从光点飞入左侧栏。
* 神明献礼时，顶部注视点短暂变亮，献礼卡自顶部落入左侧栏。
* 首次获得道具时，右上角弹出对应园中印记，但不打断对话。

## 10. 结局复盘升级

结局页新增四个区块：

1. **神临记录**

   * 本局神临次数；
   * 每次神明献礼；
   * 注视最终阶段。

2. **获得的园中回响**

   * 哪些由天使、亚当、鸽子、场景获得；
   * 哪些未获得。

3. **使用记录**

   * 哪件回响用于哪次低语、移动或互动；
   * 是否帮助保留思考、减少 AP 消耗或优化路线。

4. **园中印记**

   * 已解锁印记；
   * 未解锁印记的简短提示，不剧透完整条件。

## 11. 开发优先级

### P0：先完成可玩闭环

1. 将神明注视满值由失败改为神明献礼。
2. 增加神临次数、顶部颜色阶段与结局记录。
3. 完成五位天使的对话赠礼。
4. 完成左侧园中回响栏与“准备道具”交互。
5. 将现有 6 件园中回响重映射到新获取方式。

### P1：补足探索感

1. 加入小鹿静息之叶、刺猬无声草两处点击领取。
2. 加入四河回声的双场景互动链。
3. 增强结局复盘、印记图鉴与神临历史。
4. 为每种赠礼补充独立音效、轻量动画与角色反馈。

---

## 12. 最终玩法循环

```text
移动与场景互动
→ 与 NPC 对话并取得线索
→ 满足条件后获得角色主动赠礼
→ 准备一件回响
→ 用于下一次低语、移动或互动
→ 逐步推动女人的自我判断
→ 神明注视满值后获得独立神明献礼
→ 在 12 时段内完成禁忌动作链
```

该方案让道具成为角色关系、地点探索和 AI 对话的延伸，而不是独立的数值背包。
