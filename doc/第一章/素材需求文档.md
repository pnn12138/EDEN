## 1. 当前素材目标

第一章素材服务于“教程后的正式伊甸园 Hub”。素材目标：

```text
1. 建立更完整、更接近《创世记》原典的伊甸园空间
2. 明确园中央两棵树、四河源头、亚当修理看守地、命名石滩、分别善恶树庭院
3. 保留引言中出现的刺猬，并让刺猬成为第一章低风险动物锚点
4. 支持 NPC 移动、NPC 互相对话、地点观察、禁忌动作链的反馈
5. 通过环境音和短音效表现神的注视、天使巡望、动物草丛、河流和树庭院压迫感
6. 方便后续 CodeBuddy 接入 `public/assets/chapter1/`
```

当前不做：

```text
完整角色配音
第一章新增 NPC 发音模块
复杂动画序列
逐出伊甸园后的大地图
商业级 CG 视频
宣传海报
```

## 3. 视觉风格要求

统一风格：

```text
古典寓言
圣经伊甸园
半写实电影感绘本
柔和自然光
暗金、深绿、河水蓝、无花果叶灰绿
纯净但有轻微不安
无现代建筑、无现代衣物、无文字、无水印
```

避免：

```text
赛博朋克
现代科技 UI
Q 版卡通
恐怖血腥
过度宗教油画
直接画出上帝面孔
暴露或成人化人物
```

## 9. 音效来源建议

优先使用：

```text
Pixabay
Mixkit
Freesound
OpenGameArt
```

使用原则：

```text
1. 优先选择 CC0、免署名、可商用素材
2. 不使用 Non-Commercial 限制素材
3. 不使用来源不明素材
4. 下载后记录来源链接
5. 需要署名的素材必须记录作者
6. 音频体积建议压缩到单个文件 2MB 以内，环境循环最多 5MB
7. 音频缺失时游戏必须静默降级，不影响核心流程
```

## 11. 后续接入要求

后续 CodeBuddy 或素材处理 AI 读取本文件时，应遵守：

```text
1. 不随意改文件名
2. 不移动 image/、audio/ 目录
3. 新素材必须登记到素材记录表
4. 替换素材时保留旧素材来源信息
5. 接入游戏前检查文件是否存在
6. 图片缺失时页面必须有文字兜底
7. 音频缺失时游戏不能报错

9. 玩家可见内容不得出现 AI / Agent / NPC / 模型 / 程序 / 沙盒 / 系统 / RAG / Tool 等工程词
10. 刺猬素材优先复用 Chapter 0 `hedgehog_sprite_v2.png`，除非需要重绘地图插画中的环境版刺猬
```
