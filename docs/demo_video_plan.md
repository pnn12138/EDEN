## 一、路线总览

**完整路线：** 首页 → 引言 → 万物受名处 → 园子中央 → 伊甸之河 → 园中树林 → 东园幽径（狐狸）→ 园中树林 → 园子中央 → 结局复盘

**走这条路线的原因：**
1. 从初始地点「万物受名处」开始，不需要移动即可获得刻名石回响，展示场景互动系统。
2. 先经过「园子中央」再去「伊甸之河」，让地图移动和地点连接关系更清楚。
3. 「伊甸之河」展示水声源头、静息之叶和天使存在，避免开局直奔女人。
4. 「园中树林」展示小鹿视线和女人主活动区，再开始核心诱导对话。
5. 中途短去「东园幽径」让狐狸评价一句话术，补充一个策略型 NPC 场景。
6. 最后回到女人/园子中央触发禁忌动作链，路线覆盖 5 个地点，视觉更丰富。
